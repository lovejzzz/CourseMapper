# v0.18.9 两课递进与输出复查

这轮修复了两节实验设计工作坊中的具体缺陷：第一节只需识别变量与混杂因素，却被编译器扩成完整实验设计；教师给出的同一案例没有分别进入两课的任务；单课重新生成又丢失了教师事实。现在第一课提交比较表与混杂解释，第二课取回这个诊断，再提出修复方案，明确“设计方案不是实验结果”。保留 0.18.7 界面、十类材料、编辑和导出流程，Scion 仍仅本地运行。

## 实现边界

教师的具体目标优先于话题触发的通用教学模板。新的案例分配只适用于明确支持的受控比较任务：必须有完整组别条件、测量和因果限制，修复课还必须有原文中的设计原则。目标必须与案例实体匹配；两个不同实验混在一起、无关课程目标或缺失修复依据时不分配。最后的边界复查还加入“只混入另一实验的结论或修复原则”的情况，拒绝拼接不匹配的条件；诊断任务不依赖无关的修复记录。另加电压/温度传感器案例测试，检验代码不依赖植物或特定数值；这仍是有限的开发测试。

任务有稳定 ID 和内容 revision；第二课引用第一课的真实检查问题、参考答案和 revision。源记录修改后引用重建。单独选择第二课生成时不虚构已上过的第一课；在完整项目中只重新生成第二课时保留已存在的前课。这两个场景有独立测试。

所有教师给定评分类别保持不变。编译器推定的课程权重仍是草案，网页现在显示与 Word 相同的确认提示。该工作坊仍得到 18%/82% 的角色分配草案，这并非我认可的正式课堂评分方案，仍需教师决定是否计分及如何分配。任务内 25/50/25 与 25/35/40 的标准用于形成性反馈，不代表测得的评分可靠性。

完整回归还暴露出来源匹配把通用的 “source-bound” 当成统计学关联。排除该通用词后，无关语言资料继续留在补充区，不能授权统计事实。保留原目标同时保留操作证据要求，避免通过弱化证据校验提升通过率。

## 十类材料的教育判断

以下四项分别是正确性与证据、教学内容、可用性、跨材料一致性，各 0–4。是 Codex 对这个虚构两课案例的判断，没有独立教师评分或学生实验；不以平均分签发 classroom-ready 结论。

| 材料               | 四项评分      | 具体证据与剩余限制                                                                                                                  |
| ------------------ | ------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Course Map         | 3 / 3 / 3 / 3 | `lessons[*].sections[*].learningObjectives` 保留“Identify…”与“Propose…”；源输入中的宽泛 assessment 描述仍保留，需结合实际任务查看。 |
| Syllabus           | 2 / 3 / 2 / 3 | Word 第 1 页列出两次 40 分钟；第 2 页两个不同任务名、权重草案提示；第 5 页里程碑匹配。学校政策、渠道和部分模板用语还需本地化。      |
| Lesson Plans       | 3 / 3 / 3 / 3 | 两课各 40 分钟，第二课 warm-up 取回第一课的因果限制；outline 有实际教师答案。答案多次重复，教师版仍偏长。                           |
| Slide Decks        | 3 / 3 / 3 / 3 | 可见推理步骤、错误判断和教师 notes；移除只有“作业名称”的概念图。仍以文字为主，尚未形成更好的可视化比较表。                          |
| Assignment Briefs  | 3 / 3 / 3 / 3 | 第一课交 comparison table，第二课交 revised two-group protocol；附完整源记录。大纲草案权重仍需决定，示例答案属于练习用途。          |
| Rubrics            | 3 / 3 / 3 / 3 | 区分只背定义、漏掉条件、指出混杂但没解释，以及完整因果推理；修复不能以扩大样本代替控制条件。尚未测试多位教师的一致性。              |
| Discussion Prompts | 3 / 3 / 3 / 3 | 实际问题“增加单位但保留原条件能否消除混杂？”有源记录、后续追问和参考答案；部分追问与题库重复，适合作为练习。                        |
| Quiz & Exam Bank   | 3 / 3 / 3 / 3 | 两课各八题，均有具体参考答案；“无法归因≠零效应”及“方案≠结果”可区分理解。重用已教案例，不能作为独立迁移或闭卷效度证明。              |
| Study Guides       | 3 / 3 / 3 / 3 | 第一课五个、第二课六个练习有答案；第二课写明缺席时如何重建前课诊断。移除 Word 中紧邻的重复题干；同一记录反复练习的局限仍在。        |
| Course FAQ         | 3 / 3 / 3 / 3 | 一页直接回答交什么、用什么材料、如何评分与修订；时长与任务一致。正式提交渠道需教师提供。                                            |

校准例子：只说“随机分组并增加植物数量”且保留 8 小时/4 小时光照，不能拿到修复标准的高档，因为系统性条件差异仍在；指出“相同种子和水量，但光照与肥料同时改变”优于只背变量定义；说“混杂证明肥料无效”仍然错误。评分表能表达这些差别，但实际教师评分一致性未知。

## 验证和后续

使用真实八类 Word 导出器和完整两课 PowerPoint 导出器，逐页渲染检查了 27 页 Word 和 25 页幻灯片。长段推理合并为连续排版，避免分别定位的项目符号互相遮挡。部分材料仍有旧的 Week 标签，幻灯片的总结与自查页仍有重复内容。保留可编辑文件、原始 JSON、渲染文件、自动报告与测试日志在私有审计目录。本地验证通过 862 项单元与兼容性测试、8 项 benchmark 检查器测试和 38 项浏览器回归，以及类型检查、lint、构建和 bundle 检查。浏览器用单 worker，覆盖完整恢复、Regen、编辑、移动布局与导出；本轮没有重新下载或加载大模型，也没有启用在线额度或付费服务。

下一步应优先减少教师材料的重复与未提供的行政模板，加入与教例不同的迁移题、盲评教师校准，再扩展有严格输入与答案约束的任务家族。当前成果是更可靠的课程任务编译器；并未训练出专用模型，也未证明任意学科课程都可以无需审阅直接发给学生。v0.19.0 仍不发布。
