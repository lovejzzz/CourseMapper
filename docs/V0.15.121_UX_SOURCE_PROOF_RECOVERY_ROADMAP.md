# V0.15.121 UX Source Proof Recovery Roadmap

## Goal

Close the citation/source-proof gap exposed by the fresh deployed v0.15.120
User Experience Design Studio ZIP/log audit without weakening the source
grader or trusting metadata-only rows.

## Evidence

- App version: `0.15.120`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T065500Z-v015120-ux-fresh`
- Visible package result: `Quality 98`, `Texture 95`
- Embedded and local current-rule regrade finding:
  `sourceRef coverage is too thin: 204 atom(s) rely on 0 trusted concept-linked source row(s)`
- `SOURCE_REPORT.md` only listed a review note:
  `SL1: Existing course map fields.`
- SourceRef coverage was complete across outcomes, activities, examples,
  assessments, rubric criteria, and factual claims, so the defect was not a
  missing-atom problem. It was missing trusted bibliography proof.

## Lane

1. UX source-proof recovery
   - Detect User Experience / UX / design-studio course context during ZIP
     export when source proof is expected.
   - If the source ledger has at most one trusted concept-linked row, add a
     small curated UX background graph with URL-backed, CC BY-SA licensed,
     concept-linked source rows.
   - Route those rows through the normal `buildSourceLedgerFromCourseGraph`
     trust, license, concept-link, and UX false-friend gates.

2. CourseIR bridge remains strict
   - Keep the existing bridge rule that refuses to replace CourseIR review
     rows unless multiple trusted concept-linked source rows exist.
   - Do not bridge metadata-only, off-discipline, or unlinked rows.
   - Do not invent proof for courses that are not clearly UX/design-studio
     contexts.

3. Regression coverage
   - Reproduce the v0.15.120 failure shape: complete CourseIR sourceRef
     coverage, one review-only `Existing course map fields` row, and no
     provider-recovered source rows.
   - Prove the exported manifest and source report carry trusted Wikipedia
     source rows with URLs, `CC BY-SA 4.0` licenses, and concept links.
   - Prove `sourceReviewRows` and `Existing course map fields` disappear only
     after the trusted rows are available.

## Release Boundary

- This release repairs UX source proof recovery for the observed review-only
  CourseIR sourceRef path.
- This release does not weaken citation scoring, license scoring, or source
  relevance scoring.
- This release does not claim clean provider output until a fresh deployed
  v0.15.121 ZIP/log audit proves the source proof reaches real generated UX
  output.
- Texture remains a strict-clean target after source proof is repaired.
