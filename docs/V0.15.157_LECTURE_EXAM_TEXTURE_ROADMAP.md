# V0.15.157 Lecture Exam Texture Roadmap

## Evidence

The GPT-5.5-pro Introduction to Computer Science with Python model-comparison
audit at
`verification-output/edutool-audit-loop/20260630T134335Z-v015147-gpt55pro-python-model-compare/`
regraded the old v0.15.147 package at 94/A with texture 92. The run was not a
fair model comparison because v0.15.147 sent GPT-5.5-pro an unsupported
`reasoning.effort: low`, but the exported package still exposed a deterministic
CourseMapper-side texture problem:

- Slide decks repeated `collect concept-check answers, confidence ratings,
misconception patterns, and corrected explanations...` across all 15 lessons.
- Discussion prompts repeated the same `wrong-answer sort` /
  `exam-transfer readiness` protocol chain across lecture/exam lessons.

Those phrases come from CourseMapper's lecture/exam modality decoder and
discussion protocol, not from a provider-only prose decision.

## Scope

V0.15.157 keeps the release narrow:

1. Rotate lecture/exam evidence routines by lesson before they feed slide decks,
   lesson plans, and downstream support surfaces.
2. Rotate lecture/exam feedback and instructor-move routines so misconception
   repair remains present without becoming a repeated shingle.
3. Rotate checkpoint-response discussion protocols for lecture/exam courses.
4. Add a 15-lesson lecture/exam regression using the real repeated-shingle
   evidence from the GPT-5.5-pro Python package.

## Goal

Reduce deterministic texture loss in lecture/exam packages before provider
prose, voice pass, or export scoring see the material.

## Lane

Compiler texture cleanup. This is not a source-trust broadening, scoring
threshold change, provider-prompt change, or new provider-score claim.

## Release Boundary

This release may claim that lecture/exam compiler routines no longer emit the
named concept-check and exam-readiness scaffolds as full-course repeated
shingles under regression coverage. It may not claim GPT-5.5-pro, GPT-5.4-mini,
or any deployed package now reaches 100/100 until a fresh funded v0.15.157
ZIP/log audit proves it.

## Verification Target

Ship only after the focused lecture/exam compiler regression, release-history
audit, and normal local gates pass. The next evidence step is a same-version
model comparison run once provider credits are available.
