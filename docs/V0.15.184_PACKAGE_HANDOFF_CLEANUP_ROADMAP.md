# V0.15.184 Package Handoff Cleanup Roadmap

## Evidence

Recent EduTool.dev audits reached clean or near-clean quality scores, but the
workspace still made the handoff feel noisier than the package warranted. The
export panel and Agent panel could both repeat the same caveated-download
language, and ChatPanel tests mocked the custom-tools header affordance as
visible even when the production component hides it for zero tools.

The latest source-truth release also still needed to remain in force: trusted
source rows must stay real, on-topic, concept-linked, accessible, and
license-safe.

## Goal

Make the finished-package handoff read as one coherent surface:

- export panel stays action-first and compact;
- Agent panel owns the explanatory notes;
- zero custom tools do not add a header pill;
- tests enforce the cleaner split instead of preserving duplicated warning copy.

## Lane

Product UI/UX handoff cleanup and release-truth hardening. This is not a
grader weakening, quality-score inflation, or provider-prompt change.

## Release Boundary

This release may claim that:

- caveated downloadable Agent receipts use `Package notes` / `Notes saved`
  language instead of repeating the export panel's `Ready with notes` state;
- Agent receipts no longer say `Download is ready` when the export panel already
  owns the download action;
- ChatPanel tests now preserve the production zero-custom-tools behavior;
- header Project menu cleanup remains project-level and avoids duplicate handler
  clutter;
- the stricter no-derivatives source-trust policy from v0.15.183 remains the
  current release baseline.
- Vitest uses a repo-level timeout long enough for heavy compiler fixtures to
  finish under full-suite parallel load, while keeping every assertion intact.

It may not claim a new provider score until a fresh deployed GPT-5.4-mini
ZIP/log audit proves real output on the deployed version.
