# V0.15.162 Assessment Scaffold Repair Roadmap

## Evidence

- Recent Python course-output audits showed repeated weekly-assessment scaffolds
  such as `Quick evidence check`, `Exit ticket using...`, and `Practice
response that names...`.
- Those phrases can be semantically weak even when the Course Map cell is not
  blank, so blank-cell repair alone does not remove them before they seed graph
  assessment titles, package metadata, and exported materials.
- The highest-value fix is CourseMapper-side validation and repair, not hoping a
  larger model avoids the phrase every time.

## Goal

Repair generic weekly-assessment scaffold phrases before graph/export
derivation while preserving the existing prompt-artifact cleanup order.

## Lane

Course Map readiness repair, Computer Science/Python fallback texture, and
regression coverage. This is not a grader-threshold, provider, source-ledger, or
ZIP-download change.

## Release Boundary

This release may claim deterministic CourseMapper-side repair for the known
assessment scaffold phrases. It may not claim a new deployed provider score or a
completed v0.15.162 ZIP/local-regrade audit until fresh GPT-5.4-mini evidence is
captured after deploy.

## Product Diagnosis

CourseMapper already repaired blank Course Map cells, prompt-artifact labels,
generic Session/Week skeletons, and weak-topic references. The missing slice was
complete-looking weekly-assessment text that repeated generic scaffolds such as
`Quick evidence check: apply X to a new example.` Because the text was present,
it could survive into the derived graph and later exports.

## V0.15.162 Scope

- Detect weekly-assessment scaffolds that match `Quick evidence check`, `Exit
ticket using...`, `Practice response that names...`, or `apply X to a new
example`.
- Repair those cells after prompt-artifact cleanup so topic inference still uses
  the lesson concept instead of the scaffold sentence.
- Expand Computer Science/Python weekly-assessment fallbacks to rotate code
  trace, mini-program, debugging note, implementation choice, peer review, and
  transfer-check variants.
- Add a regression fixture with exact GPT-style repeated assessment output and
  assert both Course Map cells and derived graph assessment titles are clean.
