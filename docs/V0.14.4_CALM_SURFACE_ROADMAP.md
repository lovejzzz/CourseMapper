# V0.14.4 Roadmap — Calm Surface: the UI catches up to the pipeline

**Source analysis:** a design critique of the live workspace (Probability &
Statistics for Engineers, June 11 screenshots) plus the same run's console
log (run-1781228533296). The pipeline underneath is now rich and honest —
the log shows genome 6/13, a judgment verdict, an enrichment recovery call,
a quality grade of 100/A, and a registry that compiled **51 assignment
briefs** — but the UI tells almost none of that story, and what it does say,
it says five times. The screen's loudest elements (a solid navy table
header, oversized assessment bubbles) are its least important; its most
differentiating fact (the quality grade) is buried mid-panel.

**Already landed ahead of this roadmap:** the assessment bubbles are now
quiet links (CourseMapPreview: inline indigo text, hover underline + arrow,
same dispatch/data contract, tests unchanged) and list prefixes dropped to
slate — the first application of the accent rule below.

**Thesis:** three principles, applied everywhere:

1. **Visual weight follows importance.** The table is the product; its
   chrome (headers, numbering, links) recedes and its content leads.
2. **One fact, one place.** Build state, review items, and quality each get
   exactly one home. Today build state lives in five surfaces and review
   items in three.
3. **The UI surfaces what the pipeline already knows.** Genome coverage,
   judgment verdicts, recovery retries, per-assessment identity — all
   already in the budget/digest events; none visible without the console.

**Target (acceptance):**

- A first-time viewer can answer "is it done? what needs me? how good is
  it?" from exactly three elements: the build ribbon, the review queue
  badge, and the quality chip — verified by screenshot review of the three
  workspace states (generating / reviewing / ready).
- The course-map table renders with the light sticky header, lesson bands,
  and the link language — no navy block, no bubbles, no rainbow dots —
  and stays byte-identical in its DATA (graph/compile untouched).
- 51 briefs browse comfortably: grouped by lesson, registry IDs visible,
  one-click from map link → the exact brief and back.
- The review queue triages: observations / spot-checks / structural
  notices, each class counted separately; the quiz-header repeated-phrase
  class no longer inflates "needs your eyes" (gate exemption for
  structural metadata lines).
- Zero text below 12px; one radius scale; indigo only on interactive
  elements; the two amber components become one; dark mode renders the
  full map preview correctly (today it has zero dark: variants).
- Full suite + Crucible round green afterward (UI work must not move
  artifact bytes — the golden harness and round scores are the no-regression
  proof), bundle budgets updated deliberately if the AppFlow chunk grows.

**Principle (carried + new):** code must not assert what it did not check —
and **the screen must not whisper what the pipeline shouted.**

---

## WS-A — The table is the product

**A1. Header.** Replace the solid navy header row with a sticky light one:
`bg-slate-50`, 12px medium slate-600, sentence case, bottom hairline.
Column width hierarchy: objectives widest, goals/topic narrow, fixed-width
section column.

**A2. Lesson bands.** The vertically-merged "Lesson N" cell becomes a
full-width band row: lesson number + title (medium, indigo-950 on
indigo-50), right-aligned meta chips drawn from data the graph already has
(sections · assessments · genome-linked · enriched). Bands are the natural
collapse handle (A4).

**A3. Type rhythm.** Cell body 13px/1.55; the `1a.` goal labels become
10px slate badges (the double-numbering noise recedes); `Evaluate Design`
column renders the alignment-lint verdict with a pass/finding icon instead
of a prose paragraph.

**A4. Lesson collapse + density toggle.** Bands collapse/expand lessons
(default expanded); a compact/comfortable density toggle in the preview
toolbar. State in localStorage, never persisted to the project.

## WS-B — One status spine

**B1. The build ribbon.** A single slim ribbon under the workspace header,
fed by the existing budget/digest events (`apiCallBudget` already streams
them): stage steps (map → enrich → compile → verify → ready) with live
sub-labels from the actual events ("Enriching lessons 9–12", "Recovery 1/2
for lessons 1–3"), a cost ticker, and on completion the pipeline chips
(genome 6/13 · judgment clean · coverage 13/13). The log proves every
string already exists — this is rendering, not plumbing.

**B2. Quality to the crown.** The quality chip moves to the header beside
the course title (states: grading… / 100 · A / not graded) and stamps the
download card. The right panel keeps only actions.

**B3. Deduplicate status.** The agent panel's progress card, the tab bar's
"Generating 0/9…", and the right panel's status cards all collapse into
ribbon + per-tab ready ticks. Rainbow tab dots removed. The right panel
becomes two sections: Review (queue entry) and Download (scope + buttons).

## WS-C — One review queue

**C1. Merge the three entrances.** "N items need your eyes", the agent's
"Worth a look" observations, and export warnings become one queue with
three classes: **observations** (judgment/alignment — the agent's voice),
**spot-checks** (per-deliverable look-here items), **structural notices**
(export-verify mechanics). Badge shows per-class counts, not one anxious
number.

**C2. Step-through review.** Opening the queue enters a focused drawer:
item → the exact deliverable location (reuse the focus-deliverable
plumbing) → mark reviewed / dismiss → next. Progress persists per package.

**C3. Declassify structural noise (product-side).** The repeated-phrase
export gate exempts structural metadata lines (the quiz header "(Multiple
choice, 2 pts, ~2 min)" pattern that flagged 13× in the log) — content
shingles still flag. The lang-discipline regex stops matching prose like
"Probability language" (require language-course shapes: course noun
position or a named language). Both with tests; both also shrink the
queue honestly.

## WS-D — Deliverable views at registry scale

**D1. Briefs grouped by lesson.** 51 items → lesson groups with sticky
lesson headers, registry ID + kind + weight on each brief card, jump-nav
sidebar (L1–L13). Same for rubrics (51) — and rubric cards link to their
brief.

**D2. Exams stand out.** Quiz & Exam Bank: the exam entries (kind 'exam')
get a distinct header treatment + "Covers Lessons 1–7" scope line, listed
after their lesson's weekly quiz.

**D3. Round-trip affordance.** "Show in course map" on every brief/exam
header (the reverse event exists); map link → deliverable → back is a
two-click loop, verified in component tests.

## WS-E — Tokens and parity

**E1. The accent rule, codified.** Slate carries structure; indigo means
interactive; amber/green/red mean status; nothing else gets color. Sweep:
checkboxes, icons, prefixes (done), section labels.

**E2. Scale floors.** 12px text floor (the 10–11px metadata moves up or
out); one radius scale (lg cards / md controls / sm chips); the two amber
attention components become one `NoticeBanner`; ALL-CAPS section labels →
sentence case + weight.

**E3. Dark mode parity.** The map preview has zero `dark:` variants today
(visible in the file); the toggle exists, so the table/links/bands get a
dark audit pass with screenshots in both modes.

## Verification protocol

UI work is screenshot-verified: the preview harness drives the three
workspace states and captures before/after per workstream (the Crucible's
browser machinery makes this nearly free — a `--screenshots` capture of
workspace states can ride a dry-run-with-fixture-project flow). Functional
proof: full suite green; component tests for ribbon states, queue
classing, group navigation; one live Crucible round after WS-C3 (the only
artifact-affecting change) confirming scores hold and the structural
warning class vanishes from the digest. Bundle: ribbon + queue live in the
AppFlow chunk — measure and budget the growth deliberately.
