## Lane 1 — DEPTH ON THE RECORD (the headline)

### D1. The depth slice A/B, aggregate protocol

The experiment that kept slipping is now nearly free: `compileCourse` is deterministic and headless, so a depth A/B is two facade compiles per course and two judge readings — no browser, no generation spend, judge fees only.

- **The flag:** lesson-plan activities carry the kernel's worked example, misconception corrective, and citation INSIDE the activity steps (today they sit beside the activity as reference material).
- **The protocol (per the variance note — this is the point):** ≥6 genome-linked courses, each compiled twice (deep on/off) via the facade, both arms exported and judged. NOT one pair — six-plus. A win is: judged majority for the deep arm across all pairs with zero losses, OR a ≥2-point margin on any single course; structural grade holds 100/A on every twin; texture sub-scores don't collapse.
- **Bar met →** depth ships default-ON in the compiler (it is deterministic content placement, not a generation-cost change; the structural gates already guard it). Bar unmet → named failure class in the round report, flag stays off, and the kernel-placement hypothesis is retired honestly.

### D2. The per-course-means ruler, instrumented

The variance note names the real KPI — per-course MEANS moving — but today computing them means reading eleven round reports by hand.

- A small script (`npm run crucible:means` or a section of the round report) computes per-course judge means ± sd from the stored verdicts and prints the trajectory against the v0.15.2 baseline table (world-lit 5.40 … mandarin 3.86).
- **Bar:** every future ROUND_REPORT carries the means table automatically; the named target on the wall is **mandarin 3.86 → 5+**. D1's deep arm is the first intervention measured against it.

## Lane 3 — THE HUMAN RULER (the ceiling above the judge)

### H1. The instructor packet

The judge's band is 3–6 and it is advisory forever — the only instrument above 6/10 is a human instructor. This lane prepares the artifact; the handoff itself is a user action.

- Build the instructor-facing review packet from the best course (world-lit, mean 5.40): the exported ZIP plus a one-page review guide asking the only questions that matter — _would you teach week 3 as-is? what would you change first? what's missing that your students would notice?_
- **Bar:** the packet exists in the repo (docs/instructor-review/), is generated from a live round (not a fixture), and the v0.16 roadmap's north star is written from a real instructor's margin notes — or explicitly records that none were obtainable, dated.
