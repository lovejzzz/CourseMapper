# V0.15.112 Assignment Parameter Texture Roadmap

## Goal

Stop internal assignment-parameter scaffolds from appearing in student-facing
briefs, and reduce the repeated template tails that kept the latest UX package
below the strict texture target.

The fresh deployed v0.15.111 User Experience Design Studio audit showed the
current system is close but still not clean:

- Visible UI and exported report: `98/100 (A)`, `Texture 95`
- App version: `0.15.111`
- Run ID: `run-1782687772671`
- Local regrade: `98/100 (A)`
- Scored finding: one P1 substance issue in
  `Assignment Briefs/Lesson 11 - quiz and exam bank - Assignment Briefs.docx`
- Evidence: `Work within these parameters: Use brief written explanations;
Include at least 2 misconceptions; Focus on concepts and application;
Support answers with reasons.`

The source-gate work from v0.15.111 improved the previous false-friend source
issue: the audited v0.15.111 source ledger is licensed, linked, and
concept-attached. The remaining scored loss is CourseMapper-side wording and
compiler texture.

## Lane

1. Repair assignment parameter scaffolds before export.
   - Stop rendering the internal `Work within these parameters` prefix.
   - Convert prompt-shaped parameter clauses into student-facing requirements.
   - Rewrite `misconceptions`, `Focus on`, and `Support answers with reasons`
     shapes so the grader cannot mistake compiler instructions for course
     concepts.

2. Add a defensive finalizer cleanup.
   - If stale/generated payloads still contain `Work within these parameters`,
     rewrite them before DOCX/PPTX/ZIP export.
   - Prove the exact v0.15.111 failure sentence no longer triggers
     prompt-artifact contamination.

3. Rotate repeated texture tails found in the same audit.
   - Study-guide transfer questions no longer stamp the same
     `apply the answer to the next revision` wording.
   - Slide objective openings no longer stamp the same
     `Translate the objectives into actions` sentence across decks.
   - Discussion redirect and no-invented-source caution text now vary by
     lesson while preserving source honesty.

## Release Boundary

- This release changes student-facing compiler wording and deterministic
  texture variation.
- This release does not weaken the deep quality grader, source-ledger checks,
  citation standards, export verification, or texture measurement.
- This release does not claim strict-clean provider output. A fresh deployed
  v0.15.112 ZIP/log audit must prove the prompt-scaffold P1 is gone in real
  provider output and measure whether texture reaches the strict target.
- Genome linkage remains a carry-forward target until source/research bridge
  evidence reaches the stricter target.
