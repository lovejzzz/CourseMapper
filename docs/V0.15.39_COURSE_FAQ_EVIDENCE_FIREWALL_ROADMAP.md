# v0.15.39 Course FAQ Evidence Firewall Roadmap

_Written June 20, 2026. App version: `0.15.39`._

## Goal

Ship the smallest evidence-backed release that fixes the fresh Genetics and
Society Course FAQ P1 without weakening quality grading: compact deliverable
artifact lists must not become source evidence, even when they are packed into a
single supporting-resource string or stale FAQ metadata.

## Lane

Compiler hygiene and Course Map repair. This lane stays inside deterministic
supporting-resource repair, throughline evidence-packet selection, Course FAQ
rendering, and release proof. It does not attempt the broader source-license or
source-ledger relevance redesign.

## Release Boundary

In scope: compact numbered artifact-resource detection, throughline evidence
cue rejection, Course FAQ safe evidence rendering, release manifest, contract,
and roadmap updates. Out of scope: source-license policy, trusted-source
expansion, provider randomness, and grader threshold changes.

## Evidence

(`d2f6597`). Fast verification and Pages deploy were green before the run.
The fresh Genetics and Society package exported successfully and downloaded as:

- `verification-output/edutool-audit-loop/20260620T210413Z/Genetics and Society - Course Materials (2).zip`

Local regrade reproduced the package report:

- quality: `97/100` (`A`)
- texture: `94/100`
- findings: `0 P0`, `1 P1`, `3 P2`
- export verification: passed

The remaining P1 was not a model outage or browser artifact. It was deterministic
compiler output in `Course FAQ/Lesson 01 - DNA and inheritance basics - Course FAQ.docx`:

- `Strong work uses slide decks 2. quiz bank 3 and explains a decision or implication.`
- `cites a concrete detail from slide decks 2. quiz bank 3.`

The prior v0.15.38 patch repaired exact single labels such as `slide decks`, but
the live ZIP exposed a stricter case: compact numbered artifact-label lists can
be joined into one string before the repair detector sees item boundaries.

## Fix

v0.15.39 hardens the Course Map repair pass so `supportingResources` checks
preserve array boundaries and split compact numbering patterns such as
`slide decks 2. quiz bank 3. study guides`. Embedded multi-label artifact runs
are repaired for normal disciplinary courses before blueprint compilation.

The blueprint compiler also rejects prompt artifact labels or multi-label
artifact runs when selecting a lesson's throughline evidence packet. Course FAQ
rendering now uses a safe evidence cue for:

1. the focus answer (`Strong work uses ...`);
2. the anchor contrast sentence;
3. the materials-review answer.

If stale metadata still contains artifact labels, the FAQ falls back to lesson
source evidence instead of publishing requested deliverable names as evidence.
