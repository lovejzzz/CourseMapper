# V0.15.120 Study Guide Artifact Firewall Roadmap

## Goal

Close the remaining Study Guide prompt-artifact leak exposed by the fresh
deployed v0.15.119 User Experience Design Studio ZIP/log audit.

## Evidence

- App version: `0.15.119`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T062200Z-v015119-ux-fresh`
- Visible package result: `Quality 98`, `Texture 94`
- Embedded and local current-rule regrade finding: one P1 for prompt artifact
  labels in `Study Guides/Lesson 09 - Design communication - Study Guides.docx`
- Evidence phrase:
  `discussion prompts that invite analysis and later assessments`
- Source side: `SOURCE_REPORT.md` showed five URL-backed, license-backed,
  concept-linked source ledger rows and full sourceRef coverage, so this patch
  targets compiler language hygiene rather than source trust.

## Lane

1. Study Guide check titles
   - Treat deliverable prefixes such as `Discussion prompt:`, quiz-bank labels,
     study-guide labels, Course FAQ labels, slide-deck labels, assignment-brief
     labels, and rubric labels as unsafe Study Guide check titles.
   - Preserve the useful topic after the prefix when it is safe.

2. Natural student-facing replacements
   - Render discussion prompt checks as `discussion on ...`.
   - Render quiz-bank checks as `retrieval check on ...`.
   - Render other artifact-prefixed checks as `evidence check on ...`.

3. Regression coverage
   - Extend the prompt-artifact finalizer regression with an in-class
     `Discussion prompt:` assessment that flows into Study Guide preparation
     text.
   - Prove the exported Study Guide text uses natural discussion language and
     does not retain the prompt-artifact label.
