# v0.8.61 Output Quality Roadmap

## Why this release

A full audit of a real v0.8.6 four-course export (Climate Justice, Applied Machine Learning, Business Law, Social Policy — ~330 files) found that every deliverable was produced by the blueprint compiler with zero per-deliverable AI calls, and the compiled output reads like a mail merge: tokenized fake concepts, assessment titles repeated up to 31 times per document, identical quiz templates with the same answer key in every lesson of every course, sentences truncated mid-clause, and instructor-facing steps inside student-facing briefs. Export verification reported `ready, 0 warnings, 29/29 checks passed` for all of it.

v0.8.6 made generation cheap. v0.8.61 makes the cheap path _worth shipping_: the compiler's deterministic English must hold up to an instructor's read, and the trust surface must stop overclaiming when it does not.

Predecessors: `docs/V0.8.6_COMPILER_EFFICIENCY_ROADMAP.md`. The agent cost work in `docs/V0.8.61_AGENT_COST_AND_TRUST_ROADMAP.md` moves to the next release; this output-quality release takes the v0.8.61 number because the audit findings block instructor trust today.

## Workstreams

### 1. Compiler language integrity (`courseBlueprintCompiler.js`)

1. **Concept extraction**: `wordsFromConcepts` stops emitting single words from titles. Sparse maps fall back to comma/"and"-split multi-word phrases from the lesson title ("Climate Science", "Justice Frameworks", "Community Resilience Basics"), never to bare tokens. Tags, key terms, study-guide topics, agenda lines, and "Carry forward" previews all inherit the fix.
2. **`stripListPrefix`** handles `1.1:`, `2.3 –`, `(a)` style prefixes; no output may begin with a colon.
3. **`conciseClause`** completes at clause boundaries (comma/semicolon/conjunction) instead of mid-phrase; when nothing fits, it rewrites with the short reference instead of cutting.
4. **Short-reference system**: each deliverable section names the assessment and lesson once in full, then uses deterministic short forms ("this artifact", "the Week 2 check", "this lesson"). Budget: full assessment title ≤ 4 mentions per document.
5. **Quiz variety**: correct-option position rotates deterministically (seeded by lesson index + question index); at least two distractor families per question type so the correct answer is not the only differently-phrased option; stems vary by lesson position in the course arc.
6. **Sentence integrity**: a/an agreement helper at all concept-slot joins; "Strong work: names…" punctuation; self-assessment templates use short references so they cannot dangle; empty "Grading Criteria" renders the rubric summary or is omitted.
7. **Audience separation**: student-facing sections (brief instructions, study guides, FAQs) run through a student-voice template set; instructor moves stay in lesson plans/rubric facilitation only.
8. **Policy text**: Generative AI Policy and Academic Integrity get distinct copy.

### 2. Document formatting (`exporters/`)

1. **DOCX structure**: real `Heading2`/`Heading3` for every section label (navigation pane, TOC-ready, screen readers); document title uses `Title` style.
2. **DOCX page furniture**: footer with course name + page number on every document.
3. **DOCX tables**: syllabus Outcome & Assessment Alignment becomes a real 4-column table; grading scale becomes a 2-row table; Important Dates becomes a 2-column table.
4. **PPTX placeholders**: "SUGGESTED VISUAL" guidance moves to speaker notes only; student-visible shapes never contain meta-instructions.
5. **PPTX text**: bullets render complete clauses (workstream 1.3) — no trailing fragments.

### 3. Trust surface honesty (`packageExportVerifier.js` + finish pipeline)

New deterministic content checks, surfaced as warnings in the finish summary and trust strip:

1. Dangling-clause detector (sentences ending in prepositions/conjunctions + period).
2. Leading-colon / empty-label detector.
3. Single-word concept detector (concept equals a bare token of the lesson title).
4. Repeated-phrase density (any 6+-word phrase appearing ≥ 8 times in one document).
5. Uniform quiz answer-key detector across lessons.
6. Empty-section detector.

These run in `verifyPackageExports` so the same gate covers generation, finish, and export.

### 4. Verification

1. Extend `tests/blueprint-quality-matrix.test.js` scenarios with a **sparse-repair fixture** that replicates the audited Climate Justice failure (empty enabled fields filled by deterministic repair) and asserts all language-integrity rules.
2. New focused unit suites for concept extraction, clause completion, short references, quiz rotation, and the new verifier checks.
3. Re-run the audit script logic against freshly compiled output of the four audited course shapes; iterate until clean.
4. Full `npm test` + `test:blueprint:quality:fast` green before release.

## Explicit non-goals (next release)

- **AI enrichment pass for compiled deliverables** (selective model calls for quiz items and key terms when budget allows) — architectural; tracked for v0.8.7 alongside the agent cost roadmap.
- Variable slide-deck length per lesson content.
- Course-map generation prompt changes to reduce sparse maps at the source.

## Definition of done

- Sparse-repair fixture compiles with: zero single-word concepts, zero leading-colon labels, zero dangling clauses, full-title mentions ≤ 4 per document, ≥ 3 distinct quiz answer-key sequences across 7 lessons, zero instructor-voice steps in student sections.
- DOCX exports show headings in the Word navigation pane, footers with page numbers, and real tables for alignment/grading/dates.
- PPTX exports contain no "SUGGESTED VISUAL" text on slide surfaces.
- The new verifier checks fire on the v0.8.6 golden output (proving they catch the audited defects) and stay quiet on v0.8.61 output.
- Unit suite and core blueprint quality matrix green; version bumped; changelog updated.
