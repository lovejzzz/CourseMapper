# v0.15.91 UX Source Relevance Broadening Roadmap

_Written June 28, 2026. Target app version: `0.15.91`._

## Goal

Move CourseMapper closer to honest clean `100/100` exports by fixing the next
UX source-truth gap exposed by a fresh deployed `v0.15.90` ZIP/log audit. The
app and local regrade reported `100/100`, but the trusted source ledger still
contained false friends that only looked relevant because they included words
such as `studio`, `prototype`, or `design`.

## Evidence

The fresh `User Experience Design Studio` package had:

- visible and exported quality: `100/100 (A)`,
- texture: `94/100`,
- trusted `sourceLedger` rows for `National Design Studio`,
  `Le Mans Prototype`, and an architecture-education studio/live-projects paper,
- no P1/P2 findings under the old local grader.

Those rows are not acceptable UX proof. A sports prototype racing-car page, a
White House National Design Studio page, and an architectural education article
cannot count as licensed, trusted, on-topic UX/design-studio sources merely
because their titles overlap generated course concepts.

## Lane 1: Export-Side Quarantine

- Extend the UX false-friend filter to catch the newly observed studio/prototype
  collisions.
- Keep the candidates visible as source review notes instead of trusted
  bibliography proof.
- Preserve valid UX sources when their title, evidence, or concept-specific
  source text has real UX/design research, usability, accessibility, prototype,
  interaction, or portfolio relevance.

## Lane 2: Grader Truth

- Mirror the production quarantine in the deep quality grader.
- Regrade the captured `v0.15.90` package with the stricter rule.
- The same ZIP should project to `97/A` with three P1 citation findings, proving
  the release makes the hidden caveat visible instead of weakening quality
  standards.

## Lane 3: Carry-Forward Quality Work

- Do not claim a clean provider package before a fresh deployed `v0.15.91`
  ZIP/log audit.
- Keep texture work active: the latest real UX run measured texture at `94/100`,
  mainly from repeated lesson-plan scaffolding.
- Keep source work evidence-led across domains; do not tune only for one lucky
  Project Management or UX package.

## Release Boundary

This release is a source relevance and report-truth slice. It does not change
score thresholds, hide findings, loosen source-license rules, or claim clean
`100/100` quality. The next proof must be a fresh deployed provider run that
confirms the false-friend rows are absent from trusted `sourceLedger` proof.
