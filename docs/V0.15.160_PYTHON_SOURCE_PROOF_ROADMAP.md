## Scope

V0.15.160 keeps the patch narrow:

1. Detect Python/Computer Science courses whose provider source proof collapses
   to a single trusted row or CourseIR review fallback.
2. Project licensed OpenStax Introduction to Python Programming section URLs
   into distinct source-ledger rows for concrete Python concepts.
3. Keep each curated source row concept-linked to its own section instead of
   assigning every source every course concept.
4. Preserve the source-truth bridge guard: review-only CourseIR source notes are
   removed only after multiple trusted concept-linked source rows exist.
5. Do not promote metadata-only, unlinked, off-discipline, or vague placeholder
   sources.

## Goal

Turn the known Python `SL1` review-only source fallback into honest, licensed,
concept-linked source proof that can satisfy the local deep grader without
lowering standards.

## Lane

Package export, source-ledger proof recovery, SOURCE_REPORT truth, manifest
truth, and local regrade agreement. This is not a prompt, model, UI, texture, or
grader-threshold change.

## Release Boundary

This release may claim Python source proof recovery is available when provider
proof collapses to review-only CourseIR fallback. It may not claim GPT-5.4-mini,
GPT-5.5-pro, or any deployed package reaches 100/100 until a fresh v0.15.160
ZIP/log audit proves it.

## Verification Target

tests, release-history audit, and normal local gates pass. The next evidence
