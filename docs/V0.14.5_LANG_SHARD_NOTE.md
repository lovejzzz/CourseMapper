# V0.14.5 — Can a `lang` genome shard exist? (F3 feasibility note)

**Question.** Mandarin is the only reference course with no genome shard
(`scripts/crucible/courses.mjs` marks it "no 'lang' shard → not eligible").
Should the foundry build one?

**Recommendation up front: not a Mandarin content shard.** The model path —
the rm romanization contract (v0.14.1), the dialogue contract (v0.14.5 F2),
and the generated pronunciation reference (F1) — is the right architecture
for language COURSE CONTENT. A small **language-pedagogy shard** is the only
genome-shaped piece worth scoping, and it is not committed this release.

## Why a Mandarin content shard fights the genome's shape

The genome is **concept-shaped**: kernels are discipline concepts (~10–25 per
shard) with definitions, misconceptions, corrections, and verbatim-quote
citations into open OER (the foundry's admission gate requires the quote to
appear verbatim in the licensed source — see `scripts/foundry/`).

Language-course content is not concept-shaped:

- **Vocabulary is not a concept inventory.** A first-semester Mandarin course
  teaches 300–600 vocabulary items chosen by the textbook/instructor, not a
  stable cross-course set of ~20 concepts. A shard cannot anticipate which
  items a given syllabus carries; the kernel call that already reads the
  course map can (and does, via keyTerms + rm + dialogue).
- **Grammar points are closer to concept-shaped** (的 possession, 吗
  questions, negation with 不/没, measure words, SVO order) — perhaps 15–25
  per CEFR/ACTFL level. These COULD be kernels. But their teaching value is
  in sequenced, course-specific examples using the course's own vocabulary —
  exactly what a static shard cannot supply and the kernel call already does.
- **Per-language explosion.** A "lang" shard is really a per-language,
  per-level family (Mandarin A1, Japanese A1, Spanish A1…). Each needs its own
  curation and its own quote-verified sources. That is a content-team roadmap,
  not one foundry run.

## What open/CEFR-aligned OER could anchor quotes?

Surveyed for quote-verifiable, license-clean anchors:

- **CC OER textbooks** (the realistic anchors): _Elementary Chinese I/II_
  (CUNY/Brooklyn College, CC BY-NC-SA), _Chinese Grammar Wiki_ (AllSet
  Learning, CC BY-NC-SA), LibreTexts Humanities world-language shelves,
  COERLL (UT Austin) materials — mostly for Spanish/French/Portuguese.
  Usable for verbatim quotes; NC clauses need a posture decision (the
  existing foundry sources are CC BY — NC is a new license tier for us).
- **CEFR Companion Volume (Council of Europe)** — defines proficiency
  descriptors, not teachable content kernels; good for level labels, wrong
  granularity for kernels. ACTFL guidelines are similar and not openly
  licensed for quote reuse.
- **HSK/TOCFL vocabulary lists** — word lists, not kernels; no definitions,
  misconceptions, or pedagogy to quote.

So sources exist for a grammar-point shard, but the payoff is low: the
kernels would duplicate what the per-course kernel call already writes, with
less course fit.

## The piece that IS genome-shaped: language pedagogy

A small **`language-pedagogy` shard** (one shard, not per language) fits the
genome exactly the way `pedagogyEvidence` (V0.13.5 P3) fits lesson plans:
concepts like _comprehensible input_, _spaced repetition for vocabulary_,
_tone perception before production_, _interleaved character practice_, the
_interpretive/interpersonal/presentational modes_. ~8–12 concepts, stable
across languages, quotable from open SLA literature (DOI-backed, same shape
as the existing evidence base). It would let the prerequisite-judgment and
"why this works" surfaces cite real SLA research on language courses instead
of staying generic.

## Decision

1. **No Mandarin/lang content shard** — vocabulary and grammar kernels are
   course-specific; the rm + dialogue + pronunciation-reference architecture
   (model-authored within existing call budgets, deterministically rendered)
   is the right path and is now shipped end to end.
2. **Defer a `language-pedagogy` shard** to a future foundry run (8–12
   concepts, open SLA sources, standard admission gate). Scope it only after
   a live language round shows the generic pedagogy citations are a real
   quality gap — not before.
3. Revisit a grammar-point shard only if (2) ships and live rounds still show
   grammar-explanation defects the kernel call cannot fix.
