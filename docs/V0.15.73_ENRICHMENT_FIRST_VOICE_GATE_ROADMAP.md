# v0.15.73 Enrichment-First Voice Gate Roadmap

_Written June 27, 2026. Target app version: `0.15.73`._

## Evidence

The latest completed ZIP/log audit is still the deployed v0.15.71 Project
Management package. It regraded at `95/100`, with package texture `93`, local
texture `92`, partial enrichment `10/12`, and one readiness blocker. v0.15.72
fixed the Study Guide prompt-artifact leak and premature Course Map tick from
that run, but a fresh deployed v0.15.72 package has not yet proved a clean
score.

The same v0.15.71 log showed the model did spend one native recovery call for
lessons 11 and 12, but the package still exported with those lessons on template
fallback and then ran the optional voice pass. That makes the next CourseMapper
side issue priority ordering: incomplete lesson kernels must stay the dominant
quality caveat, and optional texture polish should not run as if coverage were
complete.

## Lane

Product quality and pipeline truth. Keep package generation focused on complete
lesson coverage before optional texture polish, without weakening the grader or
claiming a clean deployed score.

## Scope

- Compute the enrichment coverage gap from the structured enrichment outcome.
- Skip the in-pipeline voice pass when enrichment covered fewer than all
  requested lessons.
- Record a pipeline decision explaining the exact coverage gap and why voice
  polish was deferred.
- Keep the existing readiness blocker and grader standards intact.

## Non-Goals

- Do not claim a `100/100` package before a fresh deployed v0.15.73 ZIP/log
  audit.
- Do not weaken source, enrichment, texture, or export grading thresholds.
- Do not hide partial enrichment behind friendlier package UI.
- Do not disable the voice pass for fully enriched packages.

## Release Boundary

In scope:

- In-pipeline voice-pass gating for partial enrichment coverage.
- Pipeline decision logging for skipped polish when lesson kernels are missing.
- Focused regression coverage for enrichment-first ordering.

Out of scope:

- New provider calls or broader retry architecture.
- Source-ledger trust changes.
- Texture threshold changes.
- UI redesign of the export panel or agent panel.
