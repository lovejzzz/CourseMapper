## Goal

Prevent objective-shaped Python assessment prose from becoming a repeated
student-facing artifact label across assignments, discussions, rubrics, and
filenames. If CourseMapper has enough domain evidence to recognize the phrase,
it should compact it before compilation and repair any repeated rendered-text
shingles that survive into the deterministic content-quality pass.

## Lane

Assessment-label compiler and export content-quality repair. This is not a
grader weakening, score inflation, model upgrade, source-ledger relaxation, or
UI-only change.

## Release Boundary

This release may claim a deterministic CourseMapper-side repair for the
v0.15.170 repeated Python assessment shingle blocker. It may not claim a clean
v0.15.171 package until a fresh deployed GPT-5.4-mini ZIP/log audit proves the
package exports honestly, the repeated assignment/discussion shingle is gone,
and source/genome caveats remain truthfully reported.

## V0.15.171 Scope

- Compact objective-shaped Python assessment labels such as
  `Analyze file processing code for line-by-line...` into short artifact labels
  such as `File-processing code trace` before they fan out through compiled
  deliverables.
- Detect repeated 8-word rendered-text shingles in the deterministic
  content-quality repair pass.
- Replace excess programming-oriented repeated shingles with varied
  lesson-appropriate alternatives before DOCX/PPTX export verification.
- Preserve raw course-map objective text in provenance/source-trace fields so
  repair does not hide what the model supplied.
- Add focused regressions using the exact repeated GPT output shape.

## Why This Is CourseMapper-side

A stronger model may avoid repeating the phrase, but CourseMapper already sees
the course domain, lesson objective, assessment text, and rendered export body.
Once an objective-shaped label repeats 12 times inside one Office section,
waiting for a better model is not enough: the compiler/export pipeline should
compact and repair the known pattern before a user sees a blocked package.
