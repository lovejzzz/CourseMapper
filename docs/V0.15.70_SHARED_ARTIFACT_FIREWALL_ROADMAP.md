# v0.15.70 Shared Artifact Firewall Roadmap

_Written June 26, 2026. Target app version: `0.15.70`._

## Evidence

Recent Project Management ZIP/log audits have improved from the earlier prompt
artifact failures, but the quality bar is still not `100/100`. The latest
available full audit evidence remains `97/100` with texture `90/100`, partial
enrichment, source-license caveats, and a PPTX echo finding.

The safe next slice is not to lower the grader. It is to keep prompt artifact
labels and source placeholder language from entering compiled student-facing
materials through shared lesson metadata. The focused regression recreates a
bad Project Management course map where prompt labels such as `scenario
quizzes`, `rubric-driven assignments`, `final capstone presentation`, `Study
Guides`, and instructor-approved reading boilerplate are present in raw CourseIR
fields.

## Lane

Compiler/product quality. This release extends the prompt-artifact firewall
across shared lesson helpers and compiled custom outputs so a bad raw label
does not become a course concept, artifact, reading cue, discussion source
locator, quiz tag, or Study Guide term.

## Changes

1. Widen shared concept/artifact safety.
   - Discussion prompts, follow-ups, criteria, facilitation tips, response
     stems, tags, and artifact sets now use safe lesson concepts and artifacts.
   - Quiz-bank metadata and review-week atoms now use the same safe concept,
     artifact, transfer, and evidence-cue helpers.

2. Keep Study Guide enrichment terms clean.
   - Enriched Study Guide key terms that are actually prompt artifact labels are
     dropped before rendering.
   - Misconception rows derived from unsafe enriched term names are dropped.

3. Sanitize source-grounding extras.
   - `lessonSourceGrounding(..., extras)` now sanitizes extra fields before
     spreading them into the deliverable-facing object.
   - Discussion source-artifact locators and compiled custom reading responses
     now use safe evidence cues instead of raw reading/source placeholders.

4. Pin the live failure shape.
   - The focused regression compiles Study Guides, discussions, quiz bank,
     weekly reflection, and reading response outputs from one polluted Project
     Management lesson.
   - It asserts the prompt labels are absent while safe Project Management
     concepts and source-evidence language remain.

## Non-Goals

- This release does not claim deployed packages now regrade `100/100`.
- It does not weaken the grader, hide source-license findings, or relax texture
  evidence.
- It does not solve partial enrichment coverage, source-ledger trust, or the
  remaining PPTX echo warning by itself.

## Release Boundary

In scope:

- Keep prompt artifact labels out of compiled Study Guides, discussions,
  quiz-bank metadata, and compiled custom reading/reflection outputs.
- Sanitize source-grounding extras and discussion source locators before they
  reach deliverable-facing JSON.
- Preserve safe Project Management concepts and source-evidence language when
  unsafe labels are removed.

Out of scope:

- Claiming v0.15.70 reaches `100/100` before a fresh deployed ZIP/log audit.
- Weakening source-license, enrichment-coverage, texture, or export warnings.
- Spending another provider generation solely to reconfirm the pre-release
  v0.15.66/v0.15.69 evidence.
