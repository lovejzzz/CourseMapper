# V0.15.122 Lesson Plan Artifact Firewall Roadmap

## Goal

Remove the lesson-plan scaffold leakage exposed by the fresh deployed
v0.15.121 User Experience Design Studio ZIP/log audit without weakening the
quality grader.

## Evidence

- App version: `0.15.121`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T073919Z-v015121-ux-fresh`
- Visible package result: `Quality 74`, `Texture 92`
- Embedded and local current-rule regrade finding:
  `prompt artifact labels used as lesson concepts`
- Evidence excerpt:
  `Students draft the Week 4 assignment; the bar is precise use of usability testing — A method for evaluating how easily people can complete tasks with a product or prototype. Grouping: Quiet build time`
- Source proof recovery worked in this run: `SOURCE_REPORT.md` included trusted,
  licensed, concept-linked UX source rows and citations scored `100/100`.

## Lane

1. Lesson-plan artifact firewall
   - Treat `Week N assignment` as the same unsafe scaffold family as
     `Week N artifact`.
   - Catch short inserted variants such as `Week N lab work` before they reach
     exported lesson-plan prose.
   - Apply the replacement after language finalization too, because stale
     modality text can re-enter the finished plan there.

2. Student-facing workshop prose
   - Replace the dictionary-style `precise use of <term> — <definition>`
     workshop line with a revision instruction that asks students to use the
     concept to justify a visible decision.
   - Remove the internal `Artifact revision block` activity label from the
     lesson-plan variant pool.

3. DOCX outline wording
   - Render lesson-plan grouping metadata as `Class format:` in Word exports
     instead of the internal `Grouping:` label.

## Release Boundary

- This release fixes the observed v0.15.121 P0 lesson-plan scaffold leakage.
- This release does not weaken prompt-artifact grading, source grading, texture
  grading, or package scoring.
- This release does not claim clean provider output until a fresh deployed
  v0.15.122 ZIP/log audit proves the fix in real generated UX output.
