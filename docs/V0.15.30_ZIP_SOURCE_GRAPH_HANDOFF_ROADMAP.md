# v0.15.30 ZIP Source Graph Handoff Roadmap

## Goal

Make the downloaded ZIP grade the same source-proof package that the finish
badge grades. A package that has graph-backed source proof should keep that
proof through final download; a package without proof should receive the same
honest source-proof finding everywhere.

## Lane

Package export truth, source-ledger handoff, and UI/package quality parity.
This is a narrow wiring fix for the canonical ZIP export path, not a new
research-provider or source-entailment slice.

## Why This Exists

A fresh deployed v0.15.29 EduTool.dev Sociology package showed real progress:
fake fallback source rows no longer shipped. The remaining failure was a
handoff mismatch. The finish pass graded with `courseGraph`, while the final
header/side-panel ZIP download omitted that graph. That made the package lose
its source-ledger context only at download time.

Audit evidence:

- Run: `run-1781950003568`, generated on deployed v0.15.29.
- ZIP: `verification-output/edutool-audit-loop/20260620T100411Z/Introduction to Sociology - Course Materials (5).zip`.
- Live finish trace: `quality_grade_done` reported 99/A for
  `finish-mqm755gz-xnjom`.
- Downloaded ZIP: `PACKAGE_MANIFEST.json` and local regrade reported 98/A with
  a P1 source-proof finding because `sourceLedger`, `sourceLedgerSummary`,
  `sourceReport`, and `courseIR` were absent.
- Local regrade proof:
  `verification-output/edutool-audit-loop/20260620T100411Z/local-regrade-report.md`.

## Release Boundary

This release does not weaken the source-ledger grader and does not invent
source rows from digest text. It makes the final package assembly receive the
same graph-backed proof that the finalizer already used.

## Slice

1. Add `courseGraph` as an explicit `ExportSidePanel` prop.
2. Pass AppFlow's live `courseGraph` into the export panel.
3. Include `courseGraph` in the `downloadCourseMaterialsZip` options for the
   all-package ZIP path.
4. Keep the header CTA event bridge routed through the export panel's single
   guarded download executor.
5. Add focused regression coverage for the one-verb header ZIP path and graph
   handoff.

## Non-Goals

- Do not change provider-call routing or generation cost.
- Do not fabricate source proof when the CourseGraph lacks real source rows.
- Do not change quality scoring weights.
- Do not complete semantic source-entailment checks.

- The ZIP download path passes `courseGraph` to package assembly.
- Header and side-panel ZIP downloads share that same graph-backed export path.
