# V0.15.124 Slide Note Texture Rotation Roadmap

## Goal

Reduce the remaining scored texture loss from the fresh deployed v0.15.123 User
Experience Design Studio ZIP/log audit without weakening source truth, export
verification, accessibility notes, or the deep quality grader.

## Evidence

- App version: `0.15.123`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T093445Z-v015123-ux-fresh`
- Visible and local package result: `99/100 (A)`
- P findings: `0 P0`, `0 P1`, `0 P2`
- Clean gates: export passed, enrichment coverage `1`, no export warnings, and
  the source report lists trusted, licensed, URL-backed, concept-linked rows.
- Remaining scored loss: Texture `92/100`
- Dominant repeated shingles:
  - `instructor visual note ... constraint map ...`
  - `accessibility note learning-thread timeline ...`
  - `accessibility note misconception vote-and-reveal ...`
  - `after ... use responses to identify review needs before the week ...`

## Diagnosis

The fresh v0.15.123 audit shows the hard correctness surfaces are clean. The
remaining point loss is concentrated in deterministic scaffolding we add during
compilation and PPTX export, especially speaker-note labels and visual
descriptor phrases repeated across all 12 lesson decks.

The model can help vary prose, but it cannot fix fixed strings that CourseMapper
injects after provider generation. This release therefore targets CourseMapper
owned texture without hiding quality evidence or lowering the score bar.

## Lane

1. Compiler visual descriptor rotation
   - Keep visual kind, evidence use, artifact connection, and accessibility
     purpose.
   - Rotate the description and alt-text sentence shape by lesson so every deck
     does not share the same tail.

2. PPTX speaker-note label rotation
   - Keep visual guidance in speaker notes and off student-facing slides.
   - Rotate clean visual-note labels and accessibility-note labels
     deterministically by deck/slide.
   - Preserve instructor-readable visual kind in notes without repeating
     `kind: kind ...` phrasing.

3. Regression coverage
   - Keep raw scaffold labels (`SUGGESTED VISUAL`, `ALT TEXT`,
     `Visual guidance`, `Accessibility description`) blocked.
   - Prove varied labels appear across a visual-heavy exported deck.

## Release Boundary

- This release targets the observed slide-deck texture loss from v0.15.123.
- This release does not weaken source grading, texture grading, report truth,
  export verification, or package scoring.
- This release does not claim clean provider output until a fresh deployed
  v0.15.124 ZIP/log audit proves Texture reaches `100/100` and every exported
  surface agrees.
