## Scope

V0.15.156 keeps the release narrow:

1. Replace the final generic `closing evidence check` fallback with artifact
   review language.
2. Replace the generic `Instructor-approved source` resource fallback with
   source-excerpt/activity-prompt language.
3. Keep the existing CS/Python, UX, Project Management, and history-specific
   fallback branches unchanged.
4. Extend the texture regression so generic Course Map fallback repair fails if
   the old evidence-check or instructor-approved-source scaffolds return.

## Goal

Reduce repeated fallback scaffolding before it reaches compiled deliverables, so
models with safe but repetitive prose do not get amplified into package-wide
texture loss.

## Lane

Course Map readiness and deterministic texture repair. This is not a scoring
threshold change, provider prompt change, source-trust broadening, or a new
provider-score claim.

## Release Boundary

This release may claim the generic fallback branch no longer emits the named
evidence-check and instructor-approved-source scaffolds under focused regression
coverage. It may not claim the latest deployed GPT-5.5-pro output reaches
100/100 until a fresh funded v0.15.156 ZIP/log audit proves it.

## Verification Target

normal local gates pass. The next evidence step is a fresh deployed v0.15.156
