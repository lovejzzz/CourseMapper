# Composer Roadmap v0.2.3 — Repair Is Reselection

_July 4, 2026. Input: E7's ledger. The Composer hit a 9 [9,9] panel but
paid $0.222 doing it — and $0.175 of that was the REPAIR loop rewriting
provenance-gated content with a mini model, when the library holds
shelf siblings that could swap in for $0. With a library, repair is a
selection problem, not a generation problem._

## 1 · Reselection before repair (the headline)

- **Finding:** E7 repair = 16 calls, $0.175, 79% of run cost — model
  rewrites of composed quiz sections whose defects are combination
  artifacts (this set of banked items in this lesson), not content
  defects.
- **Fix:** a composer-only pre-repair pass: for each lesson whose
  blocking findings are quiz-class (J1/J3/J3b/J11/J12/J13), redraw the
  quiz from the shelf (exposure counters make the redraw differ),
  remap per-item claims, re-run the checks, keep the redraw only if
  the lesson's blocking count drops — else revert. One attempt per
  lesson, fully deterministic, $0. Model repair then handles only what
  reselection couldn't.
- **Exit bars:** E7-class LA run at ≤$0.10 total with repair stage
  ≤$0.05; battery within the LA band (0.428–0.498); panel within 0.5
  of E7's 9.
