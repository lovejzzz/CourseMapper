# EDUTOOL v0.18.6 — Warning-Free, Recovery-Safe Output

## Goal

Finish a normal course build without turning one recoverable source gap into nine
failed material families, and make every remaining warning describe a real
actionable defect.

## Signed recovery before compilation

Evidence-only blockers now enter a narrow recovery authorization inside the
signed instructional intent graph before strict blueprint admission. The
authorization is available only when every blocker is an exact lesson-scoped
`evidence-acquisition-required` condition and the predecessor receipt is valid.
Affected lessons can use curriculum-owned objectives, source labels, and a
compiler-created practice record. Model-provisional subject matter remains
quarantined. Mixed blockers, stale receipts, and unrelated planning failures
still stop the build.

## Export and copy quality

DOCX exports keep list semantics in native Word numbering structures. Compact
labels and long bibliography rows use em-dash separators instead of literal
bullet glyphs. Assignment requirements and activity-readiness notes carry
lesson identity so the same long paragraph is not stamped across a course.
Objective and success-criteria rendering now handles `inspect` objectives,
hyphenated check-in labels, and concepts that begin with an article without
creating false dangling-clause or article-collision warnings.

## Diagnostic quality

The browser runtime suppresses only five pinned informational llama.cpp startup
messages. Unknown warnings and all errors remain visible. Node 25 unit and
export-audit processes remove only the unconfigured experimental Web Storage
accessors before dependencies probe them, eliminating verification noise
without hiding application failures.

The deterministic evidence score also keeps its measurement boundary visible
without turning unobserved score potential into a package warning. A package
with no encoded findings can finish `Ready to export`; the quality report still
states exactly which evidence the automated grader did not observe.

## Lane

The release requires formatting, lint, unit, production build, bundle, release
history, texture, gold-sample, browser, and physical ZIP checks. The export
torture matrix spans 34 courses, 8–14 lessons, 29 modalities, and more than
2,600 files; release acceptance requires zero blockers and zero warnings.

## Release Boundary

V0.18.6 is a locally verified predeploy candidate until the exact pushed commit
passes remote CI. Automated compilation and export proof do not certify factual
accuracy, accessibility, instructor approval, classroom outcomes, or the
official institution-specific policies that a teacher must confirm before
publishing.
