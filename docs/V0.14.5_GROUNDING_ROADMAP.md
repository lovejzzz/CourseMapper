# V0.14.5 Roadmap — Grounding: the instructor's own materials, the model's own structure

**Source analysis:** the v0.14.3 Quality Surface work. With the badge, the
10-course net, the depth slice, and a grader that regression-checks itself
against its own history, the _defect_ frontier is effectively closed — four
straight 100s, eleven live-only bugs fixed, fusion retired on the registry
path the same day the matrix falsified its dead-branch hypothesis. What
remains is the _authenticity_ frontier, and it has two faces:

1. **The course doesn't speak with the instructor's materials.** World Lit
   only names real texts because the course prompt names them; an uploaded
   syllabus that says "Things Fall Apart, Weeks 8–9" loses that fact into
   prose atoms. Readings are retrieved (OpenAlex/OpenLibrary), never
   _inherited_ — yet the instructor already told us what the course reads.
2. **The model still authors prose that code re-parses.** The V0.13 thesis
   ("the course map is a lossy serialization between two structured
   representations") was implemented for rendering and identity, but the
   authoring contract — the model emitting typed graph entities natively —
   stayed deferred behind a gate that no longer exists: "needs side-by-side
   live proof" was expensive in March; the Crucible runs it for ~$0.25.

**Thesis:** v0.14.5 grounds the package in two directions at once. Downward
into the instructor's reality: named readings become first-class registry
entities that every deliverable inherits verbatim, with retrieval demoted to
_supplement_. Upward into the model's reality: the native graph-authoring
contract (Pass A/B) finally ships behind a flag, proven by side-by-side
Crucible rounds, cutting cold-course cost ~25–35% and wall-clock toward
60–90s. Around them: the deck visual layer renders the descriptors we
already author, the compiler diet continues into the falsified branches'
rewires, and the Crucible learns to test providers we don't default to.

**Carried in from v0.14.3 (inherit-if-not-landed):** E7 `--judge` advisory
flag; the B4 nightly cron enablement (still pending the user's repo-secret
decision); C3 deletion of any branch the extended live round certifies dead.

**Target (acceptance):**

- An uploaded syllabus naming ≥3 readings yields a readings registry; the
  named texts appear verbatim in the course map resources, weekly readings,
  briefs, and discussion prompts of their weeks; OpenAlex attaches only to
  weeks with empty slots; the grader's named-reading penetration check
  passes on a live round with a readings-bearing syllabus fixture.
- A side-by-side Crucible round (same four reference courses, prose path vs
  native path) shows: native scores within 2 points, zero new P0/P1 classes,
  measured cost reduction ≥20%, wall-clock ≤90s median — twice in a row
  before the flag defaults on.
- Every enriched deck renders ≥1 native visual (concept-map shapes or a
  worked-example chart) with zero overflow findings; the visual is drawn
  from existing descriptor data (no new AI calls).
- Compiler diet phase 2: the kind-inference rekey retires the 19-regex
  ARTIFACT_KIND scan on the registry path; total phase-1+2 deletion
  measured and reported; golden harness green throughout.
- One full Crucible round each on Anthropic and Google models completes
  with graded reports (pass bar: no P0; documented deltas are findings, not
  failures — provider drift is what we're measuring).

**Principle:** unchanged, plus one addition: **what the instructor already
said outranks what we can retrieve.** Provenance order is instructor-named →
genome-cited → retrieved-open → nothing; a lower tier may never displace a
higher one.

## WS-A — The readings registry: inherit, don't retrieve (flagship)

**A1. Extraction.** The course-map model call already reads the full
syllabus; it loses named works because nothing asks for them. Extend the
lean contract (prompts.js lean rules + wire format) with an optional
per-section `readings` array: verbatim titles/authors AS NAMED in the
source ("Things Fall Apart", "OpenStax Ch. 4: Cell Structure", "course
packet pp. 12–30"), with a hard traceability rule (never invent; omit when
the syllabus names nothing). Parse into `graph.readings` entities
`{ id: "R8.1", title, author?, kind: book|chapter|article|packet|media,
sourceText, sessionRefs }` in deriveFromCourseMap, mirroring the assessment
registry pattern (ids, dueSession-style refs, no nested arrays — the
Firestore rule).

**A2. Inheritance.** Every surface that renders readings consumes the
registry verbatim: course-map supportingResources cells, the syllabus
week-schedule readings column, lesson-plan MATERIALS, brief "assigned
reading" references, discussion prompts ("anchor your post in <named
text>"). The compiler's existing materials builders switch source order:
registry first, genome citations second, retrieval third (the provenance
principle). Names render verbatim — the fusion lesson applies: no label
surgery on instructor-named titles.

**A3. Instructor uploads (metadata only).** The app already parses docx
(mammoth) and pdf (pdfjs) on landing. Add an optional "reading list" upload
slot in the existing source-files flow: parsed text goes through the same
extraction contract (one focused low-reasoning call when a reading-list
file is present), merging into `graph.readings` flagged
`instructorProvided: true`. Copyright posture: metadata and instructor-held
references only — we never ingest or reproduce text content of the works
themselves, and the Sources & Licenses appendix marks instructor-provided
entries as "course-assigned (instructor)".

**A4. Retrieval demotion.** readingListEngine attaches OpenAlex/OpenLibrary
ONLY to sessions whose registry slot is empty; when a registry entry names
a book, the OpenLibrary metadata lookup may ENRICH it (ISBN/edition/link)
but never replace its title; relevance-gate rejections already log — add
"slot filled by instructor reading" to the decision vocabulary.

**A5. Receipts.** Grader: named-reading penetration (each registry reading
appears in its week's lesson-plan materials AND the syllabus schedule —
P1 per missing surface); provenance-order check (no retrieved item renders
above an instructor-named one in the same week). Crucible: a new fixture
course whose PROMPT carries an explicit reading list per week (the named
texts the audit found missing — World Lit's actual canon), asserting
end-to-end inheritance live. PACKAGE_MANIFEST gains `readings[]` with
provenance tags.

## WS-B — Native graph authoring (Pass A/B), proven by the Crucible

The V0.13 deferred contract, now affordable to prove. Flag-gated end to end;
the prose path remains default until the acceptance bar is met twice.

**B1. Pass A — extraction.** One low-reasoning call: syllabus → typed
skeleton (sessions with titles/ordering, course goals, named readings (WS-A
shares this), assessment atoms with kinds) emitted as entity JSON with ids,
not spreadsheet prose. Schema = the existing CourseGraph wire shape; the
degraded-plan guard applies (v0.12.1 lesson: a malformed plan must fail
loudly, never silently disable).

**B2. Pass B — parallel authorship.** Per-lesson (batched 4–5, parallel)
calls authoring outcomes + kernel content directly onto Pass A's entity ids,
absorbing today's separate enrichment calls. Wall-clock: the v0.13.1
finding (3 sequential kernel calls ≈ 90s of "finishing") becomes ~30s
parallel. Lessons with genome coverage skip Pass B per the existing
augment/displace rules.

**B3. The side-by-side proof.** Crucible `--authoring native|prose` flag;
the acceptance round runs the four reference courses BOTH ways in one
invocation, the round report rendering paired columns (score, cost from
digests, wall-clock, kernel-coverage). Gate to flip the default: native
within 2 points on every course, zero new P0/P1 classes, cost −20% or
better, two consecutive clean rounds on different days. The golden
equivalence harness gains a third fixture pair (native-authored graph →
render → derive round-trip).

**B4. Entity-id stability.** Ids persist across re-derivation after map
edits (today they churn; undo stays cell-level because of it). Stable-id
matching by (lessonNumber, normalized title) with a documented merge rule;
the registry/readings ids inherit the same stability. This is what makes
agent edits and smart-sync truly free on the graph.

## WS-C — The deck visual layer (deterministic rendering of what we already author)

**C1. Concept-map shapes.** The hub/spokes descriptor (v0.13.3) renders as
text today. pptxgenjs supports shapes/connectors: render hub + ≤6 spokes as
real ellipses/lines on the keyTerm slide, theme-colored, fixed layout grid
(no auto-layout adventures — deterministic positions by spoke count).

**C2. Worked-example charts.** Quantitative kernels with numeric worked
examples (Kepler, kcal, cardiac output, regression) gain a small native
bar/line chart (pptxgenjs charts) when the workedExample carries plottable
pairs — a `wePlot` descriptor derived at compile time from the existing
worked-example fields; absent data → no chart, never a fabricated one.

**C3. Visual QA.** Extend the PPTX audit + grader: every enriched deck ≥1
native visual; shape/text overflow detection (bounding boxes vs slide
dims); the existing a:ea/font gates apply to shape text. Bundle note: chart
support may grow the pptxExporter chunk — measure, budget, document
(the WS-A v0.14.3 discipline).

## WS-D — Compiler diet, phase 2 (the falsified branches, rewired)

**D1. Kind-inference rekey.** The load-bearing finalizer noun ("quiz",
"memo") derives from registry kind + title head-noun on the registry path,
retiring the 19-regex ARTIFACT_KIND scan there (legacy keeps it). The
phase-1 telemetry stays armed to prove the regex path quiet post-rekey.

**D2. Strategy-label retirement.** Where the v0.14.3 extended round shows
`quiz-strategy-label-match` winning for cases an outcome-id key would
resolve, rekey those call sites; measure the residue.

**D3. The legacy-path question.** Phase-1 data shows the matrix-core legacy
class is the only consumer of several branch families. Scope (do not yet
execute) the endgame: complete the V0.13 P5 migration so map-only projects
derive a graph ON OPEN unconditionally, making the legacy compile path
itself deletable — the largest single deletion available (~3–5k lines).
Deliverable this release: a one-page feasibility note with telemetry from
real usage, not the deletion itself.

## WS-E — Provider breadth in the Crucible

**E1. `--provider anthropic|google`** rounds through the same harness (the
app's provider switch is config; the driver sets it in the seeded
localStorage). One reference round per provider, graded normally; deltas
are FINDINGS (provider drift documentation), only P0s gate. The v0.13.1
json_object lesson is the motivating bug class: provider-specific contract
breaks that fixtures never see.

**E2. Judge flag** (inherits E7 if v0.14.3 ships without it): advisory LLM
taste pass, off by default, never gates.

**E3. Drift ledger.** Provider-specific findings enter the verdict ledger
namespaced by provider, so `--calibrate` distinguishes "Anthropic renders
shorter bullets" (documented drift) from regression.

## WS-F — Language depth, the deterministic slice

**F1. Pinyin/tone reference chart**: language-genre Required Assets gains a
generated reference md (tone marks, the lesson vocabulary table with
hanzi+rm from the kernels — data we already have).
**F2. Dialogue scripts**: extend the language-course kernel contract with an
optional `dialogue` field (4–6 turns using the lesson's vocabulary; the rm
recovery mechanism applies), rendered into lesson plans (practice block)
and study guides. Model-authored within existing call budgets (rides the
enrichment call, like rm).
**F3. Lang shard feasibility**: a foundry research note on CEFR-aligned
open language OER (no shard committed this release).

Cost model: A and C are deterministic or ride existing calls; B _reduces_
cost (the point); E adds ~$0.40–0.60 per provider proof round; F2 rides the
enrichment call. Per-course cost stays ≤$0.15 on the prose path and drops
on the native path.

Release protocol: the v0.14.2/3 discipline — full battery + an extended
Crucible round (now including the readings-fixture course and, for B, the
side-by-side) + deep-read before tag.
