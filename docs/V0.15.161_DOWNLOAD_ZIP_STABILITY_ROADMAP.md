# V0.15.161 Download ZIP Stability Roadmap

## Evidence

- Fresh deployed v0.15.160 GPT-5.4-mini Python run: `run-1782837191351`, `finish-mr0vedho-8u5xm`.
- Visible workspace state: Quality 100/A, Texture 95, 15 lessons, Materials 15/15, Genome 9/15, Judgment 3 gaps, Ready in 281s, $0.12.
- Console digest: zero blockers, zero warnings, zero retries, export verifier passed 38 checks, quality P0/P1/P2 all zero.
- User-facing failure: both header and package-panel Download ZIP clicks made the Chrome tab unresponsive and did not create a newer `Introduction to Computer Science with Python - Course Materials*.zip` file in Downloads.

## Goal

Make the finished-package Download ZIP action complete reliably for full-course
packages that already passed finish verification and grading.

## Lane

Browser export runtime, package ZIP assembly, finish-pass quality report reuse,
and user-facing download stability. This is not a grader-threshold, prompt,
model, or content-quality scoring change.

## Release Boundary

This release may claim the Download ZIP path avoids avoidable repeat grading and
outer ZIP recompression. It may not claim a completed clean v0.15.161 ZIP/local
regrade until a fresh deployed GPT-5.4-mini run downloads successfully.

## Product Diagnosis

The Download ZIP button was not just saving an already-finished package. It rebuilt the package, re-ran package quality assembly when a finish-pass grade already existed, and then DEFLATE-compressed an outer ZIP containing Office files that are already compressed archives. On full-course outputs, that placed avoidable CPU work on the browser main thread at the exact moment the user expected an immediate download.

## V0.15.161 Scope

- Reuse the verified finish-pass quality result when building the downloadable ZIP after package finish.
- Embed that precomputed grade into `PACKAGE_MANIFEST.json` and `QUALITY_REPORT.md` so export truth remains visible.
- Keep local regrade standards unchanged: auditors can still grade the actual ZIP bytes after download.
- Store the outer course-materials ZIP without DEFLATE recompression to avoid double-compressing `.docx`, `.pptx`, and `.xlsx` files.
- Keep GPT-5.4-mini as the default provider audit model; use GPT-5.5-pro only for occasional controlled model-comparison checks.
