## Goal

thin on GPT-5.4-mini, but CourseMapper's deterministic repair layer should not stamp long repeated
Course Map review sentences across a two-section, twelve-lesson package.

## Lane

change, or model upgrade.

## V0.15.177 Scope

- Replace repeated Python evaluate-design fallback templates with varied code-trace, rerun,
  edge-case, rubric, peer-review, and transfer-check patterns.
- Add a regression for a twelve-lesson, two-section Python course that fails if fallback repair
  duplicates the long scaffolds observed in v0.15.176.
- Preserve the existing strict texture and source standards.

## Why This Is CourseMapper-side

The provider produced a package that needed fallback repair, but the repeated text observed in the
Course Map came from CourseMapper's own fallback template pool. That makes this a deterministic
compiler/product fix rather than a model-only issue.
