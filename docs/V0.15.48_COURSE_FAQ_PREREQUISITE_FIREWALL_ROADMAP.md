# v0.15.48 Course FAQ Prerequisite Firewall Roadmap

_Written June 26, 2026. App version: `0.15.48`._

## Goal

Stop CourseIR prerequisite bookkeeping labels from appearing as student-facing
Course FAQ source evidence.

## Lane

Compiler/export truth for Course FAQ text. This patch does not change source
retrieval, source scoring, package grading thresholds, or provider behavior.

## Release Boundary

In scope:

- treat CourseIR `Prerequisite concept` labels as unsafe internal source cues
  for Course FAQ answers,
- keep existing source-review and artifact-label firewalls intact,
- add a focused regression for the Project Management leak shape,
- restore local verification by rebuilding the damaged dependency install.

Out of scope:

- changing source-ledger/research retrieval,
- claiming the v0.15.47 Project Management package now regrades differently,
- fixing the remaining Lesson 10 study-guide kernel-coverage P1,
- changing PPTX repeated-phrase handling,
- weakening the deep quality grader.

## Evidence

The v0.15.47 Project Management audit saved under
`verification-output/edutool-audit-loop/20260625T211628Z/` regraded the
package at `97/100` with two P1 findings. The Course FAQ P1 cited:

- file: `Course FAQ/Lesson 03 - Scheduling - Course FAQ.docx`,
- evidence: `scheduling lab 2. scenario quizzes. Strong work uses Prerequisite concept: 2.1:`.

That phrase is not a source students can inspect. It is CourseIR prerequisite
metadata that should guide readiness planning, not a Course FAQ evidence cue.

The first kicked-off automation pass also found the local verification blocker
was not a product-code failure: `node_modules` had been left incomplete after
the previous low-disk state. Rebuilding dependencies restored bounded Vitest
execution.

## Fix

Course FAQ source-cue selection now treats `Prerequisite concept` the same way
it already treats `Existing course map fields`, source-review rows, and other
internal placeholders. When a CourseIR prerequisite label appears in
`throughlineCase.evidencePacket`, `evidencePlan.sourceCue`, readings, resources,
or an anchor contrast, the FAQ compiler falls back to safe lesson source
evidence instead of rendering the internal label.

The regression recreates the leaked Project Management shape:

- scheduling lesson,
- `Scheduling lab 2. scenario quizzes`,
- `Prerequisite concept: 2.1: Requirements`,
- unsafe anchor contrast beginning with `Strong work uses ...`.

The compiled FAQ must not contain `Prerequisite concept` or `Strong work uses
Prerequisite`, and must still retain a source-evidence cue.

## Verification

Focused verification covers:

- the new prerequisite-label Course FAQ regression,
- the existing prompt-artifact and source-review Course FAQ firewall group,
- CourseIR projection behavior that still records prerequisite metadata for
  compiler planning.

The release gate uses targeted Vitest coverage plus the normal format, lint,
test, smoke-quality, build, bundle, and release-history checks. A fresh
EduTool.dev provider generation should resume only after this release deploys.
