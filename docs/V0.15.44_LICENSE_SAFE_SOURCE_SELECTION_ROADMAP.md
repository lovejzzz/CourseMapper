# v0.15.44 License-Safe Source Selection Roadmap

_Written June 20, 2026. App version: `0.15.44`._

## Goal

Reduce avoidable source-license ambiguity in generated teaching packages without
inventing licenses, hiding findings, or weakening the source-ledger grader.

## Lane

Retrieval and source-selection policy. This lane changes which retrieved rows
are preferred before compilation. It does not relabel generic `open access`
metadata as Creative Commons, and it does not change grader scoring.

## Release Boundary

In scope: preserve OpenAlex best-OA license/URL metadata when available, prefer
explicit-license sources over ambiguous-license sources after topical gates pass,
ask secondary providers for license-safe alternatives when primary hits are only
ambiguous, and stop promoting unsolicited OpenLibrary course-book metadata into
trusted source proof.

Out of scope: claiming all OpenAlex rows are reuse-safe, removing license review
findings, changing CourseIR sourceRef bridge behavior, or proving the next live
EduTool.dev package reaches 100/100 before it is deployed and audited.

## Fix

The provider layer now selects richer OpenAlex metadata:

1. request `best_oa_location` alongside `primary_location`,
2. prefer best-OA PDF/landing URL before generic OA URL,
3. prefer best-OA license before primary-location license,
4. keep `open access` only as the fallback label when the provider gives no
   explicit license.

The source-finder and reading-list rankers now prefer explicit reuse licenses
after topical gates pass. If primary provider hits are all license-ambiguous,
source-finder queries secondary providers before ranking the final mini-shard.

The generic OpenLibrary course-book lookup is no longer promoted into graph
resources or trusted source-ledger proof. Instructor-named registry books still
get OpenLibrary ISBN/URL/publisher enrichment, but that enrichment does not
create a separate trusted bibliography row.

## Verification

Focused tests cover the release shape:

1. OpenAlex/search normalization preserves best-OA license metadata.
2. reading-list selection prefers explicit-license OpenAlex readings over
   generic `open access` readings.
3. source-finder searches secondary providers and chooses a license-safe source
   when primary hits are license-ambiguous.
4. OpenLibrary registry-book enrichment still works, while empty-slot course
   retrieval no longer promotes generic OpenLibrary metadata.

## Carry Forward

This patch removes avoidable license ambiguity. It does not guarantee that every
future topic has a license-safe source; remaining ambiguous rows must stay
visible until provider metadata proves a real license or a curated OER source
can replace them.
