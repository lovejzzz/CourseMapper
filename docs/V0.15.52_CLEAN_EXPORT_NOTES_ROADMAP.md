# v0.15.52 Clean Export Notes Roadmap

_Written June 26, 2026. Target app version: `0.15.52`._

## Goal

Clean up the v0.15.51 Project Management finish experience without weakening
trust. Downloadable packages with non-blocking caveats should feel like a usable
handoff, not a wall of raw warning messages, while deterministic product defects
we already understand should be fixed before they become user-facing caveats.

## Lane

User-facing export trust and deterministic slide-deck export quality. This
release changes presentation for non-blocking notes and fixes one deterministic
PPTX repeated-phrase source. It does not lower quality thresholds or hide
blockers from reports.

## Evidence

Manual browser evidence from the v0.15.51 Project Management finish state:

- app version: `0.15.51`
- status: package download was available
- issue: export panel and agent panel led with raw review/warning wording
- issue: non-blocking notes used defect-log copy in the primary handoff
- issue: known PPTX repeated-phrase warning should be fixed in generation
  instead of being shown as unresolved UI noise

Carry-forward evidence from the previous ZIP/log audit remains active:

- source-ledger/research bridge weakness remains a real quality target
- prompt-artifact leakage remains a real quality target
- clean green readiness remains reserved for packages with no caveats

## Release Boundary

In scope:

- Present downloadable caveated packages as `Ready with notes`.
- Keep amber/review styling for caveated packages.
- Move non-blocking issue detail behind notes toggles in the export card and
  package summary.
- Keep blockers visible and keep instructor/report evidence intact.
- Shorten repeated long assessment artifact names in slide speaker notes so the
  rendered PPTX no longer trips the repeated-phrase export audit.
- Preserve messy-import slide-deck readiness and texture guards.

Out of scope:

- Declaring the Project Management package 100/100.
- Hiding P0/P1/P2 findings from reports or grader output.
- Weakening source-ledger, prompt-artifact, texture, or export checks.
- Solving the full research/source bridge in this UI-focused release.
