# V0.15.114 UX Source False-Friend Gate Roadmap

## Goal

Stop licensed, concept-linked bycatch from counting as trusted User Experience
Design Studio source proof.

The fresh deployed v0.15.113 User Experience Design Studio audit showed why the
target is still not clean:

- Visible UI and exported report: `99/100 (A)`, `Texture 90`
- App version: `0.15.113`
- Run ID: `run-1782693090455`
- Local regrade before this fix: `99/100 (A)`, no P0/P1/P2 findings
- Patched local regrade after the stricter source rule: `94/100 (A)`, with
  five P1 citation findings
- False-friend rows: `A Critique of Private Sessions in Family Mediation`,
  `The efficacy of booster maintenance sessions in behavior therapy`,
  `Accessibility of the Metropolitan Transportation Authority`, and
  `Design Research (store)`

Those rows are real, URL/DOI-backed, licensed, and concept-linked, but they are
not discipline-appropriate UX sources for this course. CourseMapper should not
let lexical overlap on `critique`, `sessions`, `accessibility`, or `design
research` inflate trusted source proof.

## Lane

1. Tighten UX source relevance.
   - Reject family-mediation and mediator/disputant rows for UX critique
     sessions.
   - Reject behavior-therapy booster-session rows for UX critique sessions.
   - Reject Metropolitan Transportation Authority accessibility pages for UX
     digital accessibility review.
   - Reject `Design Research (store)` and retail/lifestyle-store bycatch for
     design-research concepts.

2. Keep production source export and grading aligned.
   - Source-finder topic selection should drop the bycatch before it becomes a
     trusted sourceLedger row.
   - Generated syllabus rows with the same false-friend shape should not become
     trusted proof.
   - The deep quality grader should flag already-exported packages with those
     rows as P1 citation debt.

3. Preserve legitimate UX source proof.
   - Keep usability testing chapters eligible.
   - Keep digital accessibility audits eligible when the evidence is digital
     accessibility or WCAG-facing.
   - Keep UX-practitioner collaboration and design-handoff research eligible.

## Release Boundary

- This release changes source relevance filtering and source-ledger grading.
- This release does not weaken source standards, lower grader sensitivity, hide
  exported rows, or inflate quality scores.
- This release does not claim strict-clean provider output. A fresh deployed
  v0.15.114 ZIP/log audit must prove the false-friend rows stay out of real
  provider output.
- Texture `90/100` and the generic `project-based undergraduate course` lesson
  identity observed in the same v0.15.113 audit remain carry-forward targets.
