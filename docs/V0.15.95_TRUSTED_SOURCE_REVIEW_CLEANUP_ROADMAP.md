## Problems

1. Source-finder rows could still become exported review debt even when they were metadata-only and not trusted bibliography proof.
2. UX false friends were still not broad enough. `Prototype-based programming` is real, linked, and licensed, but it is programming-domain content, not UX prototyping evidence.
3. Generated syllabus text could emit public-metadata false friends such as `Journals of Mechatronics Machine Design and Manufacturing`, which then appeared as source review debt for a UX design course.
4. The package also kept a separate readiness blocker: partial enrichment left lesson 1 on template fallback after a repair/retry call. That is not solved by this release.

## Release Scope

- Filter source-finder candidates before attachment unless they have URL/DOI proof, a non-ambiguous license, and domain-appropriate source text.
- Drop source-finder rows that require review instead of exporting them as source notes.
- Extend the UX false-friend gate to programming-prototype and mechatronics/manufacturing terms.
- Drop generated-syllabus UX false friends from source review rows.
- Keep normal non-source-finder missing-proof rows visible as review notes when they are not clearly false friends.

## Non-Goals

- This release does not claim 100/100 provider quality.
- This release does not fix partial enrichment fallback for lesson 1.
- This release does not change texture scoring or hide review findings.

## Release Boundary

Ship only the source filtering and source-report cleanup proven by the v0.15.94 UX audit evidence. Do not bundle enrichment recovery, texture variation, UI redesign, or broader source-retrieval architecture changes into this release.

## Verification Plan
