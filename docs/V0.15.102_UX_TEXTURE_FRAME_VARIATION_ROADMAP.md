# V0.15.102 UX Texture Frame Variation Roadmap

## Goal

Move the latest User Experience Design Studio output from public-score clean toward strict-clean by removing the repeated compiler frames that kept the fresh v0.15.101 audit at Texture 94/100.

## Lane

Compiler texture cleanup for Lesson Plans, Discussion Prompts, and Slide Decks.

## Evidence

Fresh deployed v0.15.101 ZIP/log evidence is saved at:

- `verification-output/edutool-audit-loop/20260628T143000Z-v015101-ux-fresh/report.md`
- `verification-output/edutool-audit-loop/20260628T143000Z-v015101-ux-fresh/local-regrade.json`

The package regraded at 100/100 (A), with 0 P0, 0 P1, and 0 P2 findings. Export verification passed, source proof was clean, and the ZIP report matched local regrade.

The strict-clean gap was texture:

- Texture: 94/100 (A)
- Repeated Lesson Plan shingle: `and show one line of reasoning students should reuse in [slot] [n]`
- Repeated Discussion Prompt shingle: `artifact expectation to test whether the proposed decision would hold up in`
- Repeated Slide Deck shingles around true/false pitfall voting, vocabulary-only objectives, and strongest-evidence closing checks.

## Problem

The overall score can round to 100 while a texture subscore below 100 still shows repeated scaffolding. The long-running quality target is stricter than the public score: no hidden texture caveat, no repeated template feel across 12 lessons, and no mismatch between UI, ZIP, report, digest, and local regrade.

## Release Scope

- Vary Lesson Plan model-note frames that tell students to reuse one line of reasoning.
- Vary Discussion Prompt artifact-review frames that stress-test the proposed decision against assessed work.
- Vary Slide Deck objective, common-pitfall, and summary note frames that previously repeated vocabulary-only, true/false, and strongest-evidence language.
- Add a twelve-lesson UX compiler regression that blocks the exact v0.15.101 shingles across Lesson Plans, Discussion Prompts, and Slide Decks.

## Non-Goals

- Do not weaken the texture metric, deep quality grader, source ledger, report digest, export verifier, or package UI.
- Do not claim strict clean until a fresh deployed v0.15.102 ZIP/log audit proves Texture 100/100 or otherwise shows no hidden texture caveat.
- Do not change source retrieval or source relevance gates in this release.

## Release Boundary

Ship only the deterministic compiler texture-frame variation for the v0.15.101 evidence: Lesson Plan model notes, Discussion Prompt artifact-review rows, and Slide Deck objective/pitfall/summary notes. Keep source-ledger logic, report truth, UI layout, and grader thresholds unchanged.
