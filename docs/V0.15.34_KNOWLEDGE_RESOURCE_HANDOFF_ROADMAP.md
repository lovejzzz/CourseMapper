The prior v0.15.33 blocker was fixed: AI Governance packages with valid
model-documentation language now reached ZIP export. The new evidence is a
different truth mismatch: CourseMapper retrieved open resources during the
knowledge-backbone pass, but the downloaded ZIP did not export any trusted
source proof and the Course Map supporting-resource cells still contained
generic placeholders.

## Goal

Keep the resource-bearing CourseGraph as the project source of truth before the
knowledge backbone renders the display Course Map, then preserve trusted
resource metadata through native render/derive synchronization so exported ZIPs
can include real source-ledger proof instead of losing it before download.

## Lane

Narrow graph handoff and source-metadata preservation. This release does not
claim genome coverage, sourceRef-rich CurriculumV1 architecture, slide-deck
texture, or a live 100/100 package. It fixes the state handoff class exposed by
the v0.15.33 ZIP/log mismatch.

## Fix Plan

1. Adopt the generated graph synchronously.
   - `useDeliverables` still emits the CourseGraph before the display-map repair.
   - `AppFlow` updates `courseGraphRef` immediately, before React state timing can
     leave the repair effect looking at a stale graph.
   - The display map still renders with assessment references for the UI.

2. Preserve verified resources during native stable-id matching.
   - Match resources by URL/DOI first, then normalized citation/title.
   - Keep provider, URL, license, origin, attribution, source-finder shard, and
     reading-list decisions when rendered maps round-trip through derive.
   - Do not fabricate rows; if no trusted source reaches the graph, the grader
     should still report missing source proof.

3. Add focused regression coverage.
   - A verified OpenAlex resource must survive render -> derive -> match with
     source metadata and section `resourceRefs` intact.
   - Existing CourseGraph, ZIP-export, and source-ledger grader tests stay
     green.

## Non-Goals

- Do not weaken the source-ledger grader.
- Do not synthesize fake citations from package labels or placeholders.
- Do not claim slide-deck repeated-phrase texture is fixed by this patch.
- Do not claim the full research-ledger architecture is complete; the broader
  ResearchSession planner remains a roadmap item.

## Release Boundary

Ship only if the focused graph/source-ledger regressions, release-history
audit, format, lint, full test suite, gold smoke, build, bundle check, and
browser verification pass locally. After push, Fast verification and GitHub
Pages deploy must complete before the release is claimed.
