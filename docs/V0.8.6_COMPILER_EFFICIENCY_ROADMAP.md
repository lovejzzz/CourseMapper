# v0.8.6 Compiler Efficiency and Trust Surface Roadmap

## North Star

Every provider token CourseMapper spends should buy source interpretation the compiler cannot do. Repeated instructions, prose scaffolding, whole-map review payloads, and trust reporting are compiler/cache work — and any weight shifted onto the compiler must be provably free of quality loss, enforced by a calibrated variety gate rather than by hope.

Origin: `docs/NEXT_STEPS_AUDIT_2026-06-09.md` (full audit at v0.8.59).

## Shipped In This Release

### 1. Generation prompt caching (A2)

Status: implemented.

- `buildProviderTextRequest` wraps Anthropic system prompts in a `cache_control: ephemeral` block whenever the model profile reports prompt-cache support (`generationPlan.caching.mode = 'none'` opts out).
- Course-map chunks, repairs, retries, and the examine pass share identical system prefixes, so cache hits apply to the heaviest call family. The agent path already cached; generation now matches it.
- Tests: `src/lib/__tests__/modelRequestBuilders.test.js`.

### 2. Focused examine pass (A3)

Status: implemented.

- `getCourseMapExamineScan` (was `getCourseMapExamineTriggers`) reports per-lesson problem indices alongside triggers. Global problems (structural fixes, missing lessons, expected-count mismatch) still trigger a full review.
- When problems are local to a minority of lessons, `buildExamineUserPrompt` sends only those lessons with embedded original `lessonIndex` values plus course-level fields; returned patches are filtered to the focus set and may not add/remove lessons.
- The conditional-review API event records the focus size for cost observability.
- Tests: `src/hooks/__tests__/useGeneration.test.js`, `src/lib/__tests__/generationPrompts.test.js`.

### 3. Copy-variety regression gate (A5)

Status: implemented and calibrated.

- `buildCopySpecificityAudit` now detects near-duplicate template families: strings ≥ 90 chars on the same structural path family (numeric indices collapsed) grouped at Jaccard ≥ 0.92, exact repeats excluded (those remain a blocker).
- Calibrated against all 40 gold samples on 2026-06-09: worst sample `gold-community-health-semester-14` at 48 families, the AI-course-design/community-health/messy-clinical cluster at 34–43, most samples at 0–3. Budget: 60 families per sample (~25% headroom). Exceeding it is a warning finding, which fails the gold gate.
- This is the enforcement mechanism for "no quality lost" on every future blueprint→compiler weight shift.
- Tests: `scripts/__tests__/copyVariety.test.js`.

### 4. Lean course-map atoms (A1, flag-gated)

Status: implemented behind `generationPlan.leanCourseMapAtoms === true`; default off pending the A/B gate below.

- Lean mode replaces verbose per-cell prose instructions with compact array contracts (`LEAN_COLUMN_DEFS`), and `LEAN_SYSTEM_ADDITION` overrides the prose-formatting rules.
- `expandLeanCourseMap` deterministically renders the standard cell prose — objective stems, list numbering, goal references — before validation, so validators, the blueprint compiler, UI, and exports see an unchanged contract.
- Expansion is idempotent: string cells pass through, so continuation chunks on the verbose contract and legacy restored maps are safe.
- Tests: `src/lib/__tests__/leanCourseMap.test.js`.

### 5. Package trust strip

Status: implemented.

- `PackageTrustStrip` renders compiled / custom / auto-fixed / stale / failed chips in the workspace header from deliverable state and the last finish-package run.
- Tests: `src/components/__tests__/PackageTrustStrip.test.jsx`.

### 6. Housekeeping

Status: implemented.

- The dormant Express dev proxy moved from the repo root to `archive/dev-proxy/server.js`; deployment-security tests now assert no server entry point exists at the root.
- Version bumped to 0.8.6 with changelog and README entries.

## Release Gate Before Lean Mode Defaults On

Lean course-map atoms must not become the default until:

1. A 34-course sweep (`audit:v0855:sweep` pattern) run with lean mode forced on passes with 0 blockers / 0 warnings.
2. The gold audit passes with no sample exceeding the 60-family variety budget.
3. A live provider A/B (one small + one standard fixture) confirms expected output-token reduction without examine-trigger regression.
