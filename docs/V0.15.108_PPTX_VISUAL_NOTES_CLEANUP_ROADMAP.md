# V0.15.108 PPTX Visual Notes Cleanup Roadmap

## Goal

Close the package-blocking export hygiene defect from the fresh deployed
v0.15.107 User Experience Design Studio audit. That run exported successfully,
kept trusted concept-linked sources, and improved texture to 95/100, but the
package still graded 74/C because Slide Deck PPTX speaker notes carried raw
visual-planning labels such as `SUGGESTED VISUAL` and `ALT TEXT`.

Those labels are useful internally while planning slides, but they read like
prompt scaffolding when shipped inside the exported package. The fix belongs in
CourseMapper's PPTX exporter and quality grader, not in the provider model.

## Lane

1. Clean PPTX speaker-note wording.
   - Preserve visual guidance for instructors.
   - Preserve accessibility descriptions for visual hints.
   - Stop exporting raw all-caps planning markers that resemble prompt labels.

2. Keep the quality gate honest.
   - The deep quality grader should fail packages that still contain raw PPTX
     visual-planning note labels.
   - The failure should point at the exported slide deck rather than a vague
     prompt-artifact category.

3. Reduce false positives without weakening the firewall.
   - Keep explicit prompt labels such as `final capstone presentation`
     guarded.
   - Do not treat legitimate UX course deliverables such as
     `portfolio-ready capstone presentation` as internal prompt artifacts.

## Release Boundary

- This release changes only PPTX speaker-note wording and the mirrored package
  quality checks for that export shape.
- This release does not weaken source-ledger rules, source relevance checks,
  texture scoring, report truth, or export verification.
- This release does not claim strict-clean provider output. A fresh deployed
  v0.15.108 ZIP/log audit must prove the new exporter and grader behavior in
  real generated materials.
