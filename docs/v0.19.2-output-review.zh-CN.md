# v0.19.2：从证据关系到可执行的比较方案

本轮保留 0.18.7 首页、十类材料、编辑器和导出选择；Scion 仍在本地推理，共享在线 API 继续暂停。改动属于确定性的教学任务 compiler，样本生成没有模型调用，也没有权重训练或 adapter 激活。

## 为什么做这些改动

上一版仍有八个已暴露来源包无法形成具体任务。问题不是材料数量不足，而是缺少能把材料关系变成问题、推理、答案、错误反馈和评分档位的共同结构。新增操作先判断输入是否满足明确条件，再生成共享任务，最后投影到原有材料。独立练习使用不同的虚构来源包，走同一操作和求解过程。

| 操作                     | 学生需要展示的理解                       | 教师参考与边界                                                                                       |
| ------------------------ | ---------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| 底片曝光与照片印制日期   | 分别标注事件，检查先后依赖               | 1936 年曝光、1984 年印制可相容；交换日期会产生需要核查的年代矛盾。两条记录不能补全流转史             |
| 原始记录与生效修订       | 区分记录时间、规则版本和适用时间         | 原记载 120 座，7 月 1 日起修订为 90 座；未定年照片不能直接套用任一容量，也不能把旧记录改成“错误”     |
| 缺失坐标轴的图           | 区分线条视觉方向、变量、数值变化和速率   | 保留未裁切的原图、数据、单位与时间需求；不能根据陡峭程度计算百分比                                   |
| 中文访谈归属             | 摘录“亲眼”“告诉我”“我觉得”，追踪信息来源 | 自称亲眼所见仍不是独立核验；转述与推断不能直接当事实；缺少记录不等于事情没发生                       |
| 训练、营养与教练共同变化 | 找出并行变化、基线与分配缺口             | 同等营养支持、教练/基线平衡、独立随机团队与统一测量；团队内多名运动员不等于多个独立处理重复          |
| 算法缓存与运行顺序       | 分开算法、缓存状态和先后顺序             | 每次测量前重建指定缓存状态，在输入/缓存区组内平衡随机顺序，检查正确性、重复测量和不确定性            |
| 配方标签与品尝顺序       | 区分配方效果、期待与顺序                 | 中性编码、隐藏编码表、平衡随机顺序、统一量表、参与者内配对；编码不能保证消除感官识别或残留影响       |
| 滤材初始条件与处理时间   | 区分初始浑浊度、时长和测量方法           | 同批混匀等体积水样、随机分配、相同拟定时长、前后仪器读数及独立重复；不能把同一杯反复读数充当独立水样 |

独立案例不只更名。例如算法练习改为先运行的算法观测更快，品尝练习改为第二个标签评分更高，过滤练习改为另一种滤材看起来更清。结论仍必须由条件是否可比来决定，而不能背诵“第二组更好”的固定答案。新时间、量表和操作被明确标为建议，不冒充原研究的观察结果。

实验设计要求参考 [NIST 区组设计](https://www.itl.nist.gov/div898/handbook/pri/section3/pri332.htm)、[实验设计术语](https://www.itl.nist.gov/div898/handbook/pri/section7/pri7.htm)中控制干扰、随机化和重复的原则。来源任务参考 [Library of Congress 的观察、反思与提问工具](https://www.loc.gov/programs/teachers/getting-started-with-primary-sources/guides/?reload=no)。这些原则如何映射到任务，是本实现者的工程与教学判断，不代表上述机构审核了产品。

## 实际材料审读与修复

四套完整的单课工作坊：Records and Effective Dates、Fair Algorithm Timing、访谈证据的层次、公平比较过滤材料。每套包含原有十类材料；使用网站实际的 Word、PowerPoint、XLSX、CSV、ZIP 与 PDF 导出器。案例来自已暴露回归集，全部是虚构教学记录，未声称真实研究结论。

| 材料               | 审读重点与结果                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| Course Map         | 来源、目标和任务一致；实际 XLSX 保留日期、条件及中文来源。课程图继续作为编辑和关联的入口                                 |
| Syllabus           | 任务进入目标/评估对齐与课时安排；100 分 rubric 不自动变成课程成绩权重。教师姓名、机构政策和正式日期仍需确认              |
| Lesson Plans       | 阅读、示范、练习、独立回答和反馈围绕共同任务；实验方案提供执行步骤和测量边界。教师文本较密集                             |
| Slide Decks        | 四套分别 16、19、16、17 页；来源与独立练习分开，完整推理拆页保留。部分来源/提问页有较多留白，尚未加入专门的条件对照图    |
| Assignment Briefs  | 修复教师答案依赖自然分页的问题：无论材料长度或语言，教师参考强制另起页。学生自查仍为过程检查                             |
| Rubrics            | 三项按 30/35/35 计分，四档区分证据归属、推理和边界。完整实验设计的最高档明确要求可执行方案                               |
| Discussion Prompts | 比较具体解释和可补充的证据，不把“多讨论”当作任务。讨论与原记录使用相同答案边界                                           |
| Quiz & Exam Bank   | 区分主任务、错误诊断和独立案例；保留答案页分离。题目是练习与诊断材料，并未验证考试区分度                                 |
| Study Guides       | 有完整步骤、参考结果、错误纠正、新案例和答案。短错误诊断题改用其实际提问对应的评分条件，避免要求学生额外提交整套实验设计 |
| Course FAQ         | 目标、准备、提交证据、标准及反馈对应任务；中文 compiler 指导语改为中文                                                   |

真实导出额外找出并修复两个自动基准没发现的问题：全中文课程的教学计划检查器只识别英文动作词；短错误诊断题的评分要求超出了问题范围。前者增加明确中文可观察动作，同时继续拒绝“了解”之类无可检查行动；后者将诊断的成功条件与完整实验设计评分分开。

Word/PDF 答案键只去除同一条答案已经完整包含的检查文本及完全重复的检查，保留不同要求、否定条件和手写答案键；不缩写共享答案或删除可编辑数据。四套 Office 共 153 页渲染逐页总览，放大检查作业、rubric 和学习指南；36 份原生 PDF 共 156 页，检查可提取文字、页面边界和教师答案分页。中文预览最初缺字，原因是独立 LibreOffice 审计环境没有中文字体；以任务专属字体配置加载项目已有 Noto Sans SC 后正常，未修改用户字体或运行时依赖目录。

本地单页再生成测试又发现：没有缓存模型知识块时，即使共享来源任务已经完整编译，仍会尝试一次多余的模型刷新，造成约 10 秒等待。现在只对实际编译出的受支持来源任务跳过该刷新，不把它伪记为模型 enrichment；不支持的任务仍保留原来的知识补充路径。同一中文课程在修复后从再生成开始到编译完成约 0.83 秒，保留编辑后的 14 分钟和独立案例自己的 12 分钟。这是单次本机观察，不是跨设备延迟承诺。

## 验证方法与诚实的结论

- 新增 79 项针对性回归。覆盖八类操作、独立练习、全十材料 finalizer、36 组日期先后组合、否定/假设/缺失/矛盾条件、普通算术路由、全中文课程、答题评分与九类材料源编辑同步。先保留失败，再修复实现。
- 原 18 个开发案例和 12 个已暴露案例通过原自动检查器。v0.19.0 首次留出结果仍为 11 个不支持、24 个缺陷；v0.19.1 仍保留 8 个不支持、18 个缺陷；本版这 12 个案例为 12 个支持、0 个编码缺陷。原始来源、答案、manifest、检查器和历史结果不变。
- 这些案例已经参与开发，不能称为新的盲测。新增否定与条件变化测试也是实现者编写的回归，不是独立专家评估。输出审读同样由实现者完成。
- 1092 项必需软件测试与 14 项独立 benchmark 检查器测试通过。串行浏览器导出/编辑/恢复/移动布局检查、生产构建 PDF 失败重试和精确部署 SHA 的证据随 [GitHub Release](https://github.com/lovejzzz/CourseMapper/releases/tag/v0.19.2) 发布。复现：`npm run check`、`npm run test:e2e`、先 build 后 `npm run test:production`。
- 本版自动基准结果存于 `benchmarks/classroom/v2/results/v0.19.2-exposed.json`。文件记录生成时的基础提交及工作区状态，并用 compiler 源码散列绑定实际实现；它不是在旧版干净提交上运行的结果。

仍有实质限制。新操作依赖明确、有限的来源句式；任意改写、多条修订、复杂真实语料或混合任务不一定可用。四套导出包的旧质量报告仍保留重复文字、内部链接标识、运行审计信息与缺少专门视觉表达等提示；没有为了得到高分而修改 grader。跨材料保留共同证据有必要，但学习指南的参考结果、讲解与题库答案仍有重复。部分旧导出栏目及机构政策指导仍为英文，不能声称全产品中文化。所给复杂实验方案的课时是否适合目标学生，仍需要教师试教。

目前可以确认的是：这八类明确任务的解答和评分更具体，同步结构与实际导出得到回归保护。不能确认的是通用来源理解、独立教师评分一致性、学生学习增益，或“任何课程都能直接发给学生”。这些改动加强了 Scion 后面的 compiler，不是把本地模型训练成了新的专用模型。
