# Scion 联网研究与 compiler 复查（2026-09-05）

本轮以实际代码、真实公开来源请求和实际编译输出为依据。继续保留 0.18.7 界面；共享在线模型 API 保持暂停。没有训练新模型、租服务器或重新开启 Google 免费推理。

## 改了什么

旧检索的主要问题不是缺少开关，而是搜索、定向修复和外层恢复可以各自增加等待；日期判断还可能把元数据入库时间或当天抓取误当成内容更新。本轮替换 HTTP 调度核心，将发现与恢复绑定在同一个串行事务中，统一请求数、时间、取消、去重和限流状态。单节课最多 14 次请求、20 秒网络预算；多课最多 96 次、60 秒。达到预算后保留缺口，不自动增加一轮额度。

发表、内容修订、索引和抓取日期分别记录。需要当前资料的学术查询加发表日期条件；近期/最新等词不再强制成为文章标题中的精确短语。无日期或旧资料不能单独满足当前证据要求。旧缓存失效；需要当前证据的缓存重新检查。通过教学计划审核且教师已提供足够事实、没有更新要求的课程跳过重复研究与阅读检索。对于单课、只逐字采用教师事实的路径，生成前计划仍可能标为 `needs-evidence`；该路径同样跳过随后会被丢弃的搜索，但不改变内容准入与质量审核。明确要求当前证据时不跳过。

compiler 新增复用的练习单元，绑定题目、参考答案、评分条件与来源，并由内容产生稳定标识。对明确且精确成立的比例等式，支持计算、逆向检验、剩余比例和错误辨析。教师检查与学生复习复用这些完整单元。具备定义和实例的其他学科也能生成有参考答案的复习；原有专门学科教学流程优先保留。

学习指南界面补上此前未显示的例题，答案可展开并编辑。Word 有独立练习答案区；教师版包含预期答案；CSV 等表格数据保留答案。默认比例课案中的泛泛活动改用具体练习，课时仍为 45 分钟。

## 实测证据

- 两个真实来源 API 读取合计约 1.3 秒：Wikipedia 返回原文与修订日期；Europe PMC 返回 2026 年论文摘要与发表日期。这只证明读取成功，不代表每篇都适合课程。
- 样本比例完整研究链约 5.5 秒、7 个请求，1/1 课通过来源及原文证据准入。不是假造搜索响应。
- “近期抗生素耐药研究”未通过完整准入。一次运行约 17 秒使用 14 次请求；修正查询后另一次运行在约 20 秒预算结束，部分学术候选仍未通过后续语义准入。保持证据缺口状态，没有降低准入规则将它改成成功。
- 重放三份此前真实生成的课程：统计、历史来源、实验设计。九类衍生材料的编译分别约 0.86、0.16、0.15 秒；这些是同一台机器上的单次运行，不是性能保证。本轮重放没有调用模型。
- 实际统计学习指南 Word 共两页、教师课案三页，渲染后逐页检查；继续根据教师版发现的泛泛活动修正输出。
- 在 `edutool.dev` 的 `52becbeb` 部署上实际生成一份单节统计课：一次浏览器本地模型调用完成课程骨架，总流程 30.97 秒，九类衍生材料编译约 1.64 秒，没有在线模型调用。这是含额外研究等待的单次实测，不能用来代表所有课程速度。
- 此次线上输出暴露了两个编译问题：事实投影被误作术语定义，产生两道重复题；自动补出的作业模板被误作作者内容，覆盖具体练习。修正后重放这份实际项目，留下四道有答案与评分条件的练习；教师答案对应一致，课时 45 分钟。真实规划 adapter 的回归用例也覆盖上述无用搜索路径。
- 最初 `npm run check` 通过：58 个 Studio、129 个兼容、490 个 Scion/检索测试，以及类型、lint、构建和 bundle 检查。线上复查补丁新增的回归使 Scion/检索测试增至 493 个。
- 原有 32 个浏览器检查通过。新增浏览器检查通过：真实 compiler 产物恢复、例题显示、展开答案、45 分钟课案重新生成，无在线推理或模型权重下载。浏览器检查采用一个 worker。

## 教育判断和未完成项

计算过程、答案和常见转换错误现在明确且可核对；比只有泛化活动描述更有教学用途。剩余比例是同一来源数据的推导练习，不能当作独立迁移测验。源材料里没有的样本、实验结果和定义仍不能由 compiler 凭空补出。

本轮没有证明学习效果，也没有证明所有学科都达到 classroom ready。研究仍受公开目录、CORS、许可、来源可用性和严格语义准入限制；它不是可以浏览任意网站的通用研究代理。尤其是最新研究和专业政策，找到近期文章不等于证明结论仍适用。教师材料还有可进一步减少的重复和通用说明。这些限制是继续工作的依据，不能用通过格式测试掩盖。

技术参考：[Europe PMC 检索与排序](https://europepmc.org/RestfulWebService)、[DOAJ 发表年月字段](https://doaj.github.io/doaj-docs/master/data_models/IncomingAPIArticle.html)、[MediaWiki 请求规范](https://www.mediawiki.org/wiki/API:Etiquette)。
