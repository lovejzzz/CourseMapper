## 2. 第一段 schema 决策

保留外层 `COURSE_GRAPH_VERSION = 1`，新增可选的 `teachingProgram.version = 1`。没有教学程序的旧图仍可读取。后续增加操作和评分协议时单独版本化，不能把本轮版本号误解为整个 v0.20.0 schema 已冻结。

当前程序包含：

- `objectives`：任务需要学生展示的具体表现，稳定 ID 和文本。
- `sources`：带稳定 ID 的输入陈述；旧来源标为 `legacy-task-input`，不追认其事实真实性。
- `tasks`：通过 `objectiveRef`、`inputs[].sourceRef` 引用目标与来源，保留任务 ID、原输入 ID、课次绑定、时间、作用域和未知的教师字段。
- `revision`：对规范化 JSON 计算摘要，用于检测变动和不完整保存；不是事实认证或教师审批。

任务层表现与旧课程总体 outcomes 的正式对齐关系仍待 M2 实现。推理、评分与操作目前仍通过旧 solver 派生；不能把这次来源规范化说成已完成所有教学实体统一。

没有根据文本相同自动合并来源。两个独立案例即使陈述相同，也保留各自身份。显式共享引用可表达共同来源；不同任务对同一引用提出相互矛盾的更新时拒绝静默选择其中一个。

`teachingTaskSources` 继续存在于材料快照和 map 的兼容视图中；只要程序存在，读取时以程序为准。新的图不在 `course.meta` 另存这份 ledger。旧文件中用户自定义的来源、输入和任务字段需往返保留。
