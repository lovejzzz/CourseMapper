## Problems

1. Source relevance still treated `persona` as sufficient even when the source was about the Persona video-game franchise.
2. `Persona 4 Revival` and `Revelations: Persona` are real and CC BY-SA licensed, but they are not UX persona-development source proof.
3. The local grader needed to mirror this rule so game-series persona rows cannot produce hidden citation debt behind an exported 99/A.

## Release Scope

- Extend the UX false-friend gate to Persona game-series rows and snippets.
- Reject Persona numbered titles, `Revelations: Persona`, Megami Tensei/Atlus/P-Studio evidence, and role-playing video-game snippets as UX source proof.
- Mirror the same source-sense rules in the deep quality grader.
- Add regressions using the exact v0.15.96 leak shape.

## Non-Goals

- This release does not claim 100/100 provider quality.
- This release does not change texture scoring or repeated-shingle cleanup.
- This release does not broaden retrieval architecture beyond the evidenced persona false-friend class.

## Release Boundary

Ship only the persona source-sense gate proven by the v0.15.96 audit evidence. Do not bundle texture, UI, or broader retrieval changes into this release.
