# v0.20.07 simplified interface

Date: 2026-09-22. Follows the interface simplification plan: say each thing once, keep one place for each status, show settings and panels only when needed, and give the material the space.

## What changed

| Area           | Before                                                                                                                                | After                                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Homepage       | Headline, subtitle, stepper, helper sentence, placeholder (the same instruction four times), file-type list, AI card, disabled button | One question and one description box; attachments, AI settings and Continue inside the box; example courses below                                           |
| AI settings    | Title and "Configured" badge, provider/API/model columns, internal tuning chips, two paragraphs, long research text                   | Provider, one line about local use and download size, public-source switch                                                                                  |
| Sign-in        | Google button, email button and settings gear                                                                                         | One Sign in button with Google and email options                                                                                                            |
| Setup          | Two pages (choose materials, configure) with repeated counts and generic sample previews                                              | One page: course title, editable lessons / minutes / quiz questions, one material checklist, Advanced settings, Generate                                    |
| Course shape   | Lesson count only editable by rewriting the description                                                                               | Steppers write one "Course shape (set in setup)" line; lesson detection, the session clock and quiz count read it first                                     |
| Workspace      | Three columns: assistant, material, download panel always open                                                                        | Full-width material; Assistant and Export open as one header drawer at a time; Escape closes it                                                             |
| Assistant      | Opened with Agent/Available/AI settings/working-set status                                                                            | Opens automatically during content generation longer than about a second, closes when it finishes; header shows only "Assistant" and status when it matters |
| Tabs           | A tick on every finished tab                                                                                                          | Only needs-review or out-of-date dots                                                                                                                       |
| Material views | Repeated sources, objectives, prompts, usage notes; emoji headings; empty course-map columns                                          | Each shown once; plain headings; empty columns hidden; placeholders grouped as a to-add list                                                                |
| Generated text | "evidence ledger", "admitted evidence", "revision trail" in visible copy                                                              | Plain wording; the strict classroom benchmark fails if these terms return                                                                                   |

## Verification

- `npm run check`: type checks, lint, 58 studio, 213 authoring, 1,120 compatibility and 1,100 Scion tests, benchmark evaluator (11), strict classroom benchmark (0 failures), acceptance checks (37), build and bundle check.
- Browser suite: 57/57 (one Chromium worker). Production build suite: 5/5.
- In-browser walkthrough at 1440 px and 375 px, light and dark: homepage, sign-in menu, setup page (steppers, checklist, advanced settings), workspace header, both drawers, Escape, all ten material views, a compiler-only lesson regeneration with model requests blocked.

Issues found and fixed during the walkthrough: dark-mode hover backgrounds that appeared permanently (global surface overrides matched `hover:bg-slate-100`), unreadable dark-mode badges, the Export drawer disappearing when package checks started, a brief assistant flash on instant rebuilds, duplicate accessible names between tabs and the export scope toggle, a wrapping materials header and a truncated lesson title on phones, a course-map table that needed sideways scrolling, and awkward generated wording in the Evaluate column.

No fresh Scion inference was run; model weights are unchanged. This release changes presentation and wording, not classroom-readiness claims.
