# V0.15.4 — Truthful Course Packages: the audit must catch what teachers see

_Written June 14, 2026, from the live Linear Algebra export audit. The package
looked polished at a glance but carried false required assets, generic
study-guide phrasing, thin math decks, reused course-map section content, and a
100/A quality report despite an unevaluated knowledge judgment. This release is
the repair plan and implementation bar._

## Goal

Make generated packages truthful before they are push-ready: a course package
should not list the wrong physical supplies, should not hide generic text behind
polished formatting, and should not earn a perfect audit while the pipeline says
judgment was not evaluated.

## Scope

1. Required Assets genre gate: a computational Python lab in Linear Algebra is
   not a wet lab. Physical lab assets require concrete wet-lab evidence such as
   specimens, reagents, hand lenses, lab safety, or field notebooks.
2. Course-map repair: sparse secondary sections must repair from their own
   topic first, not borrow the first section's objectives/resources.
3. Assessment identity: a problem set or computational lab about final/midterm
   review stays a graded artifact, not an exam.
4. Study-guide language: final title compression must stay topic-specific and
   must not create "this lesson criterion" or "which the lesson" phrasing.
5. Math deck substance: Linear Algebra lessons without kernel enrichment still
   get deterministic worked examples with chartable numeric steps.
6. Package quality grader: Required Assets wet-lab leaks, generic artifact
   placeholders, and unevaluated STEM judgments must become findings.

## Bars

1. Targeted regression suite passes for required assets, course-map repair,
   assessment registry, and Linear Algebra output quality.
2. Full unit test suite passes.
3. Lint, formatting check, build, and bundle budget pass.
4. A generated Linear Algebra package no longer contains the audited bad
   phrases in learner-facing study-guide fields and includes worked-example
   visual data in slide decks.
5. A deliberately bad minimal Linear Algebra package grades below 100 and
   reports the expected structure, format, and honesty findings.

## Release Boundary

This release does not try to solve missing instructor-specific syllabus facts
or invent official course dates, instructor names, or institutional policies.
Those remain local-review items. The release fixes generator truthfulness and
quality-gate honesty for the defects surfaced by the audit.
