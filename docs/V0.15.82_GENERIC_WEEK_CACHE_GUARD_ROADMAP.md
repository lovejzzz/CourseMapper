# v0.15.82 Generic Week Cache Guard Roadmap

## Goal

Stop generic `Week N` Course Map placeholders from being treated as finished
lesson identity, and prevent weak generic lesson labels from reusing stale
cross-course lesson-kernel cache entries.

## Evidence

A fresh deployed v0.15.81 Project Management audit completed on June 27, 2026
and saved evidence under:

`verification-output/edutool-audit-loop/20260627T112717Z-v01581-fresh`

The package regraded locally at `97/100 (A)` with four findings:

- P1 substance: slide decks averaged only 0.5 content-bearing slides.
- P1 format: a truncated visual-arts slide bullet appeared in a Project
  Management deck.
- P2 citations: an OpenLibrary public-metadata row shipped in the source
  ledger with ambiguous license proof.
- P2 texture: repeated case-method discussion phrasing remained in slide
  artifacts.

The same run showed a systemic CourseMapper-side root cause: the exported
Course Map and filenames used `Lesson N: Week N`, while generated artifacts
contained off-topic visual-arts language such as contour, value, composition,
and vanishing point.

## Lane

Compiler/cache/source-truth repair. This is not a model upgrade and not a
grader threshold change.

## Scope

v0.15.82 changes only bounded product behavior:

1. Treat `Week N` titles/topics as generic course-map placeholders.
2. Treat weak `Week N` course-map cells as repair-needed instead of ready.
3. Refuse lesson-kernel cache reads/writes when a lesson identity is only a
   generic numbered label or too weak to be course-specific.
4. Export metadata-only source-finder fallbacks as review notes rather than
   trusted `sourceLedger` rows.
5. Add focused regressions for the v0.15.81 Project Management failure shape.

## Release Boundary

In scope:

- Generic `Week N` Course Map readiness repair.
- Lesson-kernel cacheability guard for weak/generic lesson identities.
- Metadata-only source-finder quarantine into source review notes.
- v0.15.81 audit report anchor and focused tests.

Out of scope:

- Changing quality score thresholds.
- Hiding source review caveats.
- Claiming a clean 100/100 package before a fresh deployed v0.15.82 audit.
- Broad source retrieval architecture work.
- UI panel redesign beyond verifying the v0.15.81 amber/notes state.

## Carry Forward

- Fresh deployed v0.15.82 ZIP/log audit must verify whether generic `Week N`
  labels, stale off-topic kernels, thin slide decks, source review rows, and
  repeated texture have cleared in real provider output.
- Local-save quota warnings remain a runtime target when they reproduce in
  current-run app logs.
- If source-finder returns only review-only metadata, CourseMapper should keep
  the caveat visible and continue work on stronger source retrieval rather than
  promoting metadata into trusted proof.
