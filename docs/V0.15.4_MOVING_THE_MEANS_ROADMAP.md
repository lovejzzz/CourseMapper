## Lane 0 — FIELD FINDINGS (from a live drawing-course audit + the nightly, June 13)

_A user-submitted "drawing course" package + log, plus the nightly Deep proof
red, surfaced two concrete, evidence-backed defects. Both are PRE-EXISTING
(the gold audit fails identically at the v0.15.2 commit ac4c9bb — not a
v0.15.3 regression) and both reduce to one root: **a generic source map
produces generic, repetitive output that is still badged "ready."** These are
P0/P1 for v0.15.4 because they are the means-mover the release is named for._

### Z1. Nightly Deep proof red → fixed at the compiler source (P0)

Baseline on June 13: `npm run audit:gold` exited 1 with **37 of 40 gold samples
`blocked`, 182 blockers**. Deep proof only runs on `release/**` + nightly, and
v0.15.0–v0.15.3 shipped via `main` pushes, so the nightly went red unnoticed.

- **Repetition (120 blockers):** compiled surfaces emitted BYTE-IDENTICAL copy
  across ≥3 lessons (gate: `COPY_SPECIFICITY_MAX_REPEAT_COUNT = 2`, ≥90-char
  strings). Roots were `compileStudyGuides` review questions/practice/review
  strategy/student resources and `compileDiscussions` `equityConsiderations`;
  repeated upstream participation/metacognitive prompts also needed a
  lesson-specific wrapper.
- **Quiz Bloom/objective plan (62 blockers):** 31 direct
  `sourceGroundedQuizPlan` blockers plus 31 assessment-authenticity knock-ons.
  Registry exam/review/extension quiz entries needed the same source-grounded
  quiz-plan metadata contract as weekly quiz questions.
- **Current bar:** `npm run audit:gold` now passes **40/40** with 0 blockers and
  0 warnings, without lowering any threshold; the near-duplicate budget also
  holds after adding syllabus readiness-cue specificity.

### Z2. "Course map ready, but not" — generic skeleton graded ready (P1)

Live drawing course: a thin prompt drove native authoring Pass A to a
placeholder skeleton (every lesson "Lesson N: Week N", topic "N.1: Week N",
**0 assessments**). The degenerate-skeleton gate fired correctly
(`nativeGraphAuthoring.js:533`) and fell back to prose, which repaired 60
map fields with generic templates — but Pass B HAD authored real drawing
content into the deliverables (horizon line, vanishing point, perspective).
Net: real lessons underneath, generic "Week N" map on top, graded 98/A
"ready", and the "Week N" placeholder leaks into deliverable prose ("focuses
on Week 3, horizon line…").

- **Design choices (pick one, then bar it):** (a) after a degenerate-skeleton
  fallback, back-fill the course-map titles/topic-sections from Pass B's
  authored concepts so the map matches the deliverables; and/or (b) withhold
  the "ready" badge / surface a "generic map" honesty warning when the map is
  template-detected; and/or (c) have Pass A author real topics from a bare
  title (it demonstrably can — Pass B does). NOTE: touches the native-authoring
  flow flipped to default in v0.15.1 — must re-run the native A/B so the flip's
  bar still holds.
- **Bar:** a bare-title course (e.g. "drawing course") produces a map whose
  topics match its deliverables' real concepts, OR is honestly not badged
  ready; the native-authoring default round still meets its 100/A bar.

## Lane 1 — DEPTH TIER 2 (the same experiment, deeper surfaces)

### M1. Kernel substance inside assessments and study guides

Tier 1 put the kernel inside lesson-plan activity steps and won 3W-0L-5T.
Tier 2 extends the same placement discipline to the surfaces the judge reads
next: rubric criteria that quote the worked example's moves as the quality
bar, study-guide practice problems that re-parameterize the worked example
(same path, different numbers), and discussion graders that name the
misconception a weak post will commit.

- **Protocol (standing):** extend scripts/depthSliceAb.mjs to grade and judge
  the tier-2 featureIds — same 8 courses, same one-flag delta, judge fees
  only. The harness is the asset; reuse it.
- **Bar:** tier-2 deep wins ≥6 judged pairs with zero losses OR a ≥2-point
  margin on any course; structural and texture hold on every twin → tier 2
  joins the deep default in its own commit with the trail in the comment.
  A loss anywhere → the surface that lost is named and tier 2 ships only
  where it won.

### M2. The mandarin lane (target: 4.00 → 5+)

The judge's standing complaint on language courses is specific: "substitutes
generic scaffolding language for actual Korean content." The lang kernels
carry examples and romanization the surfaces don't fully spend.

- Audit the mandarin round artifacts against the kernel atoms (what did the
  kernel know that the lesson plan never said?), then place the unspent atoms
  — dialogue lines into the practice blocks, romanized examples into the
  guided segment, term corrections into the exit ticket.
- **Bar:** mandarin's MEAN crosses 4.5 on ≥3 post-change readings (no
  single-reading claims — the variance note owns this lane); no other
  course's mean drops by more than the noise band.

## Lane 2 — THE WHALE (diet phase 3, the budget's named remainder)

### W1. Split useDeliverables

230 KB of source in one hook — generation orchestration, compiled-lesson
sync, enrichment + extraction, voice post-hoc, image generation — all in the
workspace chunk. Extract by ownership (verbatim, the proven discipline):
the enrichment/extraction block and the voice/image post-hoc paths are the
prime movers; rare paths go lazy (the imageSearch/importCourseMap pattern).

- **Bar:** AppFlow chunk ≤248 KiB raw / ≤76 KiB gzip — the v0.15.3 ratchet
  note deletes itself; zero behavior change (battery + syncEditProof green);
  no new chunk regressions (ChatPanel/DeliverableView budgets hold).
- **Trap on the wall:** lines ≠ bytes. PROBE chunk membership (sourcemap
  census: `npx vite build --sourcemap`, read the map) before lazifying
  anything — v0.15.3 lazified two modules that were never in the chunk and
  bought only preload glue.
