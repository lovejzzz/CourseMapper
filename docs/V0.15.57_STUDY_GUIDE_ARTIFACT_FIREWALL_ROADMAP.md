# v0.15.57 Study Guide Artifact Firewall Roadmap

_Written June 26, 2026. Target app version: `0.15.57`._

## Evidence

The fresh Project Management ZIP/log audit at
`verification-output/edutool-audit-loop/20260626T140255Z/` regraded the
package at 74/100 because prompt artifact labels such as "scenario quizzes"
were treated as lesson concepts in exported Study Guides and Course FAQ-style
language. The same audit also kept source/research and texture issues visible
as follow-up work.

## Goal

Extend the artifact-label firewall from Course FAQ-only repair into Study
Guides and the shared lesson concept/artifact helpers that feed multiple
compiled surfaces.

## Lane

Study Guide compiler and shared lesson-helper truth. This release removes
unsafe prompt artifact labels from Study Guides and the shared concept,
artifact, source-cue, prerequisite, transfer, teaching-intent, and assessment
metadata helpers before export. It does not weaken the deep quality grader,
hide findings, or claim the remaining enrichment/source/texture issues are
solved.

## Changes

1. Treat prompt artifact labels, compact numbered artifact runs, and internal
   source placeholders as unsafe lesson concepts/artifacts before shared helper
   selection.
2. Sanitize lesson titles, primary concepts, student artifacts, source cues,
   prerequisite plans, transfer plans, teaching intent, and assessment metadata
   through shared safe helpers.
3. Compile Study Guides from safe concepts, artifacts, source cues, key terms,
   tags, and exam-prep lists instead of raw CourseIR labels.
4. Scrub deliverable-level source-grounding display metadata so agent/audit
   views do not repeat internal prompt artifacts or placeholder source labels.
5. Pin the live Project Management leak shape with a Study Guide regression
   while preserving the strict grader and the remaining quality targets.

## Release Boundary

In scope:

- Treat prompt artifact labels such as `scenario quizzes`, `rubric-driven
assignments`, and `final capstone presentation` as unsafe lesson concepts.
- Treat compact numbered artifact runs and internal placeholder source language
  as unsafe concept, artifact, and evidence-cue inputs.
- Fall back to lesson-specific concepts, artifacts, and source-evidence phrases
  across Study Guides and shared lesson metadata helpers.
- Scrub deliverable-level source-grounding display metadata so agent/audit
  surfaces do not repeat internal prompt artifacts.
- Pin the audited Project Management Study Guide leak with focused regression
  coverage.

Out of scope:

- Marking the 74/C package as acceptable.
- Hiding amber/blocked package state from the UI or bundled reports.
- Weakening prompt-artifact, texture, source-ledger, or enrichment grading.
- Solving partial enrichment retry/blocking, source/research bridging, or
  deterministic texture cleanup in this slice.
