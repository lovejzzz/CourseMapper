# V0.15.104 UX Review-Word Source Gate Roadmap

## Goal

Stop UX source-finder and source-ledger trust from accepting wrong-field sources just because they share the generic word `review` with concept-review or studio-review topics.

## Lane

Source retrieval, source-ledger trust, and grader truth for User Experience Design Studio packages.

## Evidence

Fresh deployed v0.15.103 ZIP/log evidence is saved at:

- `verification-output/edutool-audit-loop/20260628T164317Z-v015103-ux-fresh/report.md`
- `verification-output/edutool-audit-loop/20260628T164317Z-v015103-ux-fresh/local-regrade-current-rules.json`
- `verification-output/edutool-audit-loop/20260628T164317Z-v015103-ux-fresh/edutool.dev-current-run.log`
- `verification-output/edutool-audit-loop/20260628T164317Z-v015103-ux-fresh/package.zip`

The app and ZIP reported `99/100 (A)` with one citation P1: a clinical-methods reading was attached to a UX student reading slot. `SOURCE_REPORT.md` proved the root cause was broader than the visible citation: source-ledger rows `sf1` and `sf-3-2` were trusted concept-linked rows for UX critique concepts even though they were wrong-field review papers.

The current local regrade correctly projects the same artifact to `97/A` with three findings: two source-ledger false friends plus the visible clinical-methods reading. Texture remains `95/A`.

## Problem

The UX source gate had a topic-specific allowance for review-oriented concepts, but its source side accepted bare `review`. That allowed titles like `systematic review` and `A Review on Explainable Artificial Intelligence` to pass concept-review matching without containing UX, design, critique, studio, portfolio, or human-computer-interaction anchors.

## Release Scope

- Remove bare `review` as a UX source-topic anchor.
- Keep specific, discipline-appropriate review anchors: `design review`, `work-in-progress review`, and `portfolio review`.
- Apply the same rule to production source-ledger filtering and the deep quality grader mirror.
- Add a source-finder regression proving the health-gamification systematic review is rejected before it reaches the mini-shard cache.
- Add a source-ledger regression proving the same false friend is dropped instead of exported as trusted proof.
- Add a grader regression proving the same row scores as off-discipline if it appears in an exported package.

## Non-Goals

- Do not weaken the citation, source-ledger, or texture graders.
- Do not hide the `Quality 99`/`Texture 95` evidence from the v0.15.103 run.
- Do not claim strict-clean provider output until a fresh deployed v0.15.104 ZIP/log audit proves it.
- Do not change UI layout, provider generation strategy, or source provider breadth in this release.

## Release Boundary

Ship only the source gate and mirrored grader rule required by the v0.15.103 evidence. The remaining texture work and fresh deployed proof stay as carry-forward items.
