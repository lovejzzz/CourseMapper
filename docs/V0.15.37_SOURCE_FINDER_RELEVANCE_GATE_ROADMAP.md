# v0.15.37 Source Finder Relevance Gate Roadmap

## Evidence

The hourly EduTool.dev audit on June 20, 2026 ran against deployed v0.15.36
with the Genetics and Society prompt. The package exported successfully and
showed real progress from v0.15.35:

- ZIP evidence:
  `verification-output/edutool-audit-loop/20260620T190413Z/Genetics and Society - Course Materials (1).zip`
- Package score: `98/100 (A)`.
- Local regrade: `98/100 (A)`.
- Previous source-thinness P1: gone.
- Source ledger rows: five source rows instead of one.
- CourseIR/sourceRef coverage: `49/49`.
- SOURCE_REPORT.md shipped with concept links for source-finder rows.

The same audit exposed the next retrieval defect. Source-finder preserved rows,
but broad Crossref metadata could still attach to genetics lessons by matching
only generic words:

- `Building environment design.Indoor environment. Design process for the
visual environment.` was linked to gene-environment interaction.
- `Geotechnical investigation and testing. Testing of geotechnical structures.`
  was linked to genetic testing and privacy.

These rows are real metadata, but they are not good teaching sources for a
Genetics and Society package.

## Design

This release takes the smallest relevance slice:

1. Add a discipline-anchor gate for academic metadata providers.
2. When the course/topic context is genetics/genomics, academic metadata rows
   from OpenAlex, Crossref, and ERIC must carry a genetics/genomics anchor in
   the source title or snippet.
3. Keep the existing token-overlap and title-trap gates; this is an extra
   guard for broad terms such as `environment`, `testing`, `privacy`, and
   `risk`.
4. Do not apply this stricter gate to every provider. Wikipedia, Open Library,
   and OER/catalog fallbacks keep their existing behavior because their role is
   different and their metadata shape is less comparable.

## Lane

Narrow source-finder relevance hardening. This patch improves the quality of
retrieved evidence before source-ledger normalization. It is not the full
ResearchSession planner, not a new paid call, and not a grader relaxation.

## Non-Goals

This does not claim 100/100 quality. License ambiguity, review-only rows, and
template texture advisories must remain visible when present. This also does
not solve all disciplines; it patches the Genetics and Society failure class
proved by the fresh deployed audit.

## Release Boundary

Ship only if the focused source-finder regression passes, the full local gates
pass, the release-history audit can validate tracked proof from a clean checkout,
and browser verification confirms the app loads with v0.15.37.
