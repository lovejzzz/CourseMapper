# Composer Roadmap v0.2.2 — Cross-Discipline & Variety

_July 4, 2026. Input: the E6c queue plus one defect found while
planning this document: exposure counters are mutated in memory and
never written back — the CAT-style anti-homogenization draw has been a
no-op, and every same-syllabus composition draws identical assets._

## 1 · Exposure persistence + the homogenization index (the found defect)

- **Fix:** after composition the pipeline writes the asset store back
  (counters only — assets stay immutable per C-3). Then measure the
  index the charter promised: pairwise overlap of sampled surfaces
  (quiz stems, plan segments) across ≥3 same-syllabus compositions —
  before the fix (e6 vs e6c: expected ≈100%) and after (a fresh
  composition drawing against persisted counters).
- **Exit bar:** counters persist; index reported for both states; the
  post-fix composition overlaps <80% with e6c while holding grade ≥97.

## 2 · LA library (the scoped C6 slice)

- **Method:** extend the harvest to the three LA runs (grades 97–99:
  v012-la-verify, v016-la-replay, v017-la-replay) — $0; then a SCOPED
  math gap-fill for moves the harvest leaves empty (≤$3, disclosed as a
  slice of the full C6 build-out, which remains flagged for owner
  spend approval at $15–25).
- **Exit bar:** every math kernel on the LA graph has ≥1 asset for the
  five plan-critical moves (teach/worked/reteach/activity/guide).

## 3 · E7 — cross-discipline composition (the big unproven claim)

- **Method:** panel the Trellis LA package first (no LA panel baseline
  exists), then compose LA on the frozen v012-la-verify graph, full
  battery + 3-seat panel.
- **Exit bars:** repair ≥0.50 (Trellis LA same-graph band 0.428–0.498);
  panel ≥ the Trellis LA baseline − 0.5; cost ≤$0.10; zero seam
  objections. Misses reported with the E6 decision-rule honesty.
