# v0.15.63 Course Map Kernel Focus Roadmap

_Written June 26, 2026. Target app version: `0.15.63`._

## Evidence

The fresh deployed v0.15.62 Project Management ZIP/log audit regraded at
96/100 (A), matching the package report. Enrichment covered all 12 lessons, but
the generated Course Map could still expose generic labels such as "Session 4"
even when lesson kernels and slide content had concrete Project Management
focus terms.

That is a CourseMapper-side product issue. A stronger model may generate better
initial labels, but the compiler should not present a checked/finished Course
Map with generic placeholders after richer kernel evidence exists.

## Goal

Render CourseGraph maps with the best available lesson focus. If the graph
still has generic "Session N" or "Topic N" labels and enrichment has concrete
kernel terms, preview/export/blueprint compilation should show the concrete
lesson focus instead.

## Lane

Course Map truth and compiler substance. This release targets the unfinished
map signal discovered in the v0.15.62 audit. It does not claim a 100/100 package:
source-ledger proof, slide-deck depth, and texture variation remain open until
fresh deployed ZIP/log evidence proves otherwise.

## Changes

1. CourseGraph rendering now derives a lesson focus from enrichment kernel
   title/topic/focus fields, key terms, or slide titles.
2. Generic session titles and topic labels are replaced with that lesson focus
   during render.
3. Generic "Session N" references inside rendered Course Map cells are replaced
   when the lesson focus is known.
4. Manual Course Map overrides still render verbatim over compiler-owned
   entities.
5. A focused CourseGraph regression recreates the live "Lesson 1: Session 1"
   shape and verifies the rendered map uses Project Management concepts.

## Release Boundary

In scope:

- Repairing compiler-owned generic Course Map labels when enrichment kernels
  provide concrete lesson focus.
- Preserving manual instructor map edits.
- Pinning the behavior in CourseGraph render coverage.

Out of scope:

- Weakening source-ledger grading.
- Inventing trusted source rows.
- Claiming slide decks are fully deep when the ZIP regrade still reports thin
  decks.
- Claiming texture is clean before the texture score reaches 100.
