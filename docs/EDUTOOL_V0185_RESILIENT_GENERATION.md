# EDUTOOL v0.18.5 — Resilient, Discipline-Safe Generation

## Goal

Keep recoverable source and browser-storage limits from becoming whole-product
failures, while preserving the compiler's evidence and discipline boundaries.

## Evidence-recovery lane

A governing-source miss is not permission to publish model-provisional subject
matter. It is also not a reason to mark every material family as failed. When
the instructional plan has only `evidence-acquisition-required` blockers,
Scion now records an evidence-recovery authorization and marks the exact lesson
numbers as missing from the admitted knowledge overlay. The existing
source-review compiler path then produces inspectable recovery materials and
keeps the source decision visible.

Any other instructional-plan blocker still stops generation. The recovery path
does not weaken stale-receipt checks, unadmitted-claim checks, or post-draft
promotion requirements.

## Discipline lane

Bare “least squares” belongs to more than statistics. In the retained Linear
Algebra workspace, Orthogonal Projections included a Least Squares
Approximation section and was incorrectly given a simple-regression objective.
The regression classifier now requires an explicit regression or statistical
model identity. Linear-algebra least squares keeps the compiler's vector
projection example; explicit regression lessons keep their checked regression
specimen.

## Storage lane

Large anonymous projects can exhaust persistent browser storage. Conversation
history is optional and must not compete destructively with the course project.
If persistent conversation writes still exceed quota after compaction and
pruning, EDUTOOL stores a minimal sanitized copy in the current tab session.
It does not delete course data, and it does not repeat a production warning for
the recovered condition.

## Lane

This release changes generation admission, quantitative-operation routing, and
optional conversation persistence. It adds focused regression coverage plus
the normal formatting, lint, unit, build, bundle, release-history, and browser
smoke gates.

## Release Boundary

V0.18.5 is a locally verified predeploy candidate. It does not claim that a
source-recovery package is source-grounded or promotion-ready, does not certify
factual or instructional quality, and does not claim production deployment,
instructor approval, accessibility certification, or classroom outcomes.
