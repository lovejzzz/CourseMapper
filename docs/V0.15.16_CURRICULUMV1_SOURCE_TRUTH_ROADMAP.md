# V0.15.16 - CurriculumV1 Source Truth

## Goal

v0.15.15 made sparse native plans repair through CurriculumV1. The next gap was
healthy native plans: they still assembled to CourseGraph first and only carried
CourseIR as proof metadata afterward.

v0.15.16 makes the healthy native path move through the same source-of-truth
direction: assemble the Pass A/Pass B wire map, validate it as CourseIR, project
the compile graph from CurriculumV1, and only then render package artifacts.

## Lane

This is a native runtime architecture patch. It is still not the full one-call
provider flip.

In scope:

1. Resolve healthy native assembly through a validated CourseIR projection.
2. Preserve real instructor readings and resources through projection.
3. Keep CourseIR support notes out of the CourseGraph resource registry unless
   they came from real native source surfaces.
4. Expose healthy native CourseIR projection in run logs and package manifests.
5. Preserve stable native entity ids after course-map edits.

Out of scope:

1. No provider routing change to one dense CourseIR call.
2. No claim that edited maps fully regenerate a fresh CourseIR object yet.
3. No broad genome expansion beyond v0.15.15's research-methods shard.
4. No live EduTool.dev ZIP/log claim for this release.

## Release Boundary

v0.15.16 ships only after local proof shows the runtime seam, package manifest,
release ledger, build, bundle budget, full unit suite, constitution audit, and
40-sample gold audit are green. Remote Fast verification and Pages deploy are
claimed only after push.

## Acceptance

The release is acceptable when:

1. `resolveNativeAssembly` returns a `courseir-v1` graph for healthy native
   skeletons.
2. Degenerate sparse native skeletons still repair through CurriculumV1 before
   prose fallback.
3. Native readings survive as readings and do not duplicate into generic
   resources.
4. Native resources survive as resource registry entries, while CourseIR support
   notes do not create fake resources.
5. The run digest/log trail includes the healthy CurriculumV1 source graph
   signal.
6. `PACKAGE_MANIFEST.json` can disclose `courseIR.nativeAssembly` for healthy
   native CourseIR projection.

## Carry Forward

The full objective still requires the provider to author dense CourseIR directly
as the primary generation artifact. This release narrows the runtime gap after
native assembly; it does not yet remove the native skeleton/pass-B shape or make
edited maps regenerate a fresh CourseIR brain.
