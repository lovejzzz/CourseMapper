# V0.15.100 Assignment Texture Roadmap

## Goal

Move the latest UX provider package closer to a clean 100/100 by fixing the only scored v0.15.99 loss: repeated Assignment Brief prose texture.

## Lane

Compiler texture cleanup for assignment-brief instruction and review-protocol language.

## Evidence

Fresh deployed v0.15.99 User Experience Design Studio evidence is saved at:

- `verification-output/edutool-audit-loop/20260628T124549Z-v01599-ux-fresh/package.zip`
- `verification-output/edutool-audit-loop/20260628T124549Z-v01599-ux-fresh/edutool.dev-current-run.log`

The package regraded at 99/A with all non-texture dimensions at 100. The only finding was:

- `Texture score 89/100 indicates repeated prose patterns across deliverables`
- Evidence: `after artifact inspect critique evidence and require one named next iteration for`

## Problem

The assignment compiler accepted a generic UX review protocol and repeated it across all 12 briefs:

- `compare the before/after artifact, inspect critique evidence, and require one named next iteration...`

It also stamped fixed instruction leads for:

- reviewing materials and identifying the central problem or decision
- selecting specific evidence from readings, activities, or discussion notes
- naming one limitation, assumption, or boundary condition

That kept source truth clean but left the package sounding templated.

## Release Scope

- Detect the generic before/after critique review protocol and rewrite it into lesson-varied, artifact-specific review language.
- Rotate assignment material-review, evidence-selection, and limitation-check instructions by lesson.
- Preserve assignment identity fields, rubric criteria, source-use intent, and quality standards.
- Add a regression that recreates the 12-lesson UX design-studio failure shape and blocks the repeated shingle.

## Non-Goals

- This release does not weaken the texture grader or hide repeated language.
- This release does not change source retrieval, source-ledger filtering, citation scoring, or report/digest accounting.
- This release does not claim clean 100/100 provider output until a fresh deployed v0.15.100 ZIP/log audit proves it.

## Release Boundary

Ship only the assignment compiler texture variation and its regression. Keep any future source, UI, report-truth, or provider-quality work evidence-led.
