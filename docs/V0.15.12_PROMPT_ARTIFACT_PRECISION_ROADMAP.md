# V0.15.12 - Prompt Artifact Precision

## Goal

The 2026-06-19 EduTool audit loop generated a fresh deployed
Introductory Astronomy package after v0.15.11 reached Pages. The package showed
the important v0.15.11 fix held: requested deliverable labels did not become
Course Map topics. The Course Map topics stayed disciplinary:
sky motions, light, telescopes, solar system formation, planets, stars,
galaxies, cosmology, and final observing project.

The same package exposed a grader precision defect. A Course FAQ sentence used
"Worked examples, readings, or activity sheets" as supporting study resources.
That is a legitimate resource phrase for an astronomy course, not evidence that
requested deliverables became lesson concepts. The v0.15.11 detector still
raised a P1 prompt-artifact finding because it treated any "worked examples"
phrase near "focus on" as concept contamination.

## Lane

This is a grader precision patch, not a generation architecture change.

In scope:

1. Keep "worked examples" suspicious when it appears as a numbered lesson topic,
   such as `3.2: worked examples`, in a normal disciplinary course.
2. Stop flagging ordinary FAQ or supporting-resource sentences that tell
   students to use worked examples as practice support.
3. Preserve the P0 behavior for multi-label Course Map contamination such as
   `1.2: evidence-rich lesson plans` and `1.3: slide decks`.
4. Keep instructional-design exemptions from v0.15.11.
5. Add a regression fixture that mirrors the live Astronomy false-positive
   shape.

Out of scope:

1. No CourseIR default flip.
2. No provider-call architecture change.
3. No UI redesign.
4. No claim that the live Astronomy package is perfect; it still has normal
   low-severity report findings.

## Release Boundary

v0.15.12 ships only after the local release gates pass and the pushed commit
clears Fast verification plus GitHub Pages deploy. It does not claim a
post-fix live-provider Astronomy rerun on the deployed v0.15.12 bundle.

## Acceptance

The release is acceptable when:

1. The live Astronomy false-positive shape no longer produces a
   prompt-artifact finding.
2. The environmental-science contamination fixture still produces a P0.
3. The instructional-design course exemption still avoids false positives.
4. Release metadata, changelog, roadmap, app version, and package version all
   agree on v0.15.12.
5. Local tests, lint, build, bundle check, release-history audit, gold audit,
   and the changelog browser check pass before push.

## Carry Forward

CourseIR remains the long-term architecture for reducing provider calls while
improving coherence. v0.15.12 only tunes the shipped quality gate so the current
compiler/grader loop remains trustworthy while CourseIR waits for live
side-by-side proof.
