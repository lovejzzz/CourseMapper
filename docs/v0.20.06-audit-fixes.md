## Not done in this release

These audit recommendations need new model behavior and live Scion evaluation, which this release does not claim:

- The Scion Task Loop pipeline (grammar-constrained per-task calls, model-written solvers run in a sandbox, yes/no review votes) and the 12-input feasibility gate.
- A distilled Scion LoRA.
- EmbeddingGemma semantic ranking, Wiktionary/Wikidata providers, Scion-read passage extraction and a teacher source-review drawer.
- A manual lesson-count override on the settings screen (the corrected detector feeds both settings and generation).
- Quiz time budgets versus lesson length, issue markers beside content and progressive per-lesson generation.

No fresh Scion inference was run for this release; model weights are unchanged. Structural checks and replay metrics are software evidence, not a classroom-readiness or learning-outcome claim.
