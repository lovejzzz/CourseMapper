# V0.15.14 - Teacher-Ready Constitution

## Goal

CourseMapper needs a smaller, sharper release standard for generated package
quality. The previous 40-sample gold corpus is useful broad regression proof,
but it is too slow and too diffuse to be the default proof for every narrow
grader, report, or export patch.

v0.15.14 turns the constitutional gold-standard idea into an executable gate:
a human-readable teacher-ready package constitution, a machine-readable
contract, and five canonical fixtures that probe distinct structural risks.

## Lane

This is a release-quality architecture patch, not a provider-generation change.

In scope:

1. Define the C1-C7 obligations for teacher-ready package quality.
2. Add a machine-readable constitution contract.
3. Add three to five canonical fixture probes for high-risk package failures.
4. Add `npm run audit:constitution` as the fast deterministic release gate.
5. Keep `npm run audit:gold` as scheduled broad regression, large compiler or
   generator proof, and release-candidate hardening instead of default proof for
   every patch.

Out of scope:

1. No CourseIR default flip.
2. No live provider rerun claim.
3. No replacement for real downloaded-ZIP audits when the automation is looking
   for new defects.
4. No claim that five fixtures cover every possible course package failure.

## Release Boundary

v0.15.14 ships after local deterministic proof passes and the pushed commit
clears Fast verification plus GitHub Pages deploy. The release claims a better
default proof architecture for routine quality patches. It does not claim broad
gold-corpus coverage or deployed live-generation proof for this patch.

## Acceptance

The release is acceptable when:

1. `docs/TEACHER_READY_PACKAGE_CONSTITUTION.md` defines the teacher-ready
   obligations.
2. `quality-constitution/v1.json` names `npm run audit:constitution` as the fast
   gate and `npm run audit:gold` as broad regression.
3. The canonical fixture set contains three to five distinct structural probes.
4. `scripts/constitutionAudit.mjs` evaluates the fixtures without provider
   calls and writes JSON/Markdown reports.
5. Targeted tests prove the npm script, contract policy, fixture set, and report
   output.
6. Release metadata, changelog, roadmap, app version, package version, and
   contract all agree on v0.15.14.

## Carry Forward

The constitution should become the acceptance surface for CurriculumV1 and the
future CourseIR compiler. The compiler can be monstrous internally, but its
external promise should stay simple: every generated package must satisfy the
same C1-C7 obligations, and every exception must be explicit enough for an
instructor or auditor to trust.

Future CurriculumV1 work should connect dense model-authored course facts to
deterministic compiled artifacts, then test that compiler through the
constitution before spending provider calls. The full gold corpus still matters
for scheduled broad regression and architecture flips; the constitution is the
fast proof that a narrow patch did not violate the core teacher-ready contract.
