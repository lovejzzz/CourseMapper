# V0.15.165 Source-backed Export Truth Roadmap

## Evidence

- Fresh deployed v0.15.164 GPT-5.4-mini Python audit:
  `verification-output/edutool-audit-loop/20260630T202241Z-v015164-fresh/`.
- Visible app result was Quality 99 and Texture 95. The downloaded ZIP locally
  regraded at 99/A with 0 P0, 0 P1, and 1 P2.
- The final ZIP carried strong source proof:
  - 11 trusted OpenStax Introduction to Python Programming source rows.
  - 11/11 rows were concept-linked.
  - 239/239 CourseIR sourceRef atoms were covered.
  - 0 missing sourceRefs and 0 dangling refs.
- The scored P2 was not model writing quality. It was export truth: the final
  `PACKAGE_MANIFEST.json`, `QUALITY_REPORT.md`, and `[CM][DIGEST]` still said
  `not evaluated (0 genome-linked lessons)` after final source proof existed.

## Goal

Move source judgment from "hope the first pipeline event remains true" to
"validate final source proof, repair the judgment, then export":

- Complete trusted sourceRef proof should become an honest source-backed
  judgment when genome prerequisite judgment is unavailable.
- A stale zero-genome judgment must not beat final source-ledger proof.
- The digest, manifest, quality report, source report, and local regrade must
  read from the same final package truth.

## Lane

Export truth, source-ledger proof handoff, and quality-report agreement. This is
not a model upgrade, score inflation, source-ledger weakening, or UI redesign.

## Release Boundary

This release may claim deterministic CourseMapper-side repair for the v0.15.164
fresh ZIP/log truth mismatch. It may not claim a clean 100/100 provider result
until a fresh deployed v0.15.165 GPT-5.4-mini ZIP/log audit exists and
independently regrades clean.

## Product Diagnosis

The v0.15.164 run had the material evidence we wanted, but the evidence landed
too late for the earlier judgment surface:

1. The initial genome-linker path correctly found 0 genome-linked lessons.
2. The CourseIR/source-ledger path later produced complete OpenStax-backed
   sourceRef proof.
3. ZIP assembly bridged that source proof into trusted concept-linked rows.
4. The manifest and digest still preserved the earlier `not evaluated` line.
5. The grader treated the stale final manifest judgment as a real honesty
   caveat and correctly withheld 100/100.

That is fixable from our side. A better model might produce nicer prose, but it
does not fix a deterministic truth-surface mismatch.

## V0.15.165 Scope

- Add a shared source-backed judgment normalizer.
- Require complete sourceRef coverage plus trusted concept-linked source proof
  before replacing stale or missing judgment text.
- Use the normalized pipeline state in the live run digest and ZIP manifest.
- Count OpenStax resources in the knowledge-backbone coverage surface and
  blueprint graph path.
- Give final manifest judgment precedence over stale digest/honesty breadcrumbs
  in the deep grader.
- Add regressions for the exact Python/OpenStax stale-judgment shape.
