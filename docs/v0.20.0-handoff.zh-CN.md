# v0.20.0 收尾与交接

更新：2026-09-07。按用户额度约束收束本轮，不继续扩大工作范围。**开发版未达到 v0.20.0 发布门槛。** 当前应用版本为0.19.2，界面基线0.18.7；开发工作保存在 `codex/v0200-teaching-system`。

## 已落地

- 共同教学任务、来源绑定、教师确认、材料投影与修订历史已有实现。
- 比较设计能共享具体方案、答案、分层 rubric 和错误反馈。中文作业/rubric 栏目已改进；替代方案的导出保留完整主方案，只展示确定的差异。
- 完整任务题默认20分，沿用共同 rubric。新的比较练习呈现版本4保留六项：独立迁移、完整任务、三类错误诊断及反馈后修改。新建题目默认分值为12/20/2/2/2/0；迁移题使用自己的三个四档维度，修改练习不重复计分。分步提示保留在教学材料中。
- 已保存的分值不被默认值覆盖。版本3任务仍按原内容重建；升级经教师确认，可撤销/重做；被教师编辑的待移除题目保留并产生冲突。
- 运行时语法状态缺陷已修复为独立候选版，机械验证通过；正式应用仍选择原运行时。候选提案的 JSON 格式改善，语义定位仍有错误。失败的句子编号方案已撤回，证据保留。
