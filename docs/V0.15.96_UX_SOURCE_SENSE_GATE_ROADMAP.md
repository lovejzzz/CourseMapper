The package exported at 99/100 with no P1/P2 findings, but `SOURCE_REPORT.md` trusted two false friends as UX proof: `Mercator projection` and `Prototype (video game)`.

## Problems

1. Source relevance still treated broad words such as navigation and prototype as sufficient even when the source was in a different sense/domain.
2. `Mercator projection` is real and licensed, but map projection is not critique/design-studio source proof.
3. `Prototype (video game)` is real and licensed, but an action-adventure game page is not UX prototyping source proof.
4. The local grader needed to mirror these sense-level false-friend rules so a package cannot show 99/100 while hiding trusted citation debt.

## Release Scope

- Extend the UX false-friend gate to map-projection/Mercator source text.
- Extend the UX false-friend gate to prototype video-game source text.
- Apply the same rules in source-finder attachment, source-ledger export, and the deep quality grader.
- Add regressions using the exact v0.15.95 leak shape.

## Non-Goals

- This release does not claim 100/100 provider quality.
- This release does not change texture scoring or repeated-shingle cleanup.
- This release does not redesign source retrieval beyond the evidenced false-friend class.

## Release Boundary

Ship only the source-sense gate proven by the v0.15.95 audit evidence. Do not bundle texture, UI, or broader retrieval architecture changes into this release.
