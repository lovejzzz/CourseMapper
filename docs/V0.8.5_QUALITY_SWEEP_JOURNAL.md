# v0.8.5 Quality Sweep Journal

This journal records progress and breakthroughs made while hardening CourseMapper through full-course output testing. Entries are written as release-note source material for the v0.8.5 changelog.

## 2026-06-06

### Started the 25-course full-package quality sweep

- Set the v0.8.5 quality target around broad generated-output evidence instead of only fixing individual reports.
- Confirmed the current worktree already contains the v0.8.4 export and semantic-quality fixes from the four-course audit: semantic blockers, export/readiness alignment, non-ML asset bleed prevention, course-map repairs, cleaner XLSX headers, and DOCX bullet structure.
- Next breakthrough target: add a repeatable 25-course matrix that compiles complete packages across varied disciplines, lesson counts, and teaching modalities, then checks package text for the exact failures found in the downloaded course audits.

### Built the first headless full-package sweep gate

- Added `npm run audit:v085:sweep`, a repeatable release gate that selects unique curated course maps, compiles the full package, runs the deterministic finalizer, builds the ZIP, then parses Office exports for placeholder/internal text, speaker-note depth, FAQ coverage, required-asset markers, semantic blockers, quiz answer-pattern regressions, and DOCX list structure.
- Added a script-local `happy-dom` and canvas shim so the real PPTX exporter can be exercised in Node without changing production behavior.
- The first 2-course smoke run passed after tightening the audit harness to use production required-asset classification and exported FAQ headings instead of overly broad helper assumptions.

### Repaired export and quality issues found by full-course sweeps

- Fixed public export language so internal review tags such as local-review and source-review-required cannot leak into XLSX, CSV, PDF, or generic DOCX exports.
- Moved the repeated-copy audit from raw compiled objects to actual ZIP Office text, so warnings reflect what instructors download instead of hidden compiler metadata.
- Removed internal slide sequence guide metadata and repeated distractor-rationale boilerplate from public DOCX exports while keeping the underlying compiler evidence available in app state.
- Prioritized lesson-title concepts before broad course-level topic atoms. This removed repeated "AI pedagogy" and "community health" boilerplate and made slides, quizzes, discussions, and assignments vary by lesson focus.
- Shortened generated assignment artifact labels, review protocols, integrity text, and self-assessment checks so assignment briefs remain readable across technical, clinical, policy, economics, ethics, programming, and humanities courses.

### Final 25-course evidence

- `npm run audit:v085:sweep -- --count 25 --no-progress` passed with 25/25 courses, 0 blockers, and 0 warnings.
- The sweep covered 8-14 lesson packages across 22 modalities, including clinical simulation, clinical placement, world language, humanities, statistics, accounting/finance, policy, economics, ethics, proof seminar, programming lab, and data science lab.
- The final sweep inspected 1,828 exported files across ZIP packages, including DOCX, PPTX, XLSX, CSV/PDF-adjacent text, speaker notes, FAQ counts, required lab asset markers, and DOCX list structure.

### Closed the gold-sample copy-specificity gap

- The broader gold audit caught an issue the ZIP sweep did not: repeated multiple-choice distractors inside raw quiz-bank state, plus one repeated assignment feedback line and one chi-square inference memo classified too generically.
- The compiler now makes multiple-choice distractors role-specific, keeps final assignment milestone feedback distinct from the instructor feedback priority, and treats chi-square/categorical inference artifacts as statistical inference reports.
- `npm run audit:gold` now passes all 40 curated gold samples with 0 blockers and 0 warnings.
