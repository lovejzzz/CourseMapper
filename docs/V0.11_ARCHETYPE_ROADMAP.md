# V0.11 Roadmap — The Archetype Layer & Portfolio Layer

**Design:** `CURRICULUMOS_ARCHETYPE_LAYER_DESIGN.md`
**Predecessors:** v0.10.0 (genome + linker), v0.10.1 (activation + run digest)
**Thesis:** a professor teaching five courses holds the deep structures once;
v0.11 makes that compression a linked data layer. Cost falls because the model
writes only mappings and skins; quality rises because the compiler can render
the best-evidenced teaching move there is — structural transfer — which no
context-bound chat model can produce.

Standing rules apply to every phase: full battery locally before push
(format/lint, unit, matrix 132, `audit:deliverables`, `audit:pipeline`,
`audit:gold`, e2e, bundle budgets), run-digest verification on a live
generation when a phase changes the pipeline, refine-loop red-team suite per
phase, CCR re-judgment when student-facing output changes.

## Phase A — The archetype library + schema edge (v0.11.0)

**Build**

1. `src/lib/genome/archetypeSchema.js` — validate/normalize archetype kernels
   (id `family/slug`, abstract, slots, triggerVocabulary, misconceptionShapes
   with `{shape, template, corrective}`, reasoningMoves, taskSchemas with
   `{schema, bloom, stemTemplate, rubricFocus}`, pedagogyBindings, exemplars,
   anchors, tier). Slot-template lint: every `{slot}` referenced by a template
   must exist in `slots`.
2. **Starter set:** `scripts/foundry/sources/archetypes-genesis.json` — the
   ~24 curated archetypes from design §3 across the five families
   (systems / quantitative / epistemic / interpretive / process), each with
   2–3 misconception shapes, 2–3 task schemas, exemplar mappings into the
   genesis genome, and literature anchors (NGSS crosscutting, Shulman,
   Meyer & Land, Gentner; quote-anchored against captured source snapshots —
   the foundry `anchorCheck` applies unchanged).
3. Foundry: `buildShards.mjs` emits `public/genome/archetypes.json` (single
   global shard, hash-pinned in the manifest).
4. `kernelSchema.js`: `edges.instanceOf` — `[{archetype, confidence, mapping}]`
   with **mapping lint** (all required slots filled; slot values must share
   content words with the concept's own kernel text — course-grounded, not
   invented). Partial → `suggested`, never rendered.
5. Hand-map the genesis genome: all 6 concepts get verified `instanceOf`
   (elasticity → marginal-analysis + sensitivity; market equilibrium-adjacent
   demand curve → stock-and-flow boundary case; sampling distribution +
   p-value → sampling-and-inference; photosynthesis → gradient-driven flow /
   stock-and-flow; cell membrane → system-boundary).
6. `conceptResolver`: archetype trigger-vocabulary matching exposed as
   `resolveArchetypes(lesson, archetypeIndex)` (same lexical machinery, same
   resolved/suggested thresholds).

**Gates:** archetype schema/lint unit suite; slot-template lint red team
(missing slot, ungrounded mapping, cross-family mapping rejected without T3);
shard build + hash verification; zero behavior change with the layer unloaded.

## Phase B — Scaffolded kernel calls + template-priced misconceptions (v0.11.1)

**Build**

1. `buildLessonKernelPrompt`: when `resolveArchetypes` finds a resolved
   archetype for a lesson, inject the scaffold block (abstract + slots +
   misconception shapes + ONE task schema) into the system prompt and shrink
   the output contract: the model returns `mapping` (slot fills) + skinned
   atoms instead of from-scratch structures.
2. `kernelProjection`: misconception-shape instantiation — compiler fills
   shape templates from the returned mapping; instantiated misconceptions
   join `keyTerms[].misconception` and distractor-rationale matching.
3. Task-schema instantiation: one schema-derived MC/short-answer item per
   matched lesson, slot-filled and admission-linted like any other item
   (test-wiseness battery applies).
4. Run-digest: per-lesson `archetype:` line (which archetype, confidence,
   scaffolded or not) + kernel-call token delta vs unscaffolded baseline.

**Gates:** scaffolded-prompt unit tests (contract size, scaffold presence);
projection tests (instantiated shapes pass `lintEnrichedKeyTerm`, schema items
pass the full quiz lint); measured token-delta target on fixture prompts
(−25–40% on misconception/task atom budget); gold 40/40 unchanged
(compiled-only path untouched).

## Phase C — Analogical bridges + cross-discipline audit (v0.11.2)

**Build**

1. `src/lib/genome/archetypeBridges.js`: within a course, when ≥2 resolved
   concepts share an `instanceOf` (both tier ≥ verified or confidence ≥ 0.85),
   emit bridge objects `{archetype, fromConcept, toConcept, mappingPairs}`.
2. Rendering: study-guide "Same structure as…" block with the two mappings
   side by side; slide "watch out" reuse of the shared misconception shape;
   spiral-reference extension in `glossaryGraph`.
3. **Bridge gate (design §6):** below threshold, bridges surface ONLY as TA
   digest observations ("these may share a structure — want the comparison
   drawn?") — never in student-facing output. Red-team test enforces this.
4. Prerequisite audit extension: archetype-level findings ("this course
   teaches two instances of feedback loops without connecting them").

**Gates:** bridge-rendering red team (forced analogy never renders;
cross-family requires T3); CCR D1 re-judgment on a bridged fixture course;
substance audit unchanged or improved.

## Phase D — The Portfolio Layer (v0.11.3)

**Build**

1. `src/lib/genome/portfolio.js`: enumerate the instructor's saved projects
   (existing project storage), build a portfolio index from their local
   kernels + conceptRefs + verified mappings.
2. Portfolio resolution tier in `runGenomeLinker`: own prior-course kernels
   rank between the own-lesson cache and the public genome.
3. Portfolio bridges + glossary: cross-course spiral references ("builds on
   the sampling logic from your Methods course"); one canonical definition
   per concept portfolio-wide, divergence surfaced as a TA observation.
4. Portfolio digest panel (developer sidebar first, instructor-facing later):
   shared concepts/structures across their courses; Nth-course cost vs 1st
   from the cost ledger.
5. Privacy: portfolio index is local-only; contribution strip untouched;
   red-team test that no cross-course data enters a contribution candidate.

**Gates:** portfolio resolution tests (fingerprint vs concept-level reuse);
privacy red team; live-run digest showing portfolio hits on a second
generated course.

## Phase E — Foundry at scale: archetype tagging (v0.11.x, data run)

When the OpenStax foundry run executes (post-release operation, needs API):
a tagging pass proposes `instanceOf` mappings for every extracted concept
(batch prices, consensus-verified, mapping-linted); proposals enter as
`suggested` and ascend through instructor verification. Publish tagging
precision stats with the shard release.

## Cost & quality projections (honest expectations)

| Surface                       | Today (v0.10.1)                     | With the layer                                         |
| ----------------------------- | ----------------------------------- | ------------------------------------------------------ |
| Kernel call per missed lesson | ~1.2k out, from-scratch structures  | mappings + skins; −25–40% on misconception/task budget |
| Misconceptions                | model-written each time             | shape templates + slot fills; polish only              |
| Schema-derived items          | none                                | 1+/lesson at template price, admission-linted          |
| Transfer teaching             | absent (like every AI tool)         | deterministic bridges, gated by verification           |
| Instructor's Nth course       | same cost as 1st (minus cache hits) | portfolio resolution: fraction of 1st                  |
| Verification leverage         | per concept                         | per archetype: one fix improves thousands of concepts  |

## Risks

| Risk                                                                     | Mitigation                                                                                                       |
| ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| Forced analogies (actively harmful)                                      | mapping lint + bridge gate + cross-family T3 requirement + "no archetype" is always valid                        |
| Humanities flattened into STEM frames                                    | interpretive family is first-class; family-crossing requires instructor verification                             |
| Scaffold biases model output (echoes structure, drops discipline detail) | grounding lint unchanged: slot values must share vocabulary with kernel text; substance audit watches meta-share |
| Layer bloat (archetype proliferation)                                    | curated, capped (~300), literature-anchored; additions need anchors + exemplars in ≥3 disciplines                |
| Bundle/perf                                                              | one small global shard; archetype code rides the existing lazy genome chunk                                      |
