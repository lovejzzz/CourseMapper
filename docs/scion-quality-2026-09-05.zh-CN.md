# Scion 生成质量与管线审计

本轮保留完整 0.18.7 界面，检查实际运行代码，并用真实模型响应与实际导出文件判断问题。没有训练或发布新 adapter，也没有把基础模型改名当作训练成果。v0.19.0 仍未完成。

## 已验证的运行边界

本地 Gemma 4 E2B 在当前电脑的 Chrome 中完成下载、加载和真实推理。一次只加载一个模型，测试结束后已卸载。修复了排队取消造成后续任务永久等待、并发加载、取消返回残缺文本、上下文越界，以及输出达到上限却被记录为正常结束的问题。

本地六题教学判断测试仍出现错误：把创作时间与入藏时间视为必然冲突，对“练习是否检验迁移”的判断不可靠。温度 0 和 1 的对比没有证明提高采样温度能解决问题。一次统计课知识核心生成在约 108 秒后未通过契约检查。因此，本地运行正常与教学能力可靠是两个不同结论。

在线模式使用 Google Gemma 4 31B 基础模型，经过 Cloudflare Worker；真实响应记录模型身份、token 数与结束原因。它并不是加载了私有 adapter 的 Scion。界面默认使用本地模式，在线模式需要明确选择和浏览器数据共享许可。

Google 免费服务有用途、年龄、地区、数据使用和容量限制。在线模式面向成年专业教育工作者；不应处理学生个人数据或保密材料。参考 [Google API 条款](https://ai.google.dev/gemini-api/terms)。未开启付费模型回退，也未租用服务器。

## 实际样本

使用虚构教学数据，串行生成三份单次课工作坊草稿。每份都有 Course Map 与九类原有材料。模型请求通过同一生产在线客户端、作者契约和 Worker 代码；开发预览使用隔离的内存计数存储，因为 Cloudflare 远程预览不支持生产 SQLite Durable Object。预览最多允许六次生成，Google 自身免费限制仍然生效。

| 样本比例与抽样偏差 |            2 |      4,299 |                5,483 | 155 秒 | 核心计算关系正确；旧编译器产生残缺纠错句、错误选项解释和泛化任务 |
| 历史对象记录与证据 |            1 |      2,105 |                3,807 | 107 秒 | 区分创作与入藏日期；仍需人工检查任务与评分描述                   |
| 实验变量与因果限制 |            2 |      4,368 |                5,871 | 165 秒 | 一个题目因解释支持多个选项被拒绝；情境材料描述不足               |

这些是作者与编译器层面的集成样本，不是三次完整的首页到课程图生成验收。初始编译脚本未注入应用默认的 deep lesson-plan 配置，因此初始教案后半段仅能用作 flat 配置的观察，不能代表默认界面的 deep 教案。修复后的统计课回放已使用应用默认深度配置。

三个初始草稿均通过一个 Chrome 标签页调用生产 ZIP 导出器，实际下载 XLSX、DOCX、PPTX 和质量/清单文件。每包有十个材料文件及配套目录、清单和检查证据。导出成功不等于内容达到课堂发布标准。

## 从输出定位并修复的问题

1. 单课六条教师事实被按关键词排序缩减为五条，遗漏了“夜班人员未被抽样”。现在单课保留最多八条短事实，来源顺序、JSON 契约和引用索引范围一致。
2. 结构化纠错被拼成 `It is incorrect that the entire group...`。现在保留原主语，将片段作为明确引用呈现；重复检查不再把被否定的引用当作认可。
3. 错误选项的解释按关键词相似度拼接，结果把错误观点本身打印为理由。现在只在选项与误解精确匹配时复用对应纠正；不匹配时保留空缺。
4. 长来源事实作为幻灯片标题超过限制后，整个内容页被丢弃。现在保留事实于正文或讲者备注，使用简短标题。
5. 在线 31B 沿用小模型的最短契约，实际作业和复习内容仍大量依赖模板。现在要求在线模型直接编写具体作业、复习说明与有数字依据的计算示例，输出上限为 4,096 token；缺失必需教学字段不能作为完整结果通过。
6. 真实复测保留了全部六条统计事实，并生成 16÷20 得到 80% 的计算说明及不能外推全镇的解释。对同一真实响应进行修复后回放，三条术语和计算示例均保留，解析层无未解决条目。这个结果仅证明这份输入和响应通过了当前边界。
7. Word 视觉检查发现编译器仍把已通过的纠错句缩减为 190 字符，丢掉分母；CourseIR 另有 220 字符截断。现在编译器保留完整纠错，CourseIR 保留契约允许的 300 字符。学生指南保留最多八条核心事实，避免遗漏列表末尾的推论限制；Word 中误解和对应纠正一起分页。

已渲染并逐页检查统计课修复前后的两页学生指南，确认纠错正文完整、关键抽样限制可见且误解不与纠正分离。版面没有明显重叠或裁切，但通用“练习目标”“概念联系”等文字仍然薄弱，因此该文件仍是审核草稿。

## 额度与可用性

原 Worker 在 token 额度检查前扣每日次数，因此 token 拒绝和重试会空耗每日额度。现在先做只读预检，再原子检查并预留每日、访客、分钟和 token 额度。失败不会部分扣费；返回具体额度范围。

本次生产浏览器调用确认 `visitor-day` 已耗尽，响应提供距下次 UTC 日切的等待时间。没有重置生产计数或提高生产额度。这证明错误处理正常，但该浏览器当日不能继续在线生成。其他访客仍受共享额度约束；不能承诺所有年龄、地区与设备都有无限免费模型访问。

## 仍未完成的教育与发布验收

- 真实实验设计草稿仍有被拒绝的题目和不足的情境描述。自动回退能保住结构，不能代替一份成熟试题。
- 作业、评分标准和开放题答案仍可出现泛化的证据比较文字；独立练习与示范答案的分离尚未得到全面验证。
- 自动质量报告保留了未观察到的课程图、来源和运行判断证据。不能把手工拼装运行元数据补成真实验收记录。
- 已验证原有编辑、同步、响应式布局与下载回归；这些软件测试不证明教育有效性。
- 仍需在正常生产额度下完成完整用户生成流程，并逐种导出格式完成最终视觉检查与真实课堂复核。Google Drive 实际账户导出不属于本轮已完成的验证。

下一阶段应让共享课程图保存真正的教学活动、教师示范、独立任务、标准答案和评分依据，再让各材料读取同一份内容。应逐步替换会制造泛化正文的模板扩写路径，保留现有编辑与同步协议。扩大开放前，使用人工审核的跨学科样本检验迁移任务、来源忠实度与答题正确性；不能依赖模型自评或格式分数建立技术优势。
