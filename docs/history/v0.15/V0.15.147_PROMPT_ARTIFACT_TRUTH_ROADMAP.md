## Scope

V0.15.147 keeps the release narrow:

1. Stop the prompt-artifact detector from treating ordinary `assignments` prose near a broad `focus on` phrase as prompt-artifact leakage.
2. Keep explicit artifact-label protection for `Assignment Briefs`, `rubric-driven assignments`, numbered artifact-topic labels, and other known prompt-output labels.
3. Add an extractable separator between DOCX quiz answer callout labels and answer bodies so `ANSWER` does not glue to the answer text in grader-visible output.
4. Preserve the existing quality bar: this is a false-positive and rendering-separator fix, not a score inflation or threshold change.

## Goal

Make the quality grader distinguish real prompt-artifact leakage from legitimate UX persona-answer prose, and keep quiz answer callouts readable in both Word and local regrade extraction.

## Lane

Prompt-artifact truth, DOCX rendered-text extraction, and quality report evidence. This is not a broad source-retrieval, compiler-prompt, UI redesign, or model-selection release.

## Release Boundary
