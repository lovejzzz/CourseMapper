## Goal

Prevent assessment registry labels from becoming Course Map concepts before the
compiler, source finder, file naming, or export pipeline can treat them as
instructional topics.

## Lane

Course Map readiness repair, topic inference, graph derivation, and export truth.
This is not a model upgrade, grader weakening, or source-ledger relaxation.

## Release Boundary

This release may claim a deterministic CourseMapper-side repair for conjoined
week-labeled assessment identities. It may not claim a clean v0.15.169 package
until a fresh deployed GPT-5.4-mini ZIP/log audit proves the full provider run.

## V0.15.169 Scope

- Treat conjoined labels such as `Quiz: Week 2,Assignment: Week 2` as assessment
  identity, not a valid Course Map topic.
- Repair references to those labels in lesson titles, topic cells, objectives,
  activities, resources, and evaluate-design cells.
- Preserve the existing narrower guard for weighted assessment labels.
- Add a regression based on the exact v0.15.168 Python failure shape.

## Why This Is CourseMapper-side

A better model may avoid producing these labels, but CourseMapper already has a
readiness repair layer whose job is to reject known bad topic identities before
export. The observed failure is deterministic: the labels are recognizable and
should not be allowed to seed graph concepts, filenames, source queries, or
compiled deliverables.
