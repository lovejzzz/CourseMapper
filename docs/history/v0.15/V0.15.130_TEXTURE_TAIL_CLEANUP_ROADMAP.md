## Goal

Remove the next strict-clean texture gap after a fresh UX Studio package reached
overall `100/100` with clean source proof but still measured `Texture 95/100`.

- Remaining strict-clean gap: Texture 95/100

## Diagnosed Texture Loss

The v0.15.129 package was structurally clean, but the texture metric still found repeated compiler tails across all 12 lessons:

- Rubrics repeated variants of `audience language makes the user evidence harder to follow`.
- Lesson-plan/feedback surfaces repeated `criterion-level feedback that names the strongest evidence move, the weakest reasoning link`.
- Slide decks repeated the studio-lab signature phrase `critique a visible prototype or design artifact, then revise one concrete element`.

These are CourseMapper-side deterministic template repetitions, not provider outages and not a reason to weaken the grader.

## Lane

1. Rotate criterion-feedback tails
   - Keep criterion-level feedback visible.
   - Stop stamping the exact strongest-evidence/weakest-reasoning sentence into
     every lesson.

2. Rotate studio-lab signature practice
   - Keep visible artifact critique and prototype revision as the studio
     practice pattern.
   - Make the phrasing lesson-specific before slide decks consume it.

3. Rotate rubric professional-communication bands
   - Keep the organization, audience, and evidence-path standard.
   - Vary the developing-band language so every rubric does not share the same
     long sentence tail.

4. Regression proof
   - Assert the exact v0.15.129 shingles stay out of compiler texture evidence.

## Fix

V0.15.130 keeps the same instructional intent while rotating the high-repetition template tails:

- `buildFeedbackCycle` now varies criterion-level feedback language by lesson.
- `contextualizeModalityRoutine` now rewrites the studio-lab signature practice into lesson-specific critique/prototype revision moves.
- `buildCriterionPerformanceBand` now varies the professional-communication developing band so rubric language does not stamp the same organization/audience/evidence-path sentence into every rubric.
- Compiler texture regressions assert the exact v0.15.129 shingles stay out of future texture evidence.

## Release Boundary

  texture advisories.
