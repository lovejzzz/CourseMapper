# V0.15.163 Assessment Identity Repair Roadmap

## Evidence

- Fresh deployed v0.15.162 GPT-5.4-mini Python audit:
  `verification-output/edutool-audit-loop/20260630T181200Z-v015162-gpt54mini-fresh/`.
- Visible app result was Quality 98, Texture 92. The downloaded ZIP locally
  regraded stricter at 97/A with Texture 90.
- The scored P1 was identity contamination: assessment labels and grading
  weights such as `Evidence check: Introduction to Computer Science with
Python (7%)` became lesson identities, file stems, Course Map topics, and
  source concept links.
- Download capture succeeded because a new ZIP appeared in Downloads, although
  the browser download event still timed out. That is an automation observation,
  not the product quality finding for this slice.

## Goal

Prevent assessment-registry labels and grading weights from becoming lesson,
topic, concept, source-link, or filename identities before Course Map export.

## Lane

Course Map readiness repair and compiler identity hygiene. This is not a source
ledger trust expansion, grader-threshold change, provider-model change, or UI
redesign.

## Release Boundary

This release may claim deterministic repair for the known assessment-label
identity shape found in the v0.15.162 ZIP/log evidence. It may not claim a clean
100/100 provider result until a fresh deployed v0.15.163 ZIP/log audit exists
and independently regrades clean.

## Product Diagnosis

V0.15.162 removed generic weekly-assessment scaffolds, but the repair path still
had a topic-selection gap. When every available topic candidate was an
assessment label with a percentage weight, CourseMapper could reuse that label
instead of falling back to a real course topic. The result was honest grading
but bad export quality: the same assessment identity appeared in filenames,
Course Map cells, and source concept links.

## V0.15.163 Scope

- Treat assessment labels with grade weights as weak Course Map topics.
- Prefer domain progression fallback over the bare course title when the real
  topic candidates are weak.
- Add a 15-lesson Computer Science/Python progression fallback so repaired maps
  land on concrete programming concepts.
- Repair embedded assessment-label identities inside complete-looking Course
  Map cells before graph/export derivation.
- Add a regression fixture with the exact GPT-5.4-mini failure shape and assert
  repaired Course Map cells plus derived graph identities contain no label or
  `(7%)` leakage.
