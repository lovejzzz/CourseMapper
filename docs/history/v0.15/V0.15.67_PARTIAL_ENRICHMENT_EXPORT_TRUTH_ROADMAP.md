# v0.15.67 Partial Enrichment Export Truth Roadmap

_Written June 26, 2026. Target app version: `0.15.67`._

## Evidence

A fresh deployed v0.15.66 Project Management ZIP/log audit completed at
`verification-output/edutool-audit-loop/20260626T235926Z/`.

The source bridge improved materially: the exported source ledger contained
seven concept-linked rows, including three trusted concept-linked rows. The
package still regraded `97/100 (A)` with texture `90`, and the digest reported
`finalStatus=blocked` because enrichment covered only 11 of 12 lessons:
lesson 3 fell back to template.

The package manifest contradicted that digest truth:

- `pipeline.enrichment`: `ran (11/12 — lesson 3 fell back to template)`
- browser digest: `finalStatus=blocked`, one blocker
- `PACKAGE_MANIFEST.json readiness`: `ready`, `blockers: 0`

That is a CourseMapper export-truth bug, not an AI-model issue.

## Goal

Downloaded ZIPs must preserve partial-enrichment blockers in the durable package
evidence. If pipeline evidence says enrichment fell back to template for any
lesson, the exported package must include:

- a blocked readiness status,
- a blocker count,
- a `READINESS_REPORT.txt` repair message,
- and a manifest that matches the browser digest instead of claiming clean
  readiness.

## Lane

Package export/report truth. This release does not change model prompting or
weaken the grader; it prevents a known caveat from disappearing once the ZIP is
downloaded.

## Changes

1. ZIP assembly parses partial-enrichment pipeline evidence before package files
   and reports are written.
2. The partial-enrichment blocker is merged into effective readiness before
   `READINESS_REPORT.txt` and `PACKAGE_MANIFEST.json` are generated.
3. Existing export readiness remains intact for structural exportability, but
   clean manifest claims now require full enrichment coverage.
4. A focused package-export regression recreates the live `11/12` shape and
   proves the manifest/report preserve the blocker.

## Release Boundary

In scope:

- Fix manifest/report truth for partial enrichment.
- Keep the clear retry/repair message in downloaded artifacts.
- Preserve v0.15.66 trusted concept-linked source accounting.

Out of scope:

- Claiming v0.15.67 packages are 100/100 before a fresh deployed ZIP/log audit.
- Changing source-provider ranking or license trust rules.
- Fully repairing texture, slide echo chains, or model-side enrichment misses.
