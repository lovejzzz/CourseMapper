# v0.15.62 Source License Trust Gate Roadmap

_Written June 26, 2026. Target app version: `0.15.62`._

## Evidence

The latest completed Project Management ZIP/log audit regraded at 98/100 (A).
The remaining citation loss included source-ledger rows whose license fields
were public metadata labels rather than explicit reuse rights, such as Crossref
or Open Library public metadata.

That is a CourseMapper-side source trust issue. A metadata record can help find
a reading, but it should not become a trusted reusable course source unless the
license is clear.

## Goal

Prevent metadata-only source records from being promoted into trusted course
resources or source-ledger rows. When retrieval finds relevant but
license-ambiguous sources, CourseMapper should record the gap and keep looking
for clearer proof instead of exporting weak proof as done.

## Lane

Source/research bridge. This release targets the source-license part of the
98/100 quality loss. It does not claim a clean 100/100 package until a fresh
deployed EduTool ZIP/log audit proves the generated package has no source,
texture, export, retry, or fallback caveats.

## Changes

1. Source-finder ranking now orders explicit reusable-license sources ahead of
   metadata-only academic hits even when the metadata-only hit has stronger
   provider prestige or topical score.
2. Open reading attachment now refuses to attach relevant readings when every
   candidate has an ambiguous public-metadata license.
3. Reading-list decisions now record `no-reusable-license-reading` when a
   relevant candidate is rejected for metadata-only licensing.
4. Source-ledger and quality-check license ambiguity rules now classify provider
   public-metadata labels consistently.
5. Focused regressions cover source-finder ranking and reading attachment
   without weakening source quality thresholds.

## Release Boundary

In scope:

- Rejecting metadata-only retrieved readings as trusted reusable resources.
- Ranking explicit reusable-license sources ahead of ambiguous metadata hits.
- Aligning product and grader ambiguity classification.

Out of scope:

- Inventing licenses for metadata-only sources.
- Hiding source-ledger caveats in reports.
- Repairing native skeleton fallback.
- Claiming 100/100 without fresh deployed ZIP/log evidence.
