# V0.15.22 - EduTool Audit Tightening

## Goal

The 2026-06-19 EduTool.dev audit produced a complete, export-verified
Introduction to Psychology package at 99/A, but the actual Course Map workbook
showed two curriculum-brain defects:

1. The mixed lecture/lab format became content sections (`lecture`, `lab`).
2. The run reported `0/4` genome-linked lessons even though the repo has
   anchored kernels for the course's broad psychology and research-ethics
   topics.

v0.15.22 fixes the compiler/data path that caused those misses. The target is
not a sweeping claim that CurriculumV1 is done. The target is narrower and
evidence-bound: the exact audited failure mode must not recur.

## Lane

This is an EduTool artifact-audit tightening slice. It touches native Pass A
section hygiene, genome foundry data, shard inference, and focused regression
coverage. It does not change provider-call routing, direct CourseIR
architecture, package export formats, or the grading constitution.

The local audit evidence lives under:

`verification-output/edutool-audit-loop/20260619T223120Z/`

That directory remains ignored by git because it contains ZIP/log artifacts.
The committed release evidence is the code, data source, generated genome
manifest, focused tests, and this roadmap.

## Fix

Native skeleton authoring now states that `sectionTitles` are subject-matter
subtopics only. The parser also enforces that contract by dropping titles that
are only delivery modes, including lecture, lab, laboratory, workshop,
discussion, seminar, recitation, activity, and practice.

The psychology foundry source gains conservative aliases for broad audited
topics:

- `learning` links to existing learning kernels.
- `memory` links to existing memory kernels.
- `cognitive bias` links to the existing problem-solving/heuristics kernel.

The research-methods shard is restored as a real foundry source and therefore
re-enters `public/genome/manifest.json` with the same hash-pinned path as the
other shipped shards. `research ethics`, `human subjects`, and participant
protection wording now infer the research-methods discipline.

## Why This Matters

The package was usable, but it was not yet the better curriculum brain we want.
A course generator can look polished while still letting prompt format words
become subject matter, or while hiding an available source-anchored genome
behind a missing manifest entry.

This release moves quality in the right place: before DOCX/PPTX/XLSX export,
inside the parser and genome loader that decide what counts as curriculum
structure.

## Release Boundary

v0.15.22 ships only after focused native-authoring and genome-coverage
regressions, full unit suite, format, lint, build, bundle check, browser
verification, constitution smoke, gold smoke, and release-history audit. Remote
Fast verification and Pages deploy are claimed only after push.

## Acceptance

This slice is acceptable when:

1. Pass A prompt text forbids modality-only section titles.
2. The skeleton parser drops modality-only section titles before wire-map
   assembly.
3. The exact audited Intro Psychology topic mix infers both psychology and
   research-methods.
4. The same topic mix links at least four source-anchored genome concepts
   instead of reporting a 0/4 genome-link run.
5. The research-methods shard is produced by `npm run genome:build` and listed
   in `public/genome/manifest.json`.

## Carry Forward

The next quality step is to make the curriculum brain more explicit, not just
better matched:

1. Continue moving direct CourseIR authoring toward one validated whole-course
   object when the selected model has enough context and output budget.
2. Add first-class citations and feedback loops as CourseIR atoms.
3. Expand genome shards for high-frequency audit subjects, but keep aliases
   conservative and foundry-owned.
4. Add a small committed fixture that represents the constitutional standard,
   while keeping full `audit:gold` for broad scheduled regression rather than
   every narrow release.
