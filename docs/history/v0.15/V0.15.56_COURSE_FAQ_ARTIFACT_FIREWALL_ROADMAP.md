# v0.15.56 Course FAQ Artifact Firewall Roadmap

_Written June 26, 2026. Target app version: `0.15.56`._

## Goal

Patch the highest-evidence product defect from the fresh deployed v0.15.55
Project Management ZIP/log audit. The package regraded 74/C with a P0 because
compact prompt/assessment artifact runs and internal source placeholders reached
student-facing generated language.

## Lane

Course FAQ compiler and export-repair truth. This release removes unsafe prompt
labels from Course FAQ output before export and fixes a deterministic FAQ repair
punctuation defect. It does not weaken the deep quality grader, hide findings,
or claim the remaining partial-enrichment/study-guide issues are solved.

## Release Boundary

In scope:

- Treat compact numbered assessment/artifact runs as unsafe Course FAQ phrases.
- Treat internal placeholder source language such as `Instructor-approved
readings...` as unsafe source evidence.
- Fall back to lesson-specific assessment and source-evidence phrases instead
  of exporting those labels.
- Strip terminal punctuation before fallback FAQ repair joins an objective into
  a new sentence.
- Pin both failures with focused regression coverage.

Out of scope:

- Marking the 74/C package as acceptable.
- Hiding the amber/blocked package state from the UI or report.
- Weakening prompt-artifact, texture, source-ledger, or enrichment grading.
- Solving the remaining partial-enrichment fallback and study-guide leakage in
  this slice.
