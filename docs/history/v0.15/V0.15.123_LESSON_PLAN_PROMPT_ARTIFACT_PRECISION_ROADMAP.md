# V0.15.123 Lesson Plan Prompt-Artifact Precision Roadmap

## Goal

Remove the remaining lesson-plan prompt-artifact P1 exposed by the fresh
deployed v0.15.122 User Experience Design Studio ZIP/log audit without
weakening true prompt-artifact findings.

## Evidence

- App version: `0.15.122`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T084552Z-v015122-ux-fresh`
- Visible package result: `Quality 98`, `Texture 94`
- Embedded and local current-rule regrade finding:
  `prompt artifact labels used as lesson concepts`
- Evidence excerpt:
  `Teams take a position on the lesson's live question — “Should usability testing focus more on realistic tasks or on isolated interface elements” — and defend it with evidence about Usability testing.`
- Digest truth was otherwise clean: 12 lessons, 12 enriched, export passed,
  0 retries, 0 export warnings, citations `100/100`, and five trusted,
  licensed, concept-linked source rows.

## Diagnosis

The selected evidence line was partly a detector precision issue: the DOCX text
contained a distant `LESSON PLANS` header and a later discussion question with
the word `focus`, which let the prompt-artifact scanner combine unrelated
signals.

The exported lesson plan also contained real artifact-label prose debt around
the same lesson, including `Discussion prompts: Usability testing` references
inside instructor notes and assessment-facing copy. Those labels should become
natural course-work references before export.

## Lane

1. Lesson-plan artifact reference cleanup
   - Treat colon-labeled prompt artifacts such as `Discussion prompts: X`,
     `Quiz: X`, and `Assignment Briefs: X` as unsafe lesson-plan prose
     references.
   - Replace them with natural weekly artifact references before modality and
     lesson-plan text reach DOCX export.

2. Stale modality cleanup
   - Apply the same replacement to modality-decode text so stale generated
     strings cannot say `Discussion prompts: X evidence about X`.

3. Detector precision
   - Keep numbered prompt-artifact findings strict.
   - For focus/check findings, require the prompt-artifact label to be near the
     focus/check cue so a document title/header cannot combine with an unrelated
     later sentence.
