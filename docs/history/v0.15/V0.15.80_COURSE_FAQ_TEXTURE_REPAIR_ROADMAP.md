# v0.15.80 Course FAQ Texture Repair Roadmap

## Goal

Reduce the real v0.15.79 Course FAQ texture loss by repairing repeated
support-answer scaffolds before export while keeping the quality grader strict
and the release claim evidence-bounded.

## Evidence

A fresh deployed v0.15.79 Project Management audit completed on June 27, 2026
and saved artifacts under:

`verification-output/edutool-audit-loop/20260627T093324Z-v01579-fresh/`

The exported package reported `99/100 (A)` with the only scored finding in
texture: Course FAQ support answers repeated the same checklist and prepared
response scaffolds across lessons. The current-run local regrade also flagged a
separate `QuotaExceededError` from browser state persistence, so this release
does not claim the package is clean.

Representative repeated Course FAQ answer shingles from the audit:

- `A prepared response names the relevant ...`
- `concrete piece of lesson evidence`
- `class, office hours, or a study group`
- `as a checklist`

## Problem

The prior Course FAQ variety repair caught exact duplicate questions and one
old exact boilerplate answer shape. The v0.15.79 artifact showed a more subtle
failure: questions differed, lesson labels differed, and assessment labels
differed, but the answer scaffolds still shared the same high-frequency
phrases. The texture grader correctly kept the package below 100.

## Lane

Course FAQ post-processing texture repair. This is a deterministic output
quality slice for repeated support answers, not a grader threshold change and
not a broader provider-generation architecture change.

## Fix

v0.15.80 keeps the grader standards unchanged and repairs the product output:

1. Detect repeated Course FAQ support-answer shingles even when exact answer
   text differs.
2. Rewrite those answers with deterministic lesson/topic/assessment-specific
   templates.
3. Preserve the existing lesson context in repaired answers so student-facing
   guidance remains concrete.
4. Add a focused regression for the v0.15.79 failure shape.

## Release Boundary

In scope:

- Course FAQ repeated-answer shingle detection.
- Deterministic repair templates for Assessment Prep, Course Logistics,
  Assignment Clarification, Concept Explanation, and Technical Help.
- Focused post-processing regression for the v0.15.79 artifact shape.
- Release metadata for the v0.15.80 product-quality patch.

Out of scope:

- Changing quality score thresholds or hiding the texture finding.
- Fixing browser local-storage quota handling.
- Claiming source, enrichment, export, or UI readiness improvements beyond the
  FAQ texture repair.
- Running another provider generation before v0.15.80 is deployed.
