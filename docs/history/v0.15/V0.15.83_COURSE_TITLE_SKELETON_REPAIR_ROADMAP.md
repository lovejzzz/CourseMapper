# v0.15.83 Course Title Skeleton Repair Roadmap

## Goal

Stop repeated course-title-only Course Maps from looking complete when the
exported lessons and topic cells still say only `Project Management`.

## Evidence

A fresh deployed v0.15.82 Project Management audit completed on June 27, 2026
and saved evidence under:

`verification-output/edutool-audit-loop/20260627T122717Z-v01582-fresh`

The exported package regraded locally at `99/100 (A)` with one P2 finding:

- P2 texture: repeated prose patterns across Lesson Plans, Slide Decks, and
  Quiz Bank artifacts. The top repeated shingle was
  `accessibility source permissions and grading policy before publishing...`.

The same audit verified that the v0.15.82 fixes mostly worked:

- No `Lesson N: Week N` Course Map labels.
- No `Session N` or `Topic N` labels.
- No stale visual-arts kernels in Project Management output.
- No metadata-only trusted source-ledger rows.
- No current-run `QuotaExceededError` or local-save warning.

The remaining systemic CourseMapper-side defect was a complete-looking but weak
Course Map: all 12 exported lesson titles and all 12 topic cells collapsed to
`Project Management`.

## Lane

Course Map readiness and deterministic text repair. This is not a model upgrade
and not a grader threshold change.

## Scope

v0.15.83 changes only bounded product behavior:

1. Treat repeated course-title-only lesson titles and topic cells as weak
   skeletons when a multi-lesson map repeats them across the course.
2. Repair Project Management skeletons from concrete assessment anchors when
   present, such as `project charter` and `scheduling lab`.
3. Use a Project Management progression fallback when no concrete assessment
   anchor exists.
4. Prevent sentence-shaped support fields from being reused as Course Map topic
   candidates.
5. Replace generic Project Management fallback prose with project-specific
   stakeholder, constraint, artifact, and decision language.

## Release Boundary

In scope:

- Repeated course-title-only Course Map repair.
- Project Management fallback progression and copy variety.
- Focused readiness and finalizer regressions.
- Fresh v0.15.82 ZIP/log evidence report.

Out of scope:

- Changing quality score thresholds.
- Hiding texture findings.
- Broad source retrieval architecture work.
- Claiming a clean 100/100 package before a fresh deployed v0.15.83 audit.
- Full UI panel redesign beyond preserving the amber/review-with-notes state.

## Carry Forward

- Fresh deployed v0.15.83 ZIP/log audit must verify whether Course Map lesson
  titles, topic cells, filenames, and downstream deliverables now carry
  concrete Project Management topics.
- Texture remains the next scored target if the package still regrades below
  100/100.
- If local-save quota warnings reappear in current-run app logs, treat that as
  a separate runtime cleanup target.
