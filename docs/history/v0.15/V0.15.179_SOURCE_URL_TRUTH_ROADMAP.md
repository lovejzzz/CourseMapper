# V0.15.179 Source URL Truth Roadmap

## Evidence

- Fresh deployed v0.15.178 GPT-5.4-mini UX ZIP/log evidence:
  `verification-output/edutool-audit-loop/20260701T071819Z-v015178-ux-fresh/`.
- Visible UI, `QUALITY_REPORT.md`, `PACKAGE_MANIFEST.json`, console digest, and local deep
  regrade agreed on `100/100 A` with `Texture 95` and zero P0/P1/P2 findings.
- The same package's trusted `sourceLedger` and `SOURCE_REPORT.md` included two Persona rows:
  a valid source-finder row for `https://en.wikipedia.org/wiki/Persona_(user_experience)` and a
  syllabus-derived duplicate with a malformed URL missing the closing parenthesis.
- The malformed syllabus row still counted as trusted, accessible, concept-linked proof, so the
  source ledger could look cleaner than the actual exported citation evidence.

## Goal

Keep clean-package claims tied to source proof that is actually usable. Parenthesized source URLs
must stay intact, duplicate syllabus/source-finder rows should collapse to the stronger trusted row,
and malformed trusted URLs must fail the local quality grader instead of inflating citation proof.

## Lane

Product/source-ledger and grader truth repair. This is not a model upgrade, source-standard
weakening, or score inflation release.

## Release Boundary

This release may claim that:

- URL extraction preserves balanced parenthesized links such as Wikipedia article URLs;
- surplus punctuation around prose or markdown links is still trimmed safely;
- malformed trusted source URLs become P2 citation findings in the deep quality grader;
- a syllabus reading that duplicates a valid source-finder row dedupes against that row instead of
  adding broken trusted proof.

It may not claim a fresh deployed v0.15.179 clean package until a new ZIP/log audit proves the UI,
ZIP, manifest, quality report, source report, digest, and local regrade agree.

## V0.15.179 Scope

- Update source URL extraction so balanced parentheses inside URLs are retained.
- Keep trimming surplus trailing punctuation and wrapper parentheses.
- Add deep-quality malformed URL detection for trusted `sourceLedger` rows.
- Add a ZIP-export regression using the exact UX Persona/Wikipedia failure shape.
- Add a grader regression proving broken trusted URL proof is a P2 citation finding.

## Why This Is CourseMapper-side

A stronger model can choose better sources, but it cannot guarantee that our export parser preserves
each URL correctly or that duplicate source surfaces stay canonical. CourseMapper owns the source
ledger contract and the local grader must catch broken trusted proof regardless of model choice.
