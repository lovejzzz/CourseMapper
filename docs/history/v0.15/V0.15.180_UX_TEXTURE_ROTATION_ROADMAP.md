# V0.15.180 UX Texture Rotation Roadmap

## Evidence

- Fresh deployed v0.15.179 GPT-5.4-mini UX ZIP/log evidence:
  `verification-output/edutool-audit-loop/20260701T075806Z-v015179-ux-fresh/`.
- Visible UI, `PACKAGE_MANIFEST.json`, `QUALITY_REPORT.md`, console digest, and local deep
  regrade agreed on `100/100 A` with zero P0/P1/P2 findings.
- Source truth held in the same package: trusted `sourceLedger` rows were URL-backed, licensed,
  concept-linked, on-topic, and the parenthesized Persona URL stayed intact.
- The direct Office text scan still showed texture debt even though it was not a scored finding:
  repeated Course FAQ feedback questions, repeated discussion preference language, and repeated UX
  Course Map technology/presentation stems.

## Goal

Move repeated UX support copy from "acceptable but stamped" to deterministic variation before
export. The model can still write uneven prose, but CourseMapper should not add repeated scaffolds
through its own fallback and compiler templates.

## Lane

Product/compiler texture repair. This is not a source-standard change, grader weakening, or score
inflation release.

## Release Boundary

This release may claim that:

- sparse Course Map fallback repair keeps section position even after a section object is cloned;
- UX technology and presentation fallback cells rotate through enough stems for a 12-week,
  three-section course;
- Course FAQ feedback questions vary by lesson instead of repeating one exact question;
- discussion instructor-preference notes preserve the preference but vary by lesson/artifact.

It may not claim a fresh deployed v0.15.180 provider score until a new ZIP/log audit proves the
deployed output.

## V0.15.180 Scope

- Fix fallback section-index inference in `deliverableReadiness`.
- Expand UX Course Map fallback technology and presentation pools.
- Vary Course FAQ feedback question wording by lesson.
- Vary discussion instructor-preference wording by lesson, artifact, and concept.
- Add regressions for the exact repetition classes found in the v0.15.179 Office text scan.

## Why This Is CourseMapper-side

GPT-5.4-mini produced a clean package, but these repeated strings came from CourseMapper compiler
and fallback templates. A stronger model is not the right fix for deterministic copy that our code
stamps into exported materials.
