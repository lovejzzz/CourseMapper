## Scope

V0.15.148 keeps the release narrow:

1. Teach OpenAI pro reasoning model profiles that their supported effort levels start at `medium`.
2. Normalize task-level or plan-level reasoning levels to the minimum supported tier before building a provider request.
3. Preserve the existing low-effort behavior for compatible GPT-5 mini-style models.
4. Keep partial-enrichment readiness blockers blocked in the exported manifest after package quality warnings are merged.
5. Document that the GPT-5.5-pro artifact is not a fair model-quality benchmark until the request-compatibility bug is deployed and retested.

## Goal

Make the model comparison valid by removing a CourseMapper-side request configuration failure, and make the exported manifest agree with the digest and readiness report when the package is blocked.

## Lane

Provider request compatibility and export/report truth. This is not a grader-threshold change, score inflation, source-trust broadening, or UI redesign.

## Release Boundary

The release may claim the pro-model reasoning clamp and manifest readiness merge fix after focused regressions and normal gates pass. It may not claim GPT-5.5-pro is better or worse than another model until a fresh deployed v0.15.148 run completes without unsupported-reasoning API errors.

## Verification Target

Ship only after the pro-model request-builder regression, graded partial-enrichment manifest regression, normal release gates, and release-history audit pass. The next evidence step is a fresh deployed v0.15.148 GPT-5.5-pro ZIP/log audit using the same course shape so model quality can be compared without request-configuration noise.
