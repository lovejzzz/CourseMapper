# v0.15.29 Source Ledger Fallback Guard Roadmap

## Goal

Keep downloaded source reports trustworthy by filtering Course Map / syllabus
fallback rows before they become source-ledger proof. Real source-like fallback
rows should still export; package labels and placeholder resource sentences
should not.

## Lane

Package export proof, source provenance normalization, and grader truthfulness.
This lane repairs fallback source-ledger pollution without changing provider
routing, model-call counts, or the broader ResearchSession planner.

## Why This Exists

A fresh deployed v0.15.28 EduTool.dev Sociology package proved that the prior
source-proof export fix shipped: the downloaded ZIP included `SOURCE_REPORT.md`,
`sourceLedger`, and `sourceLedgerSummary`. The new failure was narrower but
serious: the fallback ledger treated package labels and generic course-material
placeholders as source rows.

Audit evidence:

- Run: `run-1781946349989`, generated on deployed v0.15.28.
- ZIP: `verification-output/edutool-audit-loop/20260620T090410Z/Introduction to Sociology - Course Materials (4).zip`.
- Local regrade: 90/A, citations 22/F, 27 P2 findings.
- Source rows included `course map`, `syllabus`, `lesson plans`, `slide decks`,
  `assignment briefs`, `rubrics`, `discussion prompts`, `quiz and exam bank`,
  `study guides`, `course FAQ`, and generic placeholder resource sentences.

That is not a trusted source ledger. It is polluted proof. CourseMapper should
export real receipts, or honestly say the source-backed pipeline lacks source
proof.

## Release Boundary

This is a narrow source-ledger fallback/export truth patch. It does not add new
retrieval providers, fabricate source rows from console digest text, or complete
semantic source entailment. It makes the existing source-proof surface stricter
and less noisy.

## Slice

1. Add a source-candidate guard before CourseGraph resource rows become
   normalized source-ledger rows.
2. Treat generic `course-map`, `course-resource`, `resource`, and `syllabus`
   origins/providers as fallback candidates only.
3. Reject package-label rows and placeholder resource sentences before
   normalization.
4. Preserve real source-like rows that carry a provider hint, URL, DOI,
   license, or recognizable academic/OER source signal.
5. Keep non-generic providers such as genome, OpenStax, OpenAlex, Open Library,
   ERIC, source-finder, and instructor rows on the normal ledger path.

## Non-Goals

- Do not weaken source-ledger grader checks.
- Do not lower the 100/100 quality target.
- Do not fabricate source rows from the pipeline digest.
- Do not claim source grounding when the package still lacks real source proof.

- The audited fake fallback rows cannot appear in `sourceLedger` or
  `SOURCE_REPORT.md`.
- Embedded OpenStax-like Course Map source text still exports as source proof.
- Source-backed packages with no real source rows remain honest and trigger
  missing-proof checks instead of noisy fake citation rows.
- Fast verification and GitHub Pages deploy pass after push.
