# V0.15.144 Internal Export Language and ZIP Truth Roadmap

## Goal

Use the fresh v0.15.143 blocked provider evidence to remove internal source-grounding language from public export paths and keep ZIP actions aligned with export verification truth.

## Evidence

A fresh deployed v0.15.143 User Experience Design Studio provider run completed the generation and finish pass, but it did not produce a downloadable package:

- appVersion: 0.15.143
- runId: run-1782786432050
- finishRunId: finish-mr014v92-uc77b
- finalStatus: blocked
- export verification: failed, 1 of 38 checks failed
- quality: not graded because export verification failed
- ZIP capture: no new ZIP appeared in Downloads after Chrome-extension and visible button attempts

The failing exported surface was Quiz Bank DOCX XML. The export verifier blocked the package because `word/document.xml` exposed the internal phrase `source grounding`.

## Lane

This is a narrow export-truth and UI-truth lane. It does not change source trust thresholds, quality scoring, texture scoring, provider selection, or export verification strictness.

## Fix

V0.15.144 keeps the slice narrow:

1. Quiz Bank essay scoring guidance now uses instructor-facing `course evidence` language instead of internal `source grounding` wording.
2. The adaptive fallback policy now refers to `source evidence checks` instead of internal source-grounding terminology.
3. Export-failed receipts now become shared trust-model blocker issues, with the failing material label surfaced in the export panel.
4. The Package ZIP button disables and reads `Needs attention` when the receipt says export verification failed.
5. The workspace header primary CTA uses the same trust model, so it cannot offer `Download ZIP` while the package receipt is export-failed.

## Non-Goals

This release does not claim a clean provider package. The v0.15.143 run blocked before ZIP export, so no PACKAGE_MANIFEST, SOURCE_REPORT, QUALITY_REPORT, or local deep regrade could prove the full package quality.

## Next Audit

Run a fresh deployed v0.15.144 ZIP/log audit. The audit should prove:

- Quiz Bank DOCX no longer exposes `source grounding`.
- Export verification passes and a ZIP is created.
- UI, digest, manifest, quality report, source report, and local regrade agree.
- Source rows are real, trusted, on-topic, license-safe, and concept-linked.
- Texture reaches 100 or records the exact remaining repeated-shingle family.

Ship only after focused regressions and normal release gates pass. Do not claim strict-clean provider output until a fresh deployed v0.15.144 package proves it.

## Release Boundary

Ship only after focused regressions and normal release gates pass. This release may claim the internal-language cleanup and export-failed ZIP guard, but it must not claim clean v0.15.144 provider output until a fresh deployed v0.15.144 ZIP/log audit proves export, reports, source truth, texture, UI, digest, and local regrade all agree.
