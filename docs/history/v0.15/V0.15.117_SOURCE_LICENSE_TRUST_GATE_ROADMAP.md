# V0.15.117 Source License Trust Gate Roadmap

## Goal

Keep source proof honest when a provider returns real, on-topic-looking source
rows whose license field is only open-access status or a publisher policy URL.

The fresh deployed v0.15.116 User Experience Design Studio ZIP/log audit showed
the problem:

- App version: `0.15.116`
- Run ID: `run-1782704292547`
- Visible package result: `Quality 100`, `Texture 95`
- Export status: passed
- Local regrade before this stricter gate: `100/100 (A)`, `0` P0/P1/P2
- Local regrade after this stricter gate: `98/100 (A)`, with three citation P2s
- Ambiguous trusted license rows:
  - `sf2` used `license=other-oa`
  - `sf-1-2` used `https://www.springernature.com/gp/researchers/text-and-data-mining`
  - `sf-8-2` used `https://doi.org/10.15223/policy-029`
- Texture still measured `95/100`, so strict-clean output is not yet proven.

## Lane

1. Treat open-access status as review debt, not reusable license proof.
   - `other-oa` means the source may be reachable, but it is not an explicit
     license for trusted package bibliography proof.

2. Treat publisher policy and TDM URLs as ambiguous.
   - Text-and-data-mining pages, publisher policy DOIs, Springer/Sage/Elsevier
     TDM URLs, and similar policy links cannot count as reusable license proof.

3. Apply the same rule in production assembly and the local grader.
   - Future source-ledger rows with those license strings should be dropped from
     source-finder trusted proof or routed to review evidence.
   - Existing exported packages should regrade with citation findings when they
     trusted those rows.

4. Preserve real source proof.
   - Creative Commons, Wikipedia CC BY-SA, OpenStax/OER rows, and explicit
     reusable-license rows remain trusted when URL/DOI-backed and concept-linked.

## Release Boundary

- This release changes source-license trust accounting only.
- This release does not weaken source standards, hide review rows, or inflate
  scores.
- This release does not claim the fresh v0.15.116 provider output is clean; under
  current rules it regrades at `98/A`.
- This release does not solve the remaining texture target. Texture `95/100`
  remains a carry-forward issue.
