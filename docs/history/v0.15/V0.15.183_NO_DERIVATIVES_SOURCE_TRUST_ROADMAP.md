# V0.15.183 No-Derivatives Source Trust Roadmap

## Evidence

CourseMapper's source ledger already quarantines metadata-only, inaccessible,
off-topic, and publisher-policy rows before they can count as trusted source
proof. A remaining license edge case was still too permissive: Creative Commons
no-derivatives licenses such as `CC BY-NC-ND 4.0` and
`https://creativecommons.org/licenses/by-nc-nd/4.0/` normalized as explicit
license proof and could therefore count as trusted rows when URL, DOI, and
concept links were present.

That is not strong enough for editable generated teaching packages. A
no-derivatives license may be a real citation, but it should not count as
trusted reusable source proof for CourseMapper-authored derivatives without
instructor review.

## Goal

Trusted source-ledger proof must be real, accessible, on-topic, concept-linked,
and license-safe. Creative Commons no-derivatives rows should remain visible as
review evidence when useful, but they should not satisfy the trusted
bibliography gate.

## Lane

Product/source-ledger truth hardening. This is not a model prompt change, score
inflation, or grader weakening.

## Release Boundary

This release may claim that:

- `CC BY-ND`, `CC BY-NC-ND`, and Creative Commons `by-*-nd` URLs are treated as
  review-required license proof;
- no-derivatives rows cannot count as trusted source-ledger rows even when they
  have URL/DOI and concept links;
- the UX source false-friend regression now uses a derivative-safe control
  source, so topical relevance and license safety are tested independently.

It may not claim a new deployed provider score until a fresh GPT-5.4-mini
ZIP/log audit proves real output on the deployed version.
