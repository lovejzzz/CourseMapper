  `verification-output/edutool-audit-loop/20260701T022457Z-v015172-fresh-blocked/`.
- The run blocked before ZIP export, so no exported ZIP score is claimed.
- The digest and visible UI showed:
  - final status `blocked`;
  - digest quality `100/100 A`;
  - visible texture `95`;
  - `0` P0, `0` P1, and `0` P2 findings;
  - export verification `passed` with `38` checks, `0` failed, and `0` warnings;
  - 10 deterministic repairs applied;
  - no retry calls;
  - no browser warning/error rows from the app bundle.
- The remaining blocker was visible only in the UI/export card:
  `courseMap: Non-data-science package references notebook/model-card lab assets`.
- The emitted digest still reported `blockers: 1` with `flaggedChecks: []`.

## Goal

Make the run digest the canonical truth surface for blocked package reasons.
A package can be high quality and still blocked; the digest must show why.

## Lane

Report-truth and automation-observability repair. This is not a quality-score
change, grader weakening, source-ledger relaxation, UI redesign, or model
upgrade.

## Release Boundary

This release may claim that readiness blockers and warnings are carried into
the run digest. It may not claim a clean v0.15.173 ZIP score until a fresh
deployed GPT-5.4-mini ZIP/log audit proves the package exports or blocks with
matching UI, digest, manifest, report, and local regrade evidence.

## V0.15.173 Scope

- Pass finish-pass readiness blockers and warnings into `buildRunDigest`.
- Emit readiness blocker checks in `gates.flaggedChecks` even when quality and
  export verification pass.
- Emit a fallback failed check if a blocked finish reports blocker counts but no
  blocker detail reaches the digest.
- Add a regression using the exact v0.15.172 blocker shape:
  `Non-data-science package references notebook/model-card lab assets`.

## Why This Is CourseMapper-side

The model did not hide the blocker. CourseMapper computed the blocker,
displayed it in the UI, and disabled download, but failed to carry the blocker
into the digest that automation audits. That is a product/reporting contract
bug.
