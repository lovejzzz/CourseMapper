# v0.15.90 UX Source Quarantine and Quota Roadmap

_Written June 28, 2026. Target app version: `0.15.90`._

## Goal

Keep CourseMapper moving toward clean `100/100` packages by making a hidden v0.15.89 caveat visible and repairable. A nominally perfect User Experience Design Studio run still trusted an environmental architecture source as UX studio evidence and logged app-bundle localStorage quota warnings during the same audit. This release fixes those CourseMapper-side acceptance and runtime surfaces without claiming a new clean provider result.

## Lane 1: UX False-Friend Source Quarantine

- Treat `The Green Studio Handbook` and `Environmental Strategies for Schematic Design` as UX false friends when they appear in User Experience or design-studio courses.
- Preserve those candidates as review notes instead of trusted `sourceLedger` proof.
- Keep legitimate UX practitioner, design research, usability, accessibility, prototype, and information-architecture sources eligible when they satisfy the trusted-row contract.

## Lane 2: Grader Truth Projection

- Mirror the production UX quarantine in the local deep quality grader.
- Regrade the fresh v0.15.89 UX package with the stricter rule and show that the old nominal `100/100` projects to `99/A` with a P1 citation finding.
- Use that projection as evidence that v0.15.90 improves truth accounting rather than hiding or inflating quality.

## Lane 3: Storage Quota Runtime Fallback

- When normal, compacted, and hard-compacted conversation payload saves all hit quota, clear old payloads and retry with a tiny active payload.
- If the tiny payload still cannot fit, preserve the lightweight conversation index and skip the noisy app-bundle `QuotaExceededError` warning.
- Keep non-quota storage failures visible so real persistence defects are not hidden.

## Release Boundary

This release does not claim a clean `100/100` provider package. It proves stricter source/grader/runtime handling locally and must be followed by a fresh deployed `v0.15.90` ZIP/log audit to confirm real provider output quarantines UX false friends, avoids current-run quota warnings, and maintains or improves texture.
