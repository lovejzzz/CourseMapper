# V0.15.113 Rights Statement Source Gate Roadmap

## Goal

Stop restrictive rights-statement rows from counting as trusted bibliography
proof. A source row with `http://rightsstatements.org/vocab/InC/1.0/` is
reference metadata, not reusable licensed course evidence.

The fresh deployed v0.15.112 User Experience Design Studio audit showed the
system was close but still not clean:

- Visible UI and exported report: `99/100 (A)`, `Texture 93`
- App version: `0.15.112`
- Run ID: `run-1782690624608`
- Local regrade before this fix: `99/100 (A)`, no findings
- Patched local regrade after the stricter source rule: `99/100 (A)`,
  citations `94`, with two P2 citation findings for `InC` source-ledger
  licenses
- Evidence rows: `sf4` and `sf-6-2`, both licensed as
  `http://rightsstatements.org/vocab/InC/1.0/`

The package should not get clean source proof from an in-copyright rights
statement. CourseMapper should either retrieve a reusable licensed source row
or keep the restricted row out of trusted `sourceLedger` proof.

## Lane

1. Tighten production license safety.
   - Treat `rightsstatements.org/vocab/InC` values as ambiguous license proof.
   - Treat plain `in copyright` and `all rights reserved` strings as ambiguous
     license proof.
   - Keep Creative Commons, public-domain, OER, and existing explicit-license
     rows eligible.

2. Make export and source-finder selection inherit the stricter gate.
   - `isTrustedSourceLedgerRow` rejects restricted rights-statement rows.
   - Source-finder candidate ranking no longer rewards `InC` rows as reusable
     licensed proof.
   - Package export keeps those rows from inflating trusted concept-linked
     source counts.

3. Mirror the rule in the deep quality grader.
   - Existing exported packages with `InC` sourceLedger rows now receive
     citation P2 findings.
   - The v0.15.112 captured artifact regrades with the newly visible citation
     issue instead of silently passing source truth.

## Release Boundary

- This release changes source-license truth and trusted-ledger eligibility.
- This release does not lower citation standards, hide source rows, or inflate
  scores.
- This release does not claim strict-clean provider output. A fresh deployed
  v0.15.113 ZIP/log audit must prove CourseMapper finds reusable source proof
  instead of restricted rights-statement rows and that texture reaches the
  strict target.
