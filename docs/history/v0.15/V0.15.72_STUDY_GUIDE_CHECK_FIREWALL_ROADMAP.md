# v0.15.72 Study Guide and Map Readiness Firewall Roadmap

_Written June 27, 2026. Target app version: `0.15.72`._

## Evidence

The fresh deployed v0.15.71 Project Management ZIP/log audit scored `95/100`
instead of the `100/100` target. The package remained blocked because
enrichment covered only `10/12` lessons, and the grader also found a concrete
student-facing leak:

`Study Guides/Lesson 11 - Integration and Review - Study Guides.docx` included
`In-class checks this week: rubric-driven assignments 2. discussion prompts.`

The browser state also showed a Course Map completion tick while the same page
reported `Materials 10/12 - repair needed`. That is a product-trust bug: the
workspace can make a reviewable ZIP available, but it should not present a
repair-needed map as complete.

## Lane

Product quality and UI truth. Fix deterministic CourseMapper behavior without
weakening the grader, hiding package blockers, or claiming a clean package.

## Changes

1. Harden Study Guide check titles.
   - In-class check names now pass through a safe title helper.
   - Unsafe prompt-artifact labels fall back to the lesson's safe course
     concept instead of being shown to students.

2. Broaden prompt-artifact detection.
   - The detector now covers compact combined labels such as
     `rubric-driven assignments 2. discussion prompts`.
   - It also catches `quiz and exam bank` plus final capstone presentation
     phrasing from the live Project Management prompt shape.

3. Keep Course Map readiness honest.
   - The Course Map tab tick now requires a clean ready-stage map and no amber
     coverage chip.
   - A package with `Materials N/12 - repair needed` remains unticked even if
     a ZIP is available for instructor review.

4. Pin the failure shape.
   - The compiler regression feeds the exact combined artifact labels through
     key concepts, student artifacts, and assessment-registry in-class checks.
   - The build-ribbon regression asserts the Course Map tick gate checks the
     repair-needed coverage chip.

## Non-Goals

- Claiming the deployed package is now `100/100` before a fresh v0.15.72 audit.
- Relaxing the quality grader or suppressing P1/P2 findings.
- Solving enrichment retry, source ranking, texture, PPTX echo, or double
  periods in this slice.

## Release Boundary

In scope:

- Study Guide exam-scope check-title sanitization.
- Prompt-artifact label classification for combined prompt artifacts.
- Course Map tab completion tick truth when coverage is repair-needed.

Out of scope:

- New provider calls.
- Enrichment recovery architecture.
- Source-ledger trust changes.
- Texture-score threshold changes.
