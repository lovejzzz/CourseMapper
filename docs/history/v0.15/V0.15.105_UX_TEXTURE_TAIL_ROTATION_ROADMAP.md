# V0.15.105 UX Texture Tail Rotation Roadmap

## Goal

Move the latest fresh User Experience Design Studio audit closer to strict-clean
100/100 by reducing deterministic texture repetition without weakening the
grader, source rules, export truth, or report wording.

The v0.15.104 deployed ZIP/log audit reached 99/A with no P0/P1/P2 findings and
clean export/source truth. The remaining scored loss was Texture 92, with
repeated shingles concentrated in Assignment Brief support resources, Rubric
parameter rows, Rubric task directions, and Lesson Plan kernel-fact transfer
sentences.

## Lane

1. Rotate Assignment Brief support-resource packets.
   - Replace the fixed notes/readings, rubric, checklist, office-hours list with
     six lesson-specific packet shapes.
   - Preserve the same assessment identity, support intent, and criterion
     alignment.

2. Rotate parameter-derived Rubric row language.
   - Vary the evidence signal, calibration prompt, feedback move, and
     proficient/developing/beginning performance bands for brief parameters.
   - Keep the same brief-parameter criterion derivation, weights, and objective
     alignment.

3. Rotate Rubric directions and preference notes.
   - Vary the evidence-standard sentence and instructor-preference prefix so
     rubric documents do not repeat the same support-note tail.
   - Keep source checks, bias checks, and preference meaning intact.

4. Rotate Lesson Plan kernel-fact mini-lessons.
   - Keep authored kernel facts visible, but vary the transfer sentence students
     reuse in the weekly artifact.

## Release Boundary

- This release does not claim a clean provider 100/100.
- This release does not change source-ledger trust thresholds, quality scoring,
  export readiness, or grader weights.
- The local proof is a focused 12-lesson UX compiler regression that exercises
  native enrichment, assignment parameters, rubric generation, and kernel-fact
  lesson plans.
- A fresh deployed v0.15.105 ZIP/log audit is still required to prove whether
  the texture score reaches 100 in real provider output.
