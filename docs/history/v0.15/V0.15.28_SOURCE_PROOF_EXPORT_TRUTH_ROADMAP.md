# v0.15.28 Source Proof Export Truth Roadmap

## Goal

Fix the first deployed source-ledger audit failure: a fresh EduTool.dev
Sociology package on v0.15.27 showed the browser finalizer grading source
truth at 87/B, while the downloaded ZIP regraded locally at 99/A because the
ZIP omitted `sourceLedger`, `sourceLedgerSummary`, `courseIR.sourceRefCoverage`,
and `SOURCE_REPORT.md`.

This release makes downloaded packages carry source receipts whenever the run
claims source-backed generation, and makes the grader flag source-backed
packages that omit those receipts.

## Lane

Package export proof, source provenance normalization, and grader truthfulness.
This lane repairs the current deployed source-ledger handoff without changing
provider routing, model-call counts, or the broader CourseIR rollout.

## Evidence

- Run: `run-1781942794062`, generated on deployed v0.15.27.
- Course: Introduction to Sociology.
- Browser digest: `Quality 87 · Texture 94`, source-backed pipeline with
  `genomeLinker`, `knowledgeBackbone`, and a limited knowledge judgment.
- Downloaded ZIP: `PACKAGE_MANIFEST.json` and `QUALITY_REPORT.md` regraded at
  99/A with only one format finding because source proof was absent.
- Missing export proof: no root `SOURCE_REPORT.md`, no manifest
  `sourceLedger`, no `sourceLedgerSummary`, no `courseIR.sourceRefCoverage`.

## Release Boundary

This is an exporter/grader truth patch. It does not add the full research
session planner, semantic source entailment, or new provider browsing. It uses
the deterministic Course Map and CourseGraph data already present at export
time.

## Slice

1. Recover source-ledger rows from rendered Course Map supporting-resource and
   reading cells when a source-backed pipeline reaches export with a sparse
   CourseGraph.
2. Normalize embedded source text by extracting URL, DOI, provider hints, and
   Creative Commons/open-access license labels from resource strings.
3. Merge CourseIR/CourseGraph source rows with deterministic Course Map
   fallback rows instead of allowing empty source proof.
4. Export `SOURCE_REPORT.md`, `sourceLedger`, and `sourceLedgerSummary` for
   source-backed runs even when the live graph handoff is sparse.
5. Arm source-ledger grader checks from pipeline evidence as well as exported
   proof, so old-style packages with research pipeline claims but no receipts
   receive a P1 honesty finding.

## Non-Goals

- No weakening of quality scoring or hiding source caveats.
- No claim that every source is academically ideal; weak or ambiguous rows stay
  marked for instructor review.
- No broad provider-call change. Research-once/source-ledger planning remains
  the next architecture step.

## Acceptance

- The captured v0.15.27 Sociology ZIP regrades with a source-proof P1 instead
  of appearing clean.
- Normal package verification gates pass before push.
- The next deployed EduTool.dev audit should show ZIP-level source receipts
  aligned with finalizer/source digest caveats.
