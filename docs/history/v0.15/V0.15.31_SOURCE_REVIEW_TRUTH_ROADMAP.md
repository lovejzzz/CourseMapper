# v0.15.31 Source Review Truth Roadmap

## Evidence

Fresh deployed EduTool.dev audit:

- run folder: `verification-output/edutool-audit-loop/20260620T110411Z`
- app version: `0.15.30`
- prompt: four-week undergraduate Introduction to Sociology package
- visible badge: `Quality 99 · Texture 94`
- local regrade: `99/100 (A)`
- digest: `run-1781953675892`, 5 provider calls, `$0.06`

The audit showed that v0.15.30 improved the ZIP/source handoff, but two real
quality defects remained:

1. `SOURCE_REPORT.md` and `PACKAGE_MANIFEST.json` exported `SL1: Existing
course map fields.` as a source-ledger row with missing license and no URL
   or DOI.
2. `Assignment Briefs/Lesson 04 - Research Methods - Assignment Briefs.docx`
   rendered `Academic Integrity: Integrity for...`, tripping the deterministic
   `X: X` echo gate.

## Goal

Separate trusted bibliography proof from review-only curriculum provenance.
CourseIR fallback rows can be useful handoff notes, but they must not pose as
source ledger evidence. ZIP downloads should also use the same current graph
that the finish pass graded, including attached open resources.

## Lane

Narrow source-proof truth and deterministic compiler wording. This release is
not the full ResearchSession architecture; it is the smallest product fix that
makes the audited ZIP more honest and removes one repeatable texture defect.

## Plan

1. Carry `courseGraphRef.current` through finish-package results so the export
   panel downloads against the finish graph, not a stale render prop.
2. Quarantine URL/DOI/license-missing CourseIR fallback rows into
   `sourceReviewRows`.
3. Render those rows under `SOURCE_REPORT.md` source-review notes with
   `trustedBibliography=false`.
4. Keep the grader strict: review-only rows are still P2 citation debt, just not
   fake bibliography rows.
5. Remove the assignment compiler wording that produces
   `Academic Integrity: Integrity...`.
6. Pin the behavior with source-ledger, ZIP-export, grader, one-verb export, and
   compiler-text regressions.

## Non-Goals

- No score inflation and no weaker source-ledger checks.
- No claim that packages are 100/100; the next deployed audit must prove that.
- No broad ResearchSession redesign in this patch. That remains the next
  architecture step for bridging CourseIR atoms directly to retrieved source
  rows.

## Release Boundary

Ship only if the source-ledger, ZIP-export, grader, one-verb export, compiler
texture regression, format, lint, full test suite, build, bundle check,
release-history audit, gold smoke, and browser verification pass locally. After
push, Fast verification and Pages deploy must also complete before the release
is claimed.
