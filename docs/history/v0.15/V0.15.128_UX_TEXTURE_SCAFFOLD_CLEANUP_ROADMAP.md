# V0.15.128 UX Texture Scaffold Cleanup Roadmap

## Goal

Remove the next deterministic texture weakness after a fresh UX Studio package
reached overall `100/100` but still carried repeated support and closure
phrasing through exported surfaces.

## Evidence

- App version: `0.15.127`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T123420Z-v015127-ux-fresh`
- Visible result: `Quality 100`, `Texture 95`
- Local regrade: `100/100 (A)`
- P findings: `0 P0`, `0 P1`, `0 P2`
- Export verification passed, enrichment coverage was complete, and the digest
  agreed with the manifest and quality report.
- Raw exported text still repeated scaffolds:
  - `checklist`
  - `exit ticket`
  - `office hours`
  - `quick evidence check`
  - `observe, label, calculate, or decide`
  - `Instructor-approved readings, examples, or lab materials`

## Diagnosis

The package was clean by overall score, but not fully texture-clean. The
remaining weakness was CourseMapper-side deterministic fallback and compiler
copy, not a provider outage or grader looseness. Better model output may reduce
some repetition, but compiler-owned phrases must not be stamped across 12
lessons and multiple exported files.

## Lane

1. UX Course Map fallback profile
   - Detect UX/design-studio course maps before the generic fallback profile.
   - Replace generic `quick evidence check`, `lab materials`, and
     `discipline-specific tools` copy with UX research, critique, prototype,
     portfolio, and user-evidence language.

2. Support and closure texture cleanup
   - Replace repeated FAQ/study-guide support wording around `office hours`
     with varied course communication, critique channel, peer discussion, and
     scheduled support language.
   - Replace repeated `checklist` labels with review sheet, review guide,
     readiness card, submission guide, submission steps, and evidence tracker
     wording where the checklist is not the actual artifact type.
   - Replace repeated `exit ticket` fallback wording with closure note,
     formative closure check, transfer check, and reflection language.

3. Regression proof
   - Compile a weak 12-week UX Studio map and prove generic Course Map fallback
     scaffolds do not appear.
   - Compile UX lesson plans, assignments, study guides, and Course FAQ and
     prove repeated support/closure scaffolds stay below the texture threshold.

## Release Boundary

- This release targets the concrete texture weakness from the fresh v0.15.127
  audit.
- This release does not weaken source gates, report/digest truth, export
  verification, or the deep quality grader.
- This release does not claim full provider texture cleanliness until a fresh
  deployed v0.15.128 ZIP/log audit verifies the next real output.
