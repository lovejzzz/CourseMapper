# V0.15.119 Prompt Artifact Firewall Roadmap

## Goal

Close the prompt-artifact leak exposed by the fresh deployed v0.15.118 User
Experience Design Studio ZIP audit: the package exported at `74/100` because
internal scaffolds reached Course FAQ prose and PPTX speaker-note metadata.

## Evidence

- App version: `0.15.118`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T052100Z-v015118-ux-fresh`
- Visible package result: `Quality 74`, `Texture 95`
- Embedded finding: one P0 for prompt artifact labels in
  `Slide Decks/Lesson 11 - Quiz and exam bank - Slide Decks.pptx`
- Local current-rule regrade: one P0 for prompt artifact labels in
  `Course FAQ/Lesson 10 - Discussion prompts - Course FAQ.docx`
- Source side: trusted concept-linked source rows were license-clean in this
  run, so the next blocker is compiler/export language hygiene.

## Lane

1. Course FAQ scaffolds
   - Treat `Weekly assessment: ...`, generic `Week N artifact` labels,
     source-packet phrasing, and anchor-contrast phrasing as unsafe in FAQ
     support answers.
   - Rewrite unsafe artifact names to neutral lesson-assessment language and
     unsafe evidence cues to source-evidence language.

2. PPTX speaker-note scaffolds
   - Replace raw `Visual guidance (...)` and `Accessibility description:`
     labels with natural instructor/accessibility note language.
   - Keep accessibility descriptions in the exported notes; only the internal
     marker labels are removed.

3. Grader defense in depth
   - Treat raw PPTX visual-note marker labels as P0 internal scaffolds so a
     future export cannot claim clean quality while shipping them.

4. Generic artifact references
   - Stop shortening unknown artifacts to `the Week N artifact`.
   - Use varied neutral assessment nouns for generic short references while
     preserving specific nouns such as quiz, memo, discussion post, check, and
     presentation.

## Release Boundary

- This release addresses prompt-artifact and generic artifact wording in
  compiled/exported surfaces.
- This release does not weaken the grader or hide prompt-artifact findings.
- This release does not claim clean provider output until a fresh deployed
  v0.15.119 ZIP/log audit proves the P0 is gone.
- Texture remains a strict-clean target after the P0 class is removed.
