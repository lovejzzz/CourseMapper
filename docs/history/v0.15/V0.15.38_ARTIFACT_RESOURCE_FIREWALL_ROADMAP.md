# v0.15.38 Artifact Resource Firewall Roadmap

_Written June 20, 2026. App version: `0.15.38`._

## Goal

Ship the smallest evidence-backed release that fixes the fresh Genetics and
Society P0 without weakening quality grading: deliverable labels must not become
course concepts, and the run digest must not say `ready` after quality grading
blocks the package.

## Lane

Package finalizer truth and compiler hygiene. This lane stays inside deterministic
Course Map repair, compiled Course FAQ behavior, finalize-time digest emission,
and release proof. It does not attempt a broader source-ledger or license-policy
redesign.

## Release Boundary

In scope: single supporting-resource artifact-label repair, compiled FAQ
regression coverage, run digest quality-gate reporting, release manifest,
contract, and roadmap updates. Out of scope: source-ledger coverage, source
license selection, model/provider randomness, and a new EduTool.dev generation
after the fix deploys.

## Evidence

The 20260620T200413Z EduTool.dev audit ran against deployed v0.15.37
(`7d9047d`). Fast verification and Pages deploy were green before the run.
The fresh Genetics and Society package reached the finished-package surface,
but the app reported `Quality 74 / Texture 94` with one P0:

- `prompt artifact labels used as lesson concepts`
- affected surface: `Course FAQ/Lesson 01 - DNA and inheritance basics - Course FAQ.docx`
- example text: `Strong work uses slide decks`

Console evidence also showed a truth mismatch worth tracking: export
verification passed, while the later quality grade blocked the finished state.
This release fixes both the content leak that caused the P0 and the digest
ordering that let `[CM][DIGEST]` say `ready` before finalize-time quality had
blocked the package.

## Fix

The v0.15.11 firewall already repaired multi-label prompt artifact lists and
numbered artifact topics. The live v0.15.37 package exposed a narrower hole:
a single supporting-resource cell equal to a requested deliverable label, such
as `slide decks`, survived repair and was later treated as a source/evidence
packet by compiled Course FAQ answers.

v0.15.38 changes the Course Map repair pass so exact single supporting-resource
cells that are deliverable labels are repaired for normal disciplinary courses.
It deliberately preserves the v0.15.12 precision exception that lets legitimate
`worked examples` remain a normal supporting resource.

v0.15.38 also changes the finalize flow to build a preliminary run digest only
for the quality grader's honesty input, then rebuild and emit the audit digest
after `applyQualityToFinalizerResult` has merged P0/P1/P2 quality findings into
the final status. `buildRunDigest` now carries quality status, score, grade,
finding counts, and a flagged quality check when the grader finds issues.

## Verification

Focused regression coverage now proves both layers:

1. `repairCourseMapReadiness` repairs a single `supportingResources: "slide decks"`
   cell to the real lesson topic.
2. Compiled Course FAQ text for the live Genetics shape no longer contains
   `Strong work uses slide decks` or the leaked `slide decks` label.
3. `buildRunDigest` records finalize-time quality P0s as failed quality checks
   and formats the digest as `gates: blocked ... quality 74/100 C`.

## Carry Forward

1. The fresh audit still showed `Genome 0/4` and only one source-ledger row in
   `native_c1_source_truth`; the source-ledger bridge and source relevance work
   must continue toward concept-linked trusted rows.
2. Source license ambiguity remains a separate P2 class and should be handled
   by the source-license policy work, not hidden by this patch.
