# V0.15.98 UX Source False-Friend Expansion Roadmap

## Lane

Source relevance and grader-truth hardening.

## Evidence

- `verification-output/edutool-audit-loop/20260628T112811Z-v01597-ux-fresh/package.zip`

- Tim Minchin creative public persona as persona source proof.
- Sketches of Spain as UX sketching source proof.
- One Prototype Three Prototype Five Prototype Seven Prototype as UX prototyping proof.
- Le poeme, critique de la critique as design-critique proof.

## Problems

1. The previous UX gate still treated broad terms such as persona, sketch, critique, and prototype as sufficient when the evidence was from another discipline.
2. Source-finder could keep weak candidates in a fresh mini-shard or cached mini-shard, so both candidate intake and ledger export need the same source-sense rule.
3. The local grader needed to mirror the product filter so exported ZIPs cannot look citation-clean when trusted source rows are real but pedagogically wrong.

## Release Scope

- Expand the UX false-friend gate to the exact v0.15.97 misses.
- Apply the UX weak-source check during source-finder ranking before candidates enter fresh mini-shard results.
- Keep source-ledger assembly as the final guard for older cached mini-shards.
- Mirror the same rule in the deep quality grader.
- Add regressions for the latest exported false-friend classes.

## Non-Goals

- This release does not claim 100/100 provider quality.
- This release does not fix the texture 90 repeated-scaffold loss.
- This release does not fix the remaining `name one the...` format P2.
- This release does not redesign the source retrieval architecture beyond the evidenced false-friend class.

## Release Boundary

Ship only the expanded UX source-sense filter and grader parity proven by the v0.15.97 audit evidence. Do not bundle texture, UI, or broader retrieval changes into this release.

## Verification Plan

- Targeted source-finder, source-ledger, and source-ledger-grader regressions.
- Projected regrade of the v0.15.97 artifact with the stricter v0.15.98 source-truth checks.
- Normal release gates before push.
- Fresh deployed v0.15.98 ZIP/log audit after Pages deploy.
