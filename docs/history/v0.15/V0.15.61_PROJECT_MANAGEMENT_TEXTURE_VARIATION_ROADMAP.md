# v0.15.61 Project Management Texture Variation Roadmap

_Written June 26, 2026. Target app version: `0.15.61`._

## Evidence

The fresh deployed v0.15.59 Project Management ZIP/log audit regraded at
98/100 (A), with the remaining score loss concentrated in citations, native
fallback honesty, and texture. Texture measured `90/100`, with opener variety
down to `72` and repeated phrase evidence across slide decks, discussions,
rubrics, and quiz-bank answers.

The repeated strings were deterministic compiler frames, including:

- capstone milestone review phrasing reused across Project Management lessons,
- objective slide notes using the same observable-performance sentence,
- parameter-derived rubric bands using the same scorer-location sentence,
- enriched discussion tension frames using the same source-evidence sentence,
- kernel-projected short answers using the same limitation sentence.

## Goal

Improve package texture by varying compiler-owned frames deterministically.
Repeated phrase repair should happen before export, not by weakening the
texture grader or hiding texture advisories.

## Lane

Texture/post-processing. This release targets the compiler phrases shown by the
latest Project Management audit. It does not claim source-ledger 100/100,
native-authoring fallback repair, or a clean 100/100 ZIP until fresh deployed
ZIP/log evidence proves those separately.

## Changes

1. Rotate capstone milestone-practice language before it is embedded into
   lesson modality, slide, and activity surfaces.
2. Rotate parameter-derived rubric exemplary bands so a single scorer-location
   phrase cannot stamp across every rubric.
3. Rotate objective slide-note language around observable performance targets.
4. Rotate enriched discussion tension framing for source-evidence positions.
5. Rotate kernel-projected short-answer limitation language when no explicit
   counterpoint exists.
6. Extend the texture regression suite with a 12-lesson Project Management
   fixture that caps the exact phrase families from the latest audit.

## Release Boundary

In scope:

- Deterministic variation of compiler-owned repeated phrases.
- Focused regression coverage for Project Management package texture stamps.

Out of scope:

- Weakening the texture metric or deep quality grader.
- Inventing source licenses or hiding ambiguous source rows.
- Repairing native skeleton fallback.
- Claiming 100/100 without a fresh deployed EduTool ZIP/log audit.
