# V0.15.145 Lesson Identity Truth Roadmap

## Goal

Use the fresh v0.15.144 ZIP/log evidence to stop assessment labels and grading weights from becoming Course Map lesson identities, exported filenames, and report-clean package claims.

## Evidence

A fresh deployed v0.15.144 User Experience Design Studio provider run exported a ZIP and captured console logs:

- appVersion: 0.15.144
- runId: run-1782790857270
- finishRunId: finish-mr03riu9-s0eww
- visible UI: Quality 99, Texture 93, Ready with notes
- export verification: passed, 38 files checked, 0 failed, 0 warnings
- original local regrade: 99/A, Texture 93, 0 findings
- after the new identity guard: 98/A, Texture 93, 1 P1 identity finding

The visible Course Map and ZIP filenames used assessment labels as lesson identity:

- `Lesson 1: evidence check: Studio critique (9%)`
- `Lesson 2: applied problem: Studio critique (9%)`
- `Lesson 3: practice brief: Studio critique (9%)`
- `Assignment Briefs/Lesson 01 - evidence check - Studio critique (9%) - Assignment Briefs.docx`

## Lane

This is a narrow Course Map readiness and quality-truth lane. It does not change source retrieval thresholds, source-ledger trust policy, texture scoring weights, provider selection, or export verification strictness.

## Fix

V0.15.145 keeps the slice narrow:

1. Course Map readiness treats assessment-label lesson titles with grading weights or assessment activity cues as weak lesson identities.
2. The readiness repair replaces those titles from the real lesson topic cell before export, so bad labels do not seed filenames.
3. The deep quality grader flags assessment labels or grading weights used as lesson/file identities across exported materials as a P1 identity finding.
4. The grader version is bumped to 1.7.4 so generated manifests identify the stricter quality contract.
5. Focused regressions reproduce both the readiness repair and package-level grader blind spot.

## Non-Goals

This release does not claim a clean provider package, 100/100 texture, broader UX source-linking coverage, or a genome-linked knowledge backbone. The v0.15.144 audit still recorded 0/12 genome-linked lessons and Texture 93.

## Next Audit

Run a fresh deployed v0.15.145 ZIP/log audit. The audit should prove:

- Course Map lesson titles no longer use assessment labels or grading weights.
- Lesson-rooted filenames no longer use assessment labels or grading weights.
- UI, digest, manifest, quality report, source report, and local regrade agree.
- Source rows remain real, trusted, on-topic, URL-backed, license-safe, and concept-linked.
- Any remaining score loss is explained directly, especially texture or source coverage.

## Release Boundary

Ship only after focused regressions and normal release gates pass. This release may claim the assessment-label identity repair and truth guard, but it must not claim strict-clean provider output until a fresh deployed v0.15.145 package proves it.
