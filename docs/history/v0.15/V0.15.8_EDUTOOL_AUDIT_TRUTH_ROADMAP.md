# V0.15.8 - EduTool Audit Truth: generated packages stop looking cleaner than they are

_Written June 19, 2026 after a live EduTool.dev export audit using the generated ZIP and saved console log._

## Goal

Use real EduTool output artifacts as the release judge. The first audited run generated `Introduction to Computer Science with Python` with a green in-app grade, but the ZIP and digest showed issues the shipped report underweighted: partial enrichment fallback, an empty Lesson 14 assignment brief, a course-title slide echo, and map-assessment coverage caveats.

v0.15.8 makes those defects visible in the product and fixes the deterministic export paths that created two of them.

## Lane 1 - Digest Caveats Count

The package grader now scores run-digest caveats that are already known at generation time:

- partial enrichment or template fallback becomes a substance finding;
- compiled-without-enrichment warnings become a P1 substance finding;
- additional course-map assessments without dedicated artifacts become an identity finding.

Saved DevTools logs can include older generations. Honesty checks now prefer the current digest object and scope the console transcript to that run before comparing pipeline counts or scanning for errors.

## Lane 2 - Ready UI Tells the Truth

The finished-package overview still keeps the ready state calm, but it no longer lets a green grade be the only signal when the package has serious caveats. P0/P1 quality findings add a compact review chip beside the grade and route instructors into the full quality report.

## Lane 3 - Empty Assignment Briefs Stop Shipping

Lesson-scoped Assignment Brief DOCX exports no longer produce a title-only file when a lesson has no standalone assignment entry. They render an explicit handoff note with the Course Map lesson reference, status, and review checklist. The grader also flags older title-only assignment briefs as P1 substance defects.

## Lane 4 - Slide Echo Cleanup

Slide-deck generation collapses prefix echoes like `Course: Course, variables...` in first-lesson title bullets and speaker-note anchors. This closes the live CS Python Lesson 1 `X: X` echo found by the artifact gate.

## Release Boundary

This release does not claim full enrichment coverage, new provider behavior, professor-adoption benchmark execution, or external instructor approval. It only claims stricter package truth, a visible caveat surface, and deterministic fixes for empty assignment-slice DOCX exports and course-title slide echoes.
