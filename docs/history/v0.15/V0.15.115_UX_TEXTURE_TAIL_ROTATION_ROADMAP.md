# V0.15.115 UX Texture Tail Rotation Roadmap

## Goal

Move the latest real User Experience Design Studio package closer to a strict
clean 100/100 by removing deterministic repeated compiler tails from exported
materials.

The fresh deployed v0.15.114 ZIP/log audit showed meaningful progress:

- App version: `0.15.114`
- Run ID: `run-1782696134615`
- Exported and local regrade: `100/100 (A)`
- Embedded findings: `0` P0/P1/P2
- Source proof: no repeat of the v0.15.113 UX false-friend rows
- Texture: `94/100`, still below the strict target

The remaining texture evidence was not model hallucination or bad source proof.
It came from compiler-owned template tails repeated across a 12-lesson package:

- Assignment Briefs repeated late-policy/contact language.
- Rubrics repeated calibration and criterion-feedback facilitation language.
- Study Guides repeated the same evidence-source/implication review strategy.
- Discussion Prompts repeated the design-prototype critique protocol wording.

## Lane

1. Vary the compiler-owned tails without weakening the contract.
   - Keep the same deadline, source-use, calibration, accessibility, critique,
     and revision expectations.
   - Rotate wording by lesson so 12-lesson packages do not read like stamped
     scaffolds.

2. Expand regression coverage to the actual failed surfaces.
   - The UX texture test must compile assignments, rubrics, discussions, and
     study guides, not only lesson plans/slides/discussions.
   - The compiler-tail test must include late-policy and rubric text so repeated
     non-slide scaffolds cannot silently return.

3. Keep release claims honest.
   - This release is based on a fresh deployed v0.15.114 artifact and local
     compiler regressions.
   - It does not claim strict-clean provider output until a fresh deployed
     v0.15.115 ZIP/log audit proves Texture reaches 100 and all exported
     surfaces agree.

## Release Boundary

- This release changes deterministic compiler prose and regression coverage.
- This release does not lower the texture metric, hide texture advisories,
  weaken source/citation standards, or inflate package scores.
- This release does not change provider prompts or source retrieval logic.
