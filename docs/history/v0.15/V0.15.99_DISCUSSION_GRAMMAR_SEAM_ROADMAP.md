## Problem

The discussion compiler used the primary lesson concept as a noun modifier in several peer/review sentence templates. That is safe for compact concepts such as `personas`, but unsafe for article-led concepts such as `the logic of A/B testing`.

The specific failure came from:

- `name one ${concept} uncertainty worth testing`

When `concept` was `the logic of A/B testing`, the export became:

- `name one the logic of A/B testing uncertainty worth testing`

## Release Scope

- Rewrite discussion response, criterion, peer-response, participation, and review templates to use prepositional phrasing:
  - `discussion of X`
  - `claim about X`
  - `evidence for X`
  - `uncertainty in X`
- Add a compiler regression that recreates the ten-lesson UX/A-B testing path from the audit and blocks the malformed `name one the...` family.

## Non-Goals

- This release does not claim 100/100 provider quality.
- This release does not prove the v0.15.98 source false-friend quarantine in live provider output.
- This release does not address remaining texture repetition unless a fresh deployed audit proves the source and format fixes and leaves texture as the next scored loss.
- This release does not change source retrieval, source-ledger scoring, or report/digest accounting.

## Release Boundary

Ship only the discussion grammar seam fix and its regression. Keep source truth, texture, and fresh-provider validation as carry-forward work.
