# v0.15.46 Course Map Tab Truth Roadmap

_Written June 25, 2026. App version: `0.15.46`._

## Goal

Make the Course Map tab completion marker follow the real build/package phase
instead of marking the map ready as soon as initial map streaming ends.

## Lane

Workspace UI phase truth. This patch does not change source retrieval,
generation, compilation, export bytes, or the quality grader.

## Release Boundary

In scope: the Course Map tab ready-tick predicate, its focused regression
coverage, and release-ledger documentation.

Out of scope: source selection, source-ledger trust, generated reading quality,
prompt-artifact content repair, export generation, and grader scoring.

## Evidence

The user-provided browser screenshot showed the live workspace still building:

- the build ribbon said `Enriching lessons 1-12`,
- the left panel said `Building package`,
- the package panel showed only `1 material ready`,
- the visible Course Map table still had unfinished cells,
- but the `Course Map` tab already showed a green ready check.

The source predicate confirmed the mismatch: the tab tick used only
`gen.progressStep === 'done'`, which becomes true once initial map streaming is
done even while enrichment, compilation, verification, and grading continue.

## Fix

The Course Map tab ready tick now requires all of these facts:

1. the tab is the Course Map tab,
2. the build ribbon grade step is done,
3. the package quality pass is `ready`.

That keeps the tab unticked while enrichment/compile/verify stages are active.

## Verification

Focused ribbon/tab source coverage pins the predicate next to the existing
tab-ready-tick tests. The full release gate also includes the package-review
regression from v0.15.45 so the two UI truth fixes stay compatible.

## Carry Forward

This release fixes the misleading in-progress tab tick. It does not fix the
actual Project Management content-quality findings from the audited ZIP:

- source ledger rows were missing trusted bibliography proof,
- one student reading was off-discipline medicine content,
- one Course FAQ answer used prompt-artifact labels as lesson concepts,
- one source review row was only "Existing course map fields."

Those remain source-ledger, research-pipeline, and compiler quality work.
