# v0.15.74 Source-Finder Multi-Row Bridge Roadmap

## Evidence

The current quality target still depends on fresh v0.15.73+ ZIP/log evidence.
The latest completed full audit remains below 100/100, and source proof has
repeatedly shown a narrow bridge failure: retrieved source-finder/OpenAlex
resources can be present in the run evidence but not appear as enough trusted,
concept-linked source-ledger rows in the exported package.

v0.15.71 fixed the first-order candidate choice problem by preferring a trusted
OpenAlex candidate over a first-position Open Library metadata row. The next
safe slice is to stop collapsing a source-finder topic to exactly one recovered
ledger row when multiple trusted, concept-linked sources are already available
for that lesson.

## Lane

Product quality and source-ledger bridge truth. Keep recovered source-finder
evidence strict, concept-linked, and visible in the exported ledger without
weakening source trust standards or claiming a clean deployed package before a
fresh audit.

## Scope

- Preserve multiple trusted, concept-linked source-finder candidates from a
  single retrieved topic.
- Keep the bridge bounded: at most two trusted concept-linked source-finder rows
  per topic.
- If no trusted concept-linked candidate exists, keep the prior one-row review
  behavior so ambiguous metadata remains visible without inflating trusted
  source proof.
- Preserve the strict trusted-row definition: accessible URL/DOI, non-ambiguous
  license, trust-eligible provider, and concept links.

## Non-Goals

- Do not invent licenses or DOI values.
- Do not promote Open Library public metadata into trusted bibliography proof.
- Do not lower source-ledger grader standards.
- Do not claim a clean package score before a fresh deployed ZIP/log audit.

## Release Boundary

In scope:

- Source-finder mini-shard recovery from one trusted row per topic to at most two
  trusted, concept-linked rows per topic.
- Fallback preservation of the prior one-row review behavior when no trusted
  concept-linked candidate exists.
- Focused regression coverage for OpenAlex/Crossref rows surviving the bridge
  while Open Library metadata remains untrusted.

Out of scope:

- Broader source retrieval architecture.
- CourseIR atom `sourceRefs` propagation.
- Source grading threshold changes.
- UI presentation changes for source evidence or export warnings.
