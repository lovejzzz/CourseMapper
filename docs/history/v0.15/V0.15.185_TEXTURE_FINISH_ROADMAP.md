# V0.15.185 Texture Finish Roadmap

## Evidence

Fresh deployed v0.15.184 GPT-5.4-mini output was captured from EduTool.dev as
`User Experience Design Studio - Course Materials (69).zip`. The visible UI
showed `Quality 100 · Texture 96`, a compact amber `Ready with notes` export
card, and a ready Agent panel. The downloaded ZIP locally regraded 100/A with
zero P0/P1/P2 findings.

The remaining texture caveat was not model failure or a broken package. The
first layer was repeated assignment ledger metadata: `Week N`, points, percent,
and `Course Map L<N> · A<N>.1 · N%` repeated across every Assignment Brief.
After filtering that metadata out of texture evidence, the grader exposed real
CourseMapper-side boilerplate in UX Study Guides, Quiz Bank intended-use notes,
and studio Lesson Plan instructor moves.

## Goal

Finish the current quality loop by fixing the remaining deterministic texture
sources instead of spending another provider run:

- ledger metadata stays visible for instructors, but it does not count as prose
  texture;
- assignment briefs do not print the same weight twice;
- UX Study Guide, Quiz Bank, and studio Lesson Plan boilerplate rotates by
  lesson before export;
- the clean package-handoff UI from v0.15.184 remains the baseline.

## Lane

Product compiler, DOCX export, and quality-grader calibration. This is not a
score inflation patch: repeated body prose remains measured and tested.

## Release Boundary

This release may claim that:

- the v0.15.184 fresh UX provider package locally regraded 100/A with zero
  findings, while texture remained 96 from deterministic repeated shingles;
- assignment ledger metadata is excluded from texture shingles only when it is a
  structural ledger line, not body prose;
- repeated assignment body prose is still detected by the texture metric;
- Assignment Brief DOCX metadata no longer repeats the same percent weight
  outside the Course Map reverse stamp;
- the exact UX Study Guide, Quiz Bank, and Lesson Plan repeated phrases from
  the v0.15.184 audit are pinned by regression tests and rotated in compiler
  output.

It may not claim that v0.15.185 has fresh provider proof until Pages serves
v0.15.185 and a new GPT-5.4-mini ZIP/log audit verifies the generated output.
