# V0.15 — The Teachable Core: assault the judge's ceiling, free the brain

_Written June 12, 2026, at v0.14.9. Sources: the v0.14.9 proof rounds (C1 flip blocked by 93 language-course placeholders; C2's de-confounded voice protocol winning its first fair trial 5v4; the extraction flywheel turning live on a Korean course), the advisory judge's standing 4–6/10 "too templated to teach as-is" verdict across every structurally-perfect package, and the twice-deferred C3/C4 architectural debt. Theme: v0.14 made the package PROVABLY CORRECT and the surface CALM — v0.15 makes the content TEACHABLE and the brain SEPARABLE._

**Bars are defined before work starts, per house law. The releases in this line stopped being about correctness scores — 100/A is table stakes now; every bar below is about the judge, the architecture, or the flywheel.**

---

## Why these three lanes (the honest state)

1. **The judge's ceiling is the product's ceiling.** Eleven releases of structural perfection and the advisory judge still says 4–6/10: correct kernels wearing templated prose. v0.14.9 proved the cure is measurable — the SAME generation, voiced on 8 surfaces for $0.01, gained a judge point with structural 100/A held. That instrument (same-generation A/B) changes everything: style work is now cheap to prove or kill.
2. **The brain is trapped inside a React component.** The compiler + genome + grader ARE the intellectual property ("the website was never the product — it's the first client"), but the pipeline's brain is wired through a 250 KiB AppFlow chunk and a 5,000-line hook. The CurriculumOS repo exists and waits; v0.15 draws the module boundary INSIDE this repo so the brain can be lifted out without a rewrite.
3. **Trust gates did their job — now earn the flips.** Native authoring is 2-for-3 (blocked by one honest failure class: language courses transcribe "Instructor-provided course materials" as a resource). Voice is 1-for-1 under the fair protocol. Both flips are one fixed bug + one clean day away — and each flip DELETES code (the ~212-line legacy prose path; the voice flag plumbing).

## Lane 1 — TEACHABLE: the judge-ceiling assault

### T1. Voice day-two, then the flip and the widening

- Run `--voice ab --judge` on 4 courses on a different day. **Bar (standing):** voiced wins the majority of judged pairs, structural 100/A held, ≤$0.15/course. If met → flag default ON (the pass already self-reverts when texture doesn't improve — the safety stays).
- After the flip, widen in TIERS with the same instrument: Tier 2 voices lesson briefs + study-guide intros (≈20 surfaces), Tier 3 voices discussion prompts + assignment framings (≈40). Each tier ships ONLY on a fair-trial win; a tier that loses gets reverted, not negotiated. The texture meter's three sub-scores are the canary (a tier that wins the judge but tanks sameness is suspect).

### T2. Substance depth, measured by the judge

The v0.14.7 root-cause analysis said the 5/10 isn't ONLY voice: per-surface substance is thin (one kernel fact stretched across five templated fields). One slice, one instrument:

- Pick the surface the judge cites most (lesson-plan activities), double its kernel substance (worked example + misconception + citation INTO the activity steps, not beside them), and A/B it same-generation like voice.
- **Bar:** judge prefers the deep arm on a majority of courses at ≤+15% enrichment cost; no structural regression. If the judge shrugs, we learned substance isn't the lever and stop paying for it — that's the instrument's job.

### T3. The judge becomes a regression instrument

The advisory judge currently runs ad-hoc per round. Make the ceiling VISIBLE release-over-release:

- `--judge` joins the release-round protocol; ROUND_REPORT carries a judge trajectory table (like the score history) so "did v0.15 move the 4–6 band?" has one answer in one place. Parse failures stay non-gating ("judge: unparseable" — the cs-python voiced twin lost its verdict to one this release; log and move on).
- **Bar:** three consecutive release rounds carry judge columns; the v0.15 exit review quotes the trajectory.

## Lane 2 — SEPARABLE: the brain gets its own walls (C3/C4, deferred twice, now due)

### S1. The pipeline package boundary

Carve the brain into `src/curriculumos/` with an explicit public API — no React, no localStorage, no window:

- Moves: courseBlueprintCompiler, blueprintEnrichmentPass, the genome (kernelLibrary/linker/resolver/shard loader/extraction), the quality grader + texture, packageFinalizer's deterministic core, the readings/knowledge providers.
- The seam: ONE exported facade (`compileCourse`, `gradePackage`, `linkGenome`, `extractOnMiss`) with injected IO (fetch, storage, model caller) — the same injection discipline genomeExtraction and voicePass already follow.
- **Bar:** an `npx vite-node` script outside src/ compiles a fixture course to a graded package with ZERO React imports in the dependency graph (machine-checked by a lint rule on `src/curriculumos/**`); the app consumes only the facade; full battery green; bundle budgets hold or improve.

### S2. C4 — the AppFlow diet

AppFlow is ~5,000 lines / 250 KiB. Extract by ownership, not by line count: the review-queue block (B1's new home), the save/restore block, the generation-orchestration block, each into hooks/modules with the machine (C3) as the only phase authority.

- **Bar:** AppFlow under 4,000 lines AND the AppFlow chunk back under 248 KiB (the budget raised this release goes back down — the dated comment gets deleted, which is the point of dated comments).

### S3. C3 — machine ownership inversion

derivePipelineState stops being a read-model and becomes the owner: surfaces subscribe to the machine, AppFlow stops holding phase booleans the machine re-derives.

- **Bar:** the 12-state matrix test extends to assert NO consumer reads `packageQualityPass.status` directly outside the machine (source scan); zero behavior change (battery green, in-browser matrix pass).

## Lane 3 — TRUSTED AT SCALE: earn the flips, feed the commons

### F1. Native authoring: fix the language-course failure, then day three

The mandarin native arm emitted 93 "unresolved source placeholder" P1s — Pass A transcribes a literal "Instructor-provided course materials for Lesson N" when a language course has no resource-shaped supportingResources. Fix the transcription fallback (omit the sentence rather than emit the placeholder; the brief already carries the lesson anchor), pin it with a language-course fixture, and run day three on the SAME three courses.

- **Bar (unchanged, third attempt):** 100/A, zero P1s, cost ≤ prose, on ALL THREE including mandarin. Met → flip the default, keep prose as the loud fallback, and execute the ~212-line legacy deletion in its own commit. Not met → native stays opt-in and the failure class gets named in the roadmap exit review.

### F2. The flywheel feeds the commons

Extracted kernels (the Korean 8) live only in one browser's localStorage. The contribution path is designed (privacy boundary: kernels only, no course identity) but unbuilt:

- A "Contribute kernels" receipt action packages extracted kernels as a foundry source file (the EXACT shape `scripts/foundry/sources/*.json` takes), downloads it, and the foundry's validateSource + buildShards admit them like any source. Human review stays in the loop — no auto-merge into shipped shards.
- **Bar:** the Korean 8 round-trip: extract live → contribute → validateSource green → buildShards admits → the next deploy's lang shard links the course at 10+/12 for EVERY user, not one browser.

### F3. Coverage debt, by the same motion

- The `lang` discipline gets a real shard (the Korean contribution seeds it; a foundry pass over an open Korean/Mandarin text deepens it) — the last 0-link course family in the ten-course net.
- The remaining thin shards (chem 3, stats 5) get deepening passes IF a live run surfaces them; otherwise they wait — foundry runs follow misses, not completionism.

**Deliberately out (v0.16+):** provider proof rounds (still key-gated — unchanged); the durability backend (cloud project store; needs product decisions about accounts, not engineering); CurriculumOS repo migration itself (S1's boundary is the prerequisite; the lift-out happens there, not here); judge-bar gating (the judge stays advisory until its variance is characterized across ≥3 release rounds via T3).
