## Goal

Make sparse kernel/depth-marked slide decks meet the same five-content-slide
floor that the local grader and finish pass enforce, without lowering the
grader bar or hiding the blocker.

## Lane

Slide-deck compiler repair. This is not a model upgrade, UI-only change, score
inflation, source-ledger relaxation, or grader weakening.

## Release Boundary

This release may claim a deterministic CourseMapper-side repair for the
v0.15.171 slide-deck content-floor underfill. It may not claim a clean
v0.15.172 ZIP score until a fresh deployed GPT-5.4-mini ZIP/log audit proves the
package exports honestly, slide decks clear the content-bearing P1, and
source/genome caveats remain truthfully reported.

## V0.15.172 Scope

- Add a fifth deterministic lesson-specific content-floor teaching slide for
  kernel/depth-marked decks.
- Treat decks with only zero, one, or two credited teaching-body slides as
  genuinely sparse, so they receive a full five-slide deterministic top-up
  instead of stopping after the first few credited base slides.
- Preserve deterministic content-floor slides through the existing
  enriched-slide passthrough path.
- Add a focused Python sparse-deck regression that fails if deterministic
  top-up falls back to fewer than five teaching-body slides.

## Why This Is CourseMapper-side

A stronger model may write richer decks, but CourseMapper already knows when a
deck claims kernel depth and when the rendered deck body is too thin. Once the
finish pass can identify `4.2` content-bearing slides across enriched decks, the
compiler should repair that known underfill deterministically before download.
