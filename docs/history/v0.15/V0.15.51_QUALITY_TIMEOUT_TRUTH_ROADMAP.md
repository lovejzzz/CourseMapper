# v0.15.51 Quality Timeout Truth Roadmap

_Written June 26, 2026. Target app version: `0.15.51`._

## Goal

Fix the fresh v0.15.50 ZIP/log audit truth mismatch without weakening the
grader. The deployed site now downloads the ZIP, but the browser finalizer
timed out quality grading after 10 seconds while the downloaded ZIP later
graded itself at 74/C.

## Lane

Export truth and package quality handoff reliability. This release changes the
bounded timeout around existing quality grading; it does not change generation,
grader findings, quality thresholds, or citation/source standards.

- source bridge caveat: 16 retrieved open resources in digest, 1 exported

## Release Boundary

In scope:

- Give finalize grading the same shared package-quality timeout used by ZIP
  self-grading.
- Keep timeout failure non-throwing and visible as `not-graded` when the grader
  still cannot finish.
- Pin the timeout handoff with a focused regression.

Out of scope:

- Lowering quality standards or changing finding severities.
- Hiding the 74/C package findings.
- Fixing prompt-artifact leakage, source-ledger quality, or PPTX repeated text
  in this release.
