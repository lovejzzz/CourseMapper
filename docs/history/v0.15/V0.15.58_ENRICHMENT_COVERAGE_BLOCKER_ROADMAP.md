# v0.15.58 Enrichment Coverage Blocker Roadmap

_Written June 26, 2026. Target app version: `0.15.58`._

## Evidence

The latest Project Management ZIP evidence still regraded at 74/100 because a
package could finish with partial model enrichment:

- `QUALITY_REPORT.md` reported `partial enrichment (9/12) — lessons 6, 7, 8
fell back to template`.
- The same package still carried a P0 prompt-artifact leak and texture score
  below 100.
- Earlier release slices repaired Course FAQ and Study Guide artifact leakage
  paths, but the package gate still allowed partial enrichment to continue as a
  caveat instead of a repair/block state.

## Goal

Make partial enrichment coverage a package blocker after recovery is exhausted.
If a run enriches only a subset of requested lessons, CourseMapper must not
present the package as clean export-ready; it must name the missing lessons and
require retry/repair before a clean package can be exported.

## Lane

Package finalizer and run-digest truth. This release changes the readiness
contract only after the existing enrichment recovery attempts have already had a
chance to restore missing lessons. Full coverage remains clean. Model-skipped
or zero-enrichment states continue through the existing enrichment warning
paths. The quality grader remains strict and unchanged.

## Changes

1. Convert post-recovery partial enrichment coverage into a readiness blocker.
2. Include the exact `enriched/requested` count and missing lesson numbers in
   the blocker message.
3. Mark the run digest partial-enrichment check as `failed`, not `info`, even
   if a caller passes a ready finish state.
4. Pin the live `9/12` Project Management shape in focused finalizer tests.
5. Keep the bundled quality report’s partial-enrichment finding intact so
   downloaded ZIP evidence still explains the score.

## Release Boundary

In scope:

- Block package readiness when `modelStage=ran` and `enrichedLessons <
requestedLessons`.
- Preserve clean readiness at full enrichment coverage.
- Preserve legacy compiled-without-enrichment and model-skipped warning paths.
- Keep partial enrichment visible in the digest, manifest/report, and local
  deep-quality regrade.

Out of scope:

- Weakening the deep quality grader or changing the score formula.
- Claiming artifact leakage, source/research bridging, or texture are fully
  solved by this slice.
- Spending another provider generation before the release is pushed and
  deployed.
