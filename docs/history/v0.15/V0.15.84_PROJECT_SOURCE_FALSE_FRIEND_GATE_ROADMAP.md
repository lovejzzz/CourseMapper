# v0.15.84 Project Source False-Friend Gate Roadmap

## Goal

Keep Project Management source proof on-discipline when retrieval returns
business-adjacent false friends, especially accounting audit-quality papers that
share generic terms such as `risk` but do not support project risk registers.

## Evidence

A fresh deployed v0.15.83 Project Management audit completed on June 27, 2026
and saved evidence under:

`verification-output/edutool-audit-loop/20260627T132717Z-v01583-fresh`

The in-app and exported quality report claimed `100/100 (A)` with texture `95`.
The package otherwise verified recent repairs:

- No generic `Week N`, `Session N`, or `Topic N` Course Map labels.
- No stale visual-arts kernels in Project Management output.
- Amber review-with-notes export state, not green clean-ready.
- No current-run `QuotaExceededError` or local-save warning.

The stricter local regrade exposed one real source-truth defect:

- P1 citations: source-ledger row `kr1` trusted and linked the accounting paper
  `What do we know about audit quality?` to the Project Management concept
  `risk register and mitigation planning`.

That paper is about audit firms, accounting audit quality, auditor
independence, and financial reporting. It is not support for Project Management
risk-register instruction.

## Lane

Source relevance and source-ledger report truth. This is a CourseMapper-side
retrieval/filtering fix and grader-defense fix, not a model upgrade and not a
score-threshold change.

## Scope

v0.15.84 changes only bounded product and grader behavior:

1. Add a Project Management false-friend gate for OpenAlex reading attachment.
2. Reject accounting audit-quality and financial-reporting sources unless the
   source text also contains real Project Management anchors.
3. Keep valid project-management sources eligible, including sustainability,
   construction, software, scheduling, stakeholder, governance, and risk
   management sources.
4. Add a source-ledger grader defense so exported trusted concept-linked Project
   Management rows with the same false-friend shape become P1 citation findings.

## Release Boundary

In scope:

- Project Management source false-friend filtering.
- Source-ledger grader truth for trusted concept-linked off-discipline rows.
- Focused OpenAlex attachment and source-ledger regressions.
- Fresh v0.15.83 ZIP/log evidence report and patched local regrade.

Out of scope:

- Broad source retrieval architecture changes.
- Promoting metadata-only source rows.
- Hiding source warnings or weakening citation standards.
- Claiming a clean 100/100 package before a fresh deployed v0.15.84 audit.
- General UI panel redesign.
