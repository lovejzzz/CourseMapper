# V0.15.143 UX Skeleton and Quiz Texture Roadmap

## Goal

Use fresh v0.15.142 provider evidence to remove the next deterministic blockers to strict-clean output: UX Course Map skeleton labels that still reach exported rows/filenames, and Quiz Bank projection tails that hold texture below 100.

## Lane

This is a narrow product-quality lane: Course Map readiness repair plus Quiz Bank compiler texture variation. It does not change source trust standards, quality thresholds, export verification, or provider selection.

The run was not strict-clean. Two CourseMapper-side issues remained:

1. Course Map repair still allowed repeated fallback topics into exported rows and filenames:
   - `User Experience Design Studio annotation: research detail to design choice`
   - `User Experience Design Studio studio defense: prototype move and evidence`
   - `Weekly studio critique,Final interactive prototype presentation`
2. Quiz Bank texture stayed below the target because deterministic projection reused the same short-answer and essay scaffolds across all 12 lesson files:
   - `analyze what this evidence shows and justify your conclusion`
   - `concept recall without evidence stays below`
   - `use the assigned evidence rather than general opinion`
   - `answer keeps the claim honest by naming a plausible limit`

## Fix

V0.15.143 keeps the release narrow:

- Course Map readiness now treats UX course-title-only labels, course-title-prefixed fallback labels, and comma-joined assessment/event labels as weak topics.
- The weak-topic cleanup now repairs embedded section cells, not only lesson titles, so objectives, assessment labels, resources, and exported file stems do not keep the stale skeleton.
- Quiz Bank projection now seeds short-answer and essay frame variants from lesson-specific kernel content rather than slot number alone.
- The old repeated Quiz Bank scaffolds are removed while preserving explicit evidence use, opposing-view/counterclaim handling, and partial-credit guidance.
