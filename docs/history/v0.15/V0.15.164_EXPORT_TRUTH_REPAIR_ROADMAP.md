# V0.15.164 Export Truth Repair Roadmap

## Evidence

- Fresh deployed v0.15.163 GPT-5.4-mini Python audit:
  `verification-output/edutool-audit-loop/20260630T190159Z-v015163-fresh/`.
- Visible app result was Quality 99, Texture 95. The downloaded ZIP locally
  regraded at 99/A with 0 P0, 0 P1, and 1 P2.
- The package source ledger was strong: 11 trusted OpenStax Introduction to
  Python Programming source rows, all concept-linked, with complete sourceRef
  coverage in the manifest.
- The scored P2 was report truth: the early judgment event said `not evaluated
(0 genome-linked lessons)`, but the final package had complete source-backed
  proof.
- The digest also reported one export warning: Lesson 09 assignment DOCX
  repeated `define a dictionary as a key value mapping` 12 times. Direct DOCX
  inspection showed the Course Map row was correctly `Lesson 9: files and
exceptions`, while the assignment body reused stale dictionary identity text.

## Goal

Move the failing surfaces from "hope the model writes it right" to "validate,
repair, then export":

- Source-backed packages must not be reported as unevaluated only because the
  genome linker returned 0 links.
- Cross-lesson enrichment payloads must not overwrite current lesson identity.
- Assignment briefs must be checked against the Course Map before ZIP export.

## Lane

Report truth, compiler identity hygiene, and finalizer export repair. This is
not a grader-threshold change, source-ledger inflation, provider-model change,
or UI redesign.

## Release Boundary

This release may claim deterministic CourseMapper-side repair for the v0.15.163
fresh ZIP/log findings. It may not claim a clean 100/100 provider result until
a fresh deployed v0.15.164 GPT-5.4-mini ZIP/log audit exists and independently
regrades clean.

## Product Diagnosis

The package had two different truth problems:

1. The run digest preserved an early `not evaluated` genome judgment even after
   the final CourseIR/sourceRef ledger proved complete source-backed coverage.
   The grader then treated the stale breadcrumb as the canonical package truth.

2. The Course Map export was repaired, but one assignment brief body still used
   stale dictionary identity text for a files-and-exceptions lesson. This is a
   final export validation gap: a package can have a correct filename and map
   row while the body text remains stale.

## V0.15.164 Scope

- Add a strict source-backed judgment event only when all CourseIR atoms have
  sourceRefs, all lessons have cited resources, and genome-linked judgment is
  unavailable.
- Prefer canonical final manifest/report judgment over stale early console
  `not evaluated` evidence, without hiding packages whose final judgment is
  genuinely missing.
- Require lesson-content enrichment payload identity to overlap the current
  Course Map lesson before assignment-core/key-term enrichment is used.
- Add a finalizer repair that aligns assignment brief title, related lessons,
  and overview identity back to the Course Map before ZIP packaging.
- Add regressions for complete source-backed judgment truth, stale console
  breadcrumb handling, stale cross-lesson enrichment, and the exact Lesson 9
  dictionary/files assignment identity mismatch.
