# V0.15.103 UX Source Review and Texture Tail Roadmap

## Goal

Make the latest User Experience Design Studio audit truthful across source proof and texture evidence: quarantined false-friend sources should not lower the score when real trusted concept-linked sources cover the package, and repeated compiler-owned slide/discussion scaffolds should not appear as all-lesson template tails.

## Lane

Quality truth and deterministic texture cleanup for source-ledger grading, Slide Deck notes, and Discussion Prompt guidelines.

## Evidence

Fresh deployed v0.15.102 ZIP/log evidence is saved at:

- `verification-output/edutool-audit-loop/20260628T154611Z-v015102-ux-fresh/report.md`
- `verification-output/edutool-audit-loop/20260628T154611Z-v015102-ux-fresh/local-regrade-current-rules.json`
- `verification-output/edutool-audit-loop/20260628T154611Z-v015102-ux-fresh/edutool.dev-current-run.log`
- `verification-output/edutool-audit-loop/20260628T154611Z-v015102-ux-fresh/package.zip`

The app and ZIP reported `98/100 (A)` with four citation P2 findings, all from `sourceReviewRows`. `SOURCE_REPORT.md` showed those rows were correctly quarantined with `trustedBibliography=false`, while six trusted source-ledger rows had URLs or DOIs, explicit licenses, and concept links.

The same artifact regrades under the current local rule at `100/A` with zero findings. Texture remains `94/A`, so this is not strict-clean proof.

## Problem

The previous grader treated every source-review row as scored bibliography debt even when those rows were intentionally excluded from trusted proof and the package had real trusted source-ledger rows. That made correct quarantine look like a package failure.

The same audit also exposed new all-lesson texture tails:

- Slide Deck criterion bridge: `ask which prior move already supports the criterion...`
- Slide Deck no-next-slide transition: `changes the design decision students will make...`
- Slide Deck closing handoff: `avoid vague homework language...`
- Discussion Prompt participation frame: `speak or post at least twice...`

These phrase families are compiler-owned, not provider-only randomness.

## Release Scope

- Keep source-review rows scored when the trusted bibliography is thin.
- Keep source-review rows advisory when at least two trusted, licensed, URL/DOI-backed, concept-linked source-ledger rows already provide bibliography proof.
- Preserve UX and Project Management false-friend source gates.
- Rotate the audited Slide Deck criterion, transition, and closing handoff frames by lesson.
- Rotate the audited Discussion Prompt in-class participation frame by lesson.
- Add regressions for both source-review scoring truth and the repeated v0.15.102 texture phrase families.

## Non-Goals

- Do not weaken source relevance, license, URL/DOI, concept-link, or false-friend checks.
- Do not weaken the texture metric or hide texture caveats.
- Do not claim strict-clean provider output until a fresh deployed v0.15.103 ZIP/log audit proves it.
- Do not redesign the workspace UI in this release.

## Release Boundary

Ship only the source-review scoring truth fix and the deterministic compiler texture rotations named by the v0.15.102 audit. Leave provider generation strategy, retrieval breadth, UI layout, and grader thresholds unchanged.
