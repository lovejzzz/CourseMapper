## Scope

V0.15.153 keeps the release narrow:

1. Treat `Module (mathematics)`, module theory, and abstract-algebra module
   rows as false friends for CS/Python module lessons.
2. Treat `Exception (law)`, legal exceptions, and rule/law exception rows as
   false friends for CS/Python exception lessons.
3. Require concept-specific programming anchors for ambiguous CS/Python
   concepts before source-finder rows can become trusted source-ledger proof.
4. Preserve valid programming sources such as `Modular programming`,
   `Exception handling`, `String (computer science)`, and
   `List (abstract data type)`.
5. Mirror the stricter production gate in the deep quality grader so exported
   artifacts regrade truthfully.

## Goal

Prevent generic licensed pages from inflating trusted source proof in
CS/Python packages when they are about a different discipline than the lesson.

## Lane

provider-model prompt change, source-license loosening, texture-score change,
or UI redesign.
