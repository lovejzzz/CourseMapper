# V0.15.134 Lesson Plan Texture Constraint Variation Roadmap

## Goal

Remove a CourseMapper-owned repeated texture shingle without weakening the
publication-review requirement behind it.

## Evidence

- Fresh deployed audit:
  `verification-output/edutool-audit-loop/20260629T165140Z-v015132-fresh`
- Course: User Experience Design Studio
- App version: v0.15.132
- Local regrade: 99/100, grade A
- Texture: 95
- Follow-up v0.15.133 fixed the scored assessment-registry mismatch, but the
  same artifact still exposed repeated fallback texture in exported raw text.

Repeated CourseMapper-owned phrases found in the package:

- `Confirm local timing, modality, accessibility, source permissions, and
grading policy before publishing.`
- `the draft must show how the lesson evidence changes the work`

These are not model-side source-quality failures. They are deterministic
compiler and CourseIR fallback phrases that can be repaired before export.

## Diagnosis

CourseIR used a single course-level publication-review constraint, then rendered
that exact sentence into every Course Map lesson as a supporting resource,
derived activity, and enrichment-kernel fact.

The blueprint compiler also preserved stale `supportingResources` cells that
already contained the exact CourseMapper fallback. That meant the sentence could
survive in source traces, readings, lesson-plan materials, and downstream
evidence cues.

Deep lesson plans had a second deterministic repeated shingle in the workshop
block: every lesson could say the draft must show how lesson evidence changes
the work.

## Lane

1. Normalize CourseIR publication-review constraints
   - Keep the review gate visible.
   - Make the text lesson-specific before it becomes map, activity, or kernel
     prose.

2. Sanitize stale Course Map supporting resources
   - Detect the old CourseMapper-generated publication warning when it appears
     in `supportingResources`.
   - Replace it before readings, source traces, and lesson-plan materials are
     assembled.

3. Rotate deep workshop texture
   - Preserve the evidence-change revision requirement.
   - Vary the sentence so a 12-lesson package does not repeat the same shingle.

4. Prove with a focused UX regression
   - Reproduce the 12-lesson stale-resource shape.
   - Assert the old exact shingles are absent while source-permission semantics
     remain visible.

## Fix

V0.15.134 makes the repair at the product layer:

1. CourseIR-to-Course-Map export localizes the generic course publication
   constraint by lesson before it becomes a resource, activity, or enrichment
   kernel entry.
2. The blueprint compiler normalizes stale Course Map `supportingResources`
   cells containing the exact old fallback before readings, source traces, and
   lesson-plan materials are assembled.
3. Deep lesson-plan workshop copy rotates evidence-change wording by lesson
   while preserving the same revision requirement.
4. The regression uses a 12-lesson UX map with the stale publication constraint
   injected into every lesson and proves the exact old shingles stay out of the
   compiled result.

## Release Boundary

- This release fixes one CourseMapper-owned texture path from real ZIP/log
  evidence.
- This release does not weaken source, license, report, export, digest, or
  quality-grader standards.
- This release does not claim the next package is 100/100 until fresh deployed
  v0.15.134 ZIP/log evidence proves it.
