## Finding

The package was clean on source, export, honesty, discipline, structure, and format. The remaining scored loss was texture. The concrete product defect was not the model choosing one awkward phrase; it was CourseMapper accepting repeated short skeleton labels as if they were valid lesson topics:

- every per-lesson export used `Lesson NN - design project - ...`
- Course Map lesson headings collapsed around `Lesson N: design project`
- `weekly studio critiques` repeated as the first assessment anchor
- Assignment Briefs and Course FAQ inherited `design project`, `weekly studio critiques`, and `User Experience Design Studio` in support prose

This is CourseMapper-side because the repair/compiler path controls which Course Map cells are considered strong enough to seed filenames and compiled deliverables.

## Lane

V0.15.142 keeps the patch narrow:

- Count short Course Map labels that repeat across many lessons.
- Treat those repeated short labels as weak skeleton content.
- Repair complete-looking cells that contain the repeated weak label, not only empty cells.
- Add a UX studio progression fallback for collapsed maps so repairs produce lesson-specific titles and topic cells.
- Preserve source, export, quality, and grader standards.

## Verification

Focused regression coverage reproduces the v0.15.141 failure shape:

- 12 lessons titled `User Experience Design Studio`
- every topic cell `design project`
- every assessment cell `weekly studio critiques`

Expected repair:

- lesson titles vary across the 12-week UX course
- repaired titles include `UX problem framing and studio orientation`, `usability test planning and task scenarios`, and `portfolio case reflection and handoff`
- repaired Course Map text no longer contains `design project` or `weekly studio critiques`
