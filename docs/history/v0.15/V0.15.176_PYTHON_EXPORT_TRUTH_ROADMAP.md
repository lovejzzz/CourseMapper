## Goal

export, quarantine off-topic source proof, and ensure the package report reflects the final ZIP.

## Lane

change.

## Release Boundary

This release may claim that:

- comma-joined artifact labels such as `Quiz,Assignment` are treated as weak Course Map identities;
- artifact-only concept links and the live `Session (software)` CS/Python false friend cannot count
  as trusted source-ledger proof;
- stale precomputed quality reports fall back to final ZIP grading when findings reference files
  absent from the package.

It may not claim a fresh deployed 100/100 result until a new v0.15.176 ZIP/log audit proves it.

## Why This Is CourseMapper-side

The model can emit weak labels, but CourseMapper owns the export contract. A real licensed source
is still not trusted proof if it is off-topic or concept-linked only to an artifact label, and a
quality report must not describe files that are not in the package.
