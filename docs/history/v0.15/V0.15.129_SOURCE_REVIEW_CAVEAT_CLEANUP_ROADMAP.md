# V0.15.129 Source Review Caveat Cleanup Roadmap

## Goal

Remove the next source-truth cleanliness gap after a fresh UX Studio package
reached overall `100/100` but still exported review notes for rows that were
not useful instructor action.

## Evidence

- App version: `0.15.128`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T133033Z-v015128-ux-fresh`
- Visible result: `Quality 100`, `Texture 95`
- Local regrade: `100/100 (A)`
- P findings: `0 P0`, `0 P1`, `0 P2`
- Export verification passed, enrichment coverage was complete, and the digest
  agreed with the manifest and quality report.
- Source ledger proof improved: nine trusted, licensed, accessible,
  concept-linked UX sources were exported.
- Remaining caveat: `SOURCE_REPORT.md` and `PACKAGE_MANIFEST.json` still carried
  nine source review notes, including generated syllabus placeholders and weak
  UX bycatch such as metaverse/soma-design rows, even when trusted source rows
  already covered the linked concepts.

## Diagnosis

The bad rows were not being promoted into trusted source proof, which was good.
The remaining problem was user-facing truth accounting: once trusted,
license-safe, concept-linked rows cover the same concepts, covered weak bycatch
is not instructor review debt. Exporting it as `reviewRequiredCount` makes the
package look caveated even when the actionable source proof is clean.

## Lane

1. Prune covered non-actionable review rows
   - If generated syllabus placeholders, source-finder candidates, or UX
     false-friend bycatch are fully covered by trusted concept-linked rows, do
     not export them as `sourceReviewRows`.
   - Keep them out of trusted `sourceLedger` proof.

2. Preserve real source debt
   - Keep review rows when there is no trusted concept-linked coverage.
   - Keep missing-license, missing-URL/DOI, unlinked, or CourseIR review-only
     rows visible when they are the only source evidence.

3. Regression proof
   - Update the UX false-friend regression that previously enforced exporting
     covered metaverse bycatch as review debt.
   - Keep package-export tests proving real review-only rows still appear in
     `SOURCE_REPORT.md` and `PACKAGE_MANIFEST.json`.

## Release Boundary

- This release removes false review caveats from exported source reports.
- This release does not weaken source trust, license, relevance, or concept-link
  rules.
- This release does not claim full provider cleanliness until a fresh deployed
  v0.15.129 ZIP/log audit proves `SOURCE_REPORT.md`, manifest summary, UI, and
  local regrade agree with no hidden source caveats.
