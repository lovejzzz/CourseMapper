# v0.15.87 Finalizer Retry Digest Truth Roadmap

## Goal

Keep run diagnostics truthful when package finalizer retries compile missing
deliverables after the main generation already ran enrichment.

## Evidence

The June 27, 2026 fresh v0.15.86 User Experience Design Studio audit produced a
package at:

`verification-output/edutool-audit-loop/20260627T171951Z-v01586-ux-fresh`

The fresh provider output verified the v0.15.86 UX source quarantine: weak
false-friend rows such as `Iwerks Studio`, `Flight test`, and `Website wireframe`
were exported as source review notes with `trustedBibliography=false`, not as
trusted sourceLedger proof.

The same run regraded `95/100 (A)` with one P1 that was not actually a provider
content failure. The current-run console log proves:

- `blueprintEnrichment` ran as a provider call;
- the main compiler plan and compiled-deliverable events used
  `compilerSource: "enriched-blueprint"` for 9 deliverable types;
- finalizer retries later compiled Assignments and Rubrics from deterministic
  blueprint fallback and emitted retry-local `deterministic compile only`
  enrichment decisions;
- the final digest incorrectly reported the whole package as
  `compiledWithoutEnrichment: true`.

## Lane

Report truth and auditability. This release does not weaken source, texture, or
mail-merge gates; it prevents retry-local bookkeeping from falsifying a package
that already has stronger enrichment evidence.

## Scope

In scope:

1. Preserve the strongest package-wide enrichment outcome when later events try
   to downgrade `enrichmentModelStage`.
2. Preserve `enriched-blueprint` as the compiler source when retry-stage
   deterministic compiles add or repair individual deliverables.
3. Keep the existing compiled-without-enrichment warning for truly deterministic
   packages.
4. Pin the exact v0.15.86 trace shape with a focused digest regression.
5. Record the fresh ZIP/log audit and score explanation for future automation.

Out of scope:

- Lowering citation or texture standards.
- Treating source review notes as trusted bibliography proof.
- Fixing local-save quota cleanup or agent-note deduplication in this release.
- Claiming a clean 100/100 package.

## Release Boundary

The release is useful if a run that first compiles from `enriched-blueprint` and
then performs deterministic finalizer retries no longer receives a false
mail-merge P1 in the digest or quality report.

## Carry Forward

- Citation proof remains below target: one trusted source row lacked reusable
  license proof, and review-only rows still do not count as trusted bibliography.
- Texture remains below target on the audited UX package.
- The app still showed a local-save quota warning.
- The Agent panel duplicated the same review observation card multiple times.
- A fresh deployed v0.15.87 ZIP/log audit should verify the digest now preserves
  enrichment truth in provider output.
