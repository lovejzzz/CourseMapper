## Score Explanation

The `95/100` score is mainly CourseMapper-side, not simply model quality:

- **Citations: 89/100.** All atom-level `sourceRefs` existed, but they pointed
  to `0` trusted concept-linked source-ledger rows. The exported source proof
  was only `SL1: Existing course map fields`, which is review metadata, not
  bibliography proof. Better models may provide cleaner source rows, but the
  source-ledger bridge must not let complete-looking coverage rest on a
  metadata-only fallback row.
- **Substance: 84/100.** Generic `Session N` topics became lesson concepts,
  lesson filenames, and Course Map cells after native recovery. This is
  CourseMapper-side because deterministic repair can reject generated session
  placeholders before compilation. The grader also found enriched decks
  averaged only `2.8` content-bearing slides despite 13-slide decks.
- **Texture: 88/100.** Repeated phrases such as "analyze a stakeholder or
  field evidence case before making an implementation decision" recurred
  across deck artifacts. This is mixed model/product behavior, but
  CourseMapper can reduce it with deterministic variation and post-processing.
- **Honesty/runtime: local extra P2.** The browser console logged
  `Failed to save conversation: QuotaExceededError` for the current run.
  That is app-side state management and should be handled by pruning or
  rotating saved conversations.

## Lane

Course-map repair and native recovery truth. Fix generic `Session N` labels
first because they poison the visible Course Map, exported filenames, lesson
concepts, source-finder topics, and downstream deliverables.

## Scope

- Treat `Session N`, `Topic N`, and bare numbered lesson/topic labels as weak
  generated topics in `repairCourseMapReadiness`.
- Repair generic session references in completed-looking Course Map cells
  before they become blueprint/compiler input.
- Keep concrete anchors such as `project charter`, `scheduling lab`, and
  `final stakeholder presentation` when they are present.
- Add a focused regression for the v0.15.78 Project Management failure shape.

## Non-Goals

- Do not lower the source-ledger standard.
- Do not hide the `95/100` audit result.
- Do not claim source relevance, slide deck substance, texture, or local
  storage are fixed by this patch.
- Do not change the quality score thresholds or grader penalties.
