# V0.15.9 - Provider Call Rightsizing: stop paying for avoidable batches

_Written June 19, 2026. This release follows the live EduTool.dev Calculus run
that proved the current model limits were not the reason a normal full course
used nine provider calls._

## Goal

Make provider-call count follow real model capacity and observed recovery value,
not stale fixed batch assumptions. A 15-lesson course on a long-output structured
model should normally need one native skeleton call, one native content-authoring
call, and one optional voice call.

## Evidence

- Live Calculus runs used `gpt-5.4-mini`, 15 lessons, 9 provider calls, and about
  `$0.10`.
- The run digest showed 6 blueprint-enrichment calls: 4 planned native Pass B
  batches plus 2 recovery calls against the same missing lesson group.
- The model page reports a large context and output budget, so the fixed
  4-lesson batch size was a product assumption, not a provider hard limit.

## Lane 1 - Adaptive Native Pass B

Long-output structured models get a dynamic batch size from
`adaptiveProviderBatching`. For GPT-5.4-mini-class output limits, the normal
15-lesson Pass B stage becomes one batch with a roomy output cap. Prompt-only or
small-output models keep the prior 4-lesson safety behavior.

## Lane 2 - Recovery With Evidence

Native Pass B recovery now compares missing kernel/authored lesson sets before
and after a retry. If the retry makes no progress, the stage stops spending and
falls back with a clear warning. Partial progress can still earn the second
recovery call.

## Lane 3 - Voice Call Consolidation

The voice pass already caps the selected set at eight surfaces. The integration
now sends that selected set as one batch with a 4k output cap, preserving the
v2 selector and fallback lints while avoiding a second prompt overhead.

## Lane 4 - Model Limit Truth

GPT-5.4/GPT-5.5 context metadata is updated, and model-limit lookup now checks
the most specific prefix first so `gpt-5.4-mini-*` cannot inherit a broader
family limit.

## Release Boundary

This release changes batching, recovery discipline, voice-pass call shape, and
local model-limit metadata. It does not claim a fresh live provider run, remote
CI success, or a new quality benchmark until those artifacts are attached after
push.
