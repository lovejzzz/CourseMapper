# V0.15.106 UX Iteration Source Gate Roadmap

## Goal

Close the source-truth caveat from the fresh deployed v0.15.105 User Experience
Design Studio audit. The package exported a nominal 100/100, but
`SOURCE_REPORT.md` still trusted generic `Fixed-point iteration` and `Iteration`
pages as proof for UX design-iteration concepts.

Those rows were real, linked, licensed Wikipedia sources, but they were not
discipline-appropriate UX/design sources. The fix must prevent that false-friend
shape before it becomes trusted bibliography proof.

## Lane

1. Tighten UX iteration topic anchors.
   - Keep real UX iteration sources eligible when they mention design,
     prototyping, usability, studio critique, feedback, interface, interaction,
     or user-experience context.
   - Stop accepting bare `iteration` matches from math, generic process, or
     unrelated background pages.

2. Mirror the rule across the evidence surfaces.
   - Source-finder retrieval should avoid caching generic iteration pages.
   - Source-ledger export should not promote generic iteration pages to trusted
     concept-linked rows.
   - The deep quality grader should flag older packages that already trusted
     those rows.

3. Preserve the remaining caveat honestly.
   - This release does not claim strict-clean provider output. The latest fresh
     audit still measured Texture 94 from five repeated 12/12 shingles.

## Release Boundary

- This release changes only source relevance filtering and mirrored source
  quality checks for UX iteration false friends.
- This release does not weaken the grader, hide review rows, inflate scores, or
  claim a clean provider package.
- This release does not attempt the remaining texture cleanup. The v0.15.105
  audit still carries Texture 94 until a later deterministic texture slice is
  verified.
