# v0.15.45 Package Review Surface Roadmap

_Written June 25, 2026. App version: `0.15.45`._

## Goal

Make the download surface tell the truth when a generated package is available
but still has quality or export caveats.

## Lane

Workspace and finish-package UI truth. This patch does not change source
retrieval, compiler content, export generation, or the quality grader score.

## Release Boundary

In scope: package-card readiness copy, quality/export review caveat handling,
and the first finish-package receipt export-warning message.

Out of scope: source selection, source-ledger trust, generated reading quality,
prompt-artifact content repair, and the broader stage-progress checkmark model.

## Evidence

The user-provided v0.15.44 Project Management artifacts were saved under:

- `verification-output/edutool-audit-loop/20260625T144230Z/`
- source ZIP: `/Users/tianxing/Downloads/Project Management - Course Materials.zip`
- source log: `/Users/tianxing/Downloads/edutool.dev-1782398559187.log`

The local deep quality regrade matched the package report:

- quality: `96/100` (`A`)
- texture: `92/100`
- findings: `0 P0`, `3 P1`, `1 P2`
- export verification: generated ZIP with `1` warning

The warning hidden by the previous side-panel surface was:

- Slide Decks PPTX repeated the phrase "exit ticket using scope definition to
  justify one" 22 times within one section.

The browser surface was misleading. The package card showed a green ready state
and kept download enabled even though the same page also exposed `Quality 96`,
`Texture 92`, `1 export warning`, and the quality modal listed P1/P2 findings.

## Fix

The finish-package receipt now carries the first export warning message from
export verification. The side panel merges that package caveat with quality
state:

1. P0 quality findings still block the package card.
2. P1/P2 findings, score below 100, texture below 100, and export warnings
   create a review state.
3. Review state is amber and says `Review before download`.
4. ZIP download remains available when there are no true blockers.
5. The first concrete quality/export messages are visible directly in the
   package card.

## Verification

Focused readiness coverage recreates the live failed state: downloadable package,
`96/A`, `3 P1`, `1 P2`, texture `92`, and one slide-deck export warning. The
test asserts that the card is amber review, names the warning, preserves the
quality stamp, and does not disable ZIP download.

## Carry Forward

This release fixes the misleading package surface. It does not fix the actual
quality findings from the Project Management audit:

- source ledger rows were missing trusted bibliography proof,
- one student reading was off-discipline medicine content,
- one Course FAQ answer used prompt-artifact labels as lesson concepts,
- one source review row was only "Existing course map fields."

Those remain source-ledger, research-pipeline, and compiler quality work.
