# V0.15.107 UX Assignment Texture Rotation Roadmap

## Goal

Close the remaining strict-clean texture caveat from the fresh deployed
v0.15.106 User Experience Design Studio audit. The package exported and locally
regraded at 100/100 with no P0/P1/P2 findings, and the v0.15.106 UX iteration
source gate worked in real provider output. The carry-forward issue was Texture
94/100, concentrated in Assignment Brief scaffolds repeated across all 12
lessons.

The repeated evidence named assignment workload, citation-style, milestone, and
progress-tracking phrases. These are deterministic compiler strings, so the fix
belongs in CourseMapper rather than in the provider model or the grader.

## Lane

1. Rotate assignment workload wording.
   - Preserve the same preparation and revision/submission minute values.
   - Vary the sentence shape by lesson so the same out-of-class estimate does
     not create shared shingles across 12 assignment documents.

2. Rotate assignment format and citation directions.
   - Keep source-use and local citation expectations intact.
   - Avoid stamping the same "evidence, decision logic, and revision trace"
     fallback across every lesson.

3. Rotate assignment scaffolding milestones.
   - Keep the first legacy "Prerequisite readiness check" label for regression
     compatibility.
   - Vary later lesson milestone labels, due-date phrasing, and evidence-check
     descriptions while preserving the same readiness and evidence checkpoints.

4. Rotate progress-tracking sentences.
   - Keep the assignment checklist, rubric, workload, and readiness intent.
   - Stop repeating one long progress sentence into every assignment brief.

## Release Boundary

- This release changes only deterministic Assignment Brief compiler wording and
  the focused regression that protects it.
- This release does not weaken the texture metric, source-ledger checks, source
  truth, report truth, or package grader.
- This release does not claim strict-clean provider output. A fresh deployed
  v0.15.107 ZIP/log audit must prove the repeated assignment shingles disappear
  in real output.
