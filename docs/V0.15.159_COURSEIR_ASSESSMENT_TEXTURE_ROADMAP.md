# V0.15.159 CourseIR Assessment Texture Roadmap

## Evidence

The current v0.15.158 provider run is blocked by OpenAI `Insufficient Funds`,
so this release uses existing downloaded Python ZIP evidence rather than
claiming a new provider score.

`/Users/tianxing/Downloads/Introduction to Computer Science with Python - Course Materials (5).zip`
contains repeated manifest assessment titles:

- `Quick evidence check: apply Computer Science to a new example.`
- `Exit ticket using Python to justify one course-relevant decision.`
- `Practice response that names the evidence needed for data types.`

The same families repeat across almost every lesson. That is CourseMapper-side
deterministic texture debt: once those generic titles enter CourseIR or the
Course Map, they seed the Course Map, package manifest, lesson plans, quiz bank,
and other compiled surfaces.

## Scope

V0.15.159 keeps the patch narrow:

1. Detect generic assessment scaffolds such as `Quick evidence check`,
   `Exit ticket using`, `Practice response that names...`,
   `course-relevant decision`, `new example`, and `evidence needed`.
2. Repair them during CourseIR-to-CourseMap projection before weekly-assessment
   cells are rendered.
3. Repair them during CourseMap-to-CourseIR normalization before assessment
   atoms seed package manifests and compiled deliverables.
4. Use CS/Python-specific variants such as code trace, debug note, mini
   program, peer review, and transfer check.
5. Preserve non-generic instructor-authored assessment titles.

## Goal

Stop one CourseMapper-generated assessment scaffold from repeating across a
full course and lowering texture before the next provider run.

## Lane

CourseIR projection, Course Map normalization, package-manifest texture, and
deterministic compiler input cleanup. This is not a source-trust change, grader
threshold change, UI copy change, or new provider-score claim.

## Release Boundary

This release may claim generic assessment scaffold titles are repaired before
Course Map and CourseIR manifest-seeding surfaces. It may not claim GPT-5.5-pro,
GPT-5.4-mini, or any deployed package reaches 100/100 until a fresh funded
v0.15.159 ZIP/log audit proves it.

## Verification Target

Ship only after focused CourseIR projection regressions, release-history audit,
and normal local gates pass. The next evidence step is a same-version model
comparison run once provider credits are available.
