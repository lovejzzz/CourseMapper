# V0.14.1 Roadmap — Output Integrity: every promise kept, every gate honest

**Source analysis:** the V0.14.0 four-course output audit (OUTPUT-V014:
Elementary Mandarin Chinese I, Introduction to Computer Science with Python,
Physical Geology, World Literature — June 10, 2026). Headline: ~94 hand-verified
quiz keys, **zero wrong**; fonts/structure/tables on-system; names/weights/weeks
propagate consistently. And yet: off-discipline citations in all 4 courses, the
"Week 2 quiz" label 1,064 times in one course, midterm/final exams that exist
only in the course map, two final-week lessons shipped with zero geology, raw
JSON in a shipped course map row, and a judgment layer that never spoke — all
behind `ready · 0 blockers · 0 warnings`.

**Thesis:** the audit found exactly two failure families.

1. **Silent non-participation.** The knowledge layers (genome, citations,
   enrichment, judgment) can fail to engage — no shard, dropped kernel, empty
   `requires` edges — and nothing downstream notices. Gates measure *structure*
   (files exist, cells non-empty, no `{{placeholder}}`), not *meaning*. A
   surface that only speaks when it finds problems is indistinguishable from
   one that never ran.
2. **Divergent renders of shared atoms.** The course map and the deliverables
   are two renderings of the same graph entities that are allowed to drift:
   the compiler re-mints assessment titles instead of consuming the graph's,
   keeps one assessment per lesson while the map promises four, and the
   finalizer then mangles the re-minted names. The map ends up *more specific*
   than the deliverables — the inverse of its job.

V0.14.1 fixes family 1 with **honesty** (gates that measure meaning, surfaces
that always report) and family 2 with **identity** (one assessment registry
that every render consumes). Plus every one of the 28 traced defects below.

**Target (acceptance = re-run all four audit courses and assert):**

- Zero occurrences of a week label that disagrees with its enclosing lesson.
- Every assessment named in the course map either has a downstream artifact
  (brief / exam / in-class listing) or the package warns. Geology gets a real
  midterm and final; Mandarin gets its oral prompt sheet and speaking rubric.
- Course map XLSX assessment cells hyperlink to the actual brief files;
  briefs carry the reverse reference; clicking a map assessment in-app opens
  the deliverable.
- Citations: every attached reading passes a topical-relevance check or the
  slot is dropped with a logged reason. No `<i>` HTML, no shard keys, no
  silently-truncated author lists in any citation string.
- Digest/manifest always contain a judgment line and an enrichment-coverage
  line ("ran (12/14 — lessons 13, 14 fell back)" is a warning, not a secret).
- CS and Geology courses genome-link > 0 lessons (new shards); genome-linked
  lessons have ≥ as many key terms as model-enriched ones.
- Repro harness greps clean for: JSON syntax in cells, "N sections" cover
  meta, `eastAsia="Calibri|Georgia"`, mid-sentence bullet cuts without
  ellipsis, interior-lowercase fused titles, internal vocab strings.

**Principle:** carried from V0.13 — structure, alignment, rendering, numbering
are code; the model is paid only for disciplinary authorship. V0.14.1 adds the
corollary: **code must not assert what it did not check** (no rotating
"alignment is intact" verdicts, no `ready` over unverified meaning).

## Phase 1 — Surgical bug fixes (small, independent, high blast radius)

Each item: root cause is confirmed at the cited lines; fix + fixture test.

**1.1 "the Week 2 quiz" (P0).** `compiledLanguageFinalizer.js:113-118` dedupes
replacement targets by pattern text, keeping the first lesson's week number
for titles shared across lessons (CS shipped identical
"Autograded quiz and lab checkpoint" titles for 12 lessons → all rewritten to
Week 2). Fix: resolve the week number **at replacement time** from the
enclosing item's `lessonNumber` instead of baking it into the target; when the
same pattern arrives with a different replacement, mark the target ambiguous
and drop it. Test: CS fixture → zero week labels that disagree with their
lesson; Geology's distinct titles still shorten correctly.

**1.2 Fused-title casing.** `courseBlueprintCompiler.js:3611-3618` fuses two
assessment atoms with `and` + first-char lowercase → "Grammar Check and oral
Drill", "exit Ticket". Interim fix (until Phase 3 registry removes fusion):
keep the second label's casing intact. Test: no interior-lowercase fused
titles in any fixture.

**1.3 Truncated slide bullets.** `courseBlueprintCompiler.js:14665-14671`
caps bullets at 78/112 chars; `conciseClause` (`:356-380`) cuts at a word
boundary and only trims connectives, so content verbs survive ("…pattern:
run"); the "Practice:" label is prepended *after* truncation. Fix: back up to
the last clause boundary or append "…"; compute the cap net of the prepended
label. Test: zero bullets ending in a bare content word without terminal
punctuation (398 in CS today, 25 in Geology).

**1.4 Syllabus SLOs truncated at Lesson 2.** `courseBlueprintCompiler.js:12806-12809`
and `:12844-12847` both do `unique(lessons.flatMap(outcomes), 7)` — the cap
exhausts on L1–L2 in every course. Fix: round-robin one outcome per lesson
until the cap (and raise cap to ~10); apply to both the SLO list and the
alignment matrix. Test: SLOs reference ≥ 5 distinct lessons in each fixture.

**1.5 Sample answers that don't answer.** `kernelProjection.js:205` (short
answer) and `:230` (essay) glue anchor-fact + definition; the overlay copies
verbatim (`courseBlueprintCompiler.js:14207-14209`). Fix: keep the compiler's
scenario-referencing sample-answer frame and demote kernel fact/definition to
`explanation`; or template the answer around the scenario. Test: sample
answers must reference a token from their own stem's scenario.

**1.6 Round-robin "Aligns to".** `courseBlueprintCompiler.js:13900-13912`
hands each item the next unused objective regardless of content. Fix: score
stem↔objective lexical overlap, use coverage rotation only as tie-breaker.
Test: the audit's swapped pairs (CS L4 Q1/Q2) align correctly on fixture.

**1.7 Content-free meta-MCQs.** Frames 2 and 4 of the 6 permanent quiz frames

**1.8 "Evaluate Design" self-praise.** `leanCourseMap.js:251-269` rotates 4

## Phase 2 — Honesty: coverage, judgment, and gates that measure meaning

**2.1 Per-lesson enrichment drop tracking.**
`blueprintEnrichmentPass.js:1111` (`if (!lessonId) continue;`) and `:1197`
(all-atoms-linted-out `continue`) drop whole lessons without an `issues` row;
a lessonId mismatch can silently overwrite another lesson
(`useDeliverables.js:1290`). Fix: record an issue per dropped lesson; reject
out-of-chunk lessonIds; after the chunk loop compute
`missing = requested − parsed` and `appendLog` a **warn** naming lesson
numbers.

**2.2 Coverage reaches digest, manifest, and finalizer.** Extend
`stageDecisions.modelStage` → digest line and PACKAGE_MANIFEST become
`'ran (12/14 — lessons 13, 14 fell back to template)'`; `runDigest.js`
`compiledWithoutEnrichment` logic generalizes to a coverage fraction; the
package finalizer treats coverage < 100% as a **warning** (visible in
`finish_complete` and the UI), coverage < 60% as a blocker.

**2.3 Spend the reserved retry budget on dropped lessons.** Every audit run
finished with 8–14 unused finish-retry calls. Fix: in the finalizer's retry
pass, re-issue the enrichment call for just the dropped lessons (they're
already batched ≤4/call) before falling back to template. Geology L13/L14 and
WorldLit L8 would have cost one extra call each (~$0.02) to fix.

**2.4 Judgment always speaks.** `useDeliverables.js:1098` emits the judgment
pipeline event only when `missing > 0 || outOfOrder > 0`. Fix: always emit —
`"no gaps across N linked concepts"` when clean, `"not evaluated (0
genome-linked lessons)"` when the linker came up empty. Digest
(`runDigest.js:119`) and manifest (`AppFlow.jsx:758`) then always carry the
line. Test: all four fixtures show a judgment line.

**2.5 Map↔deliverable reconciliation gate.** New finalizer check: walk
`graph.assessments`; each must resolve to a downstream artifact (brief, exam
doc, or an in-class listing in the lesson plan). Unresolved → warning naming
the assessment ("Midterm Exam: minerals through metamorphic rocks — promised
in map 7.2, no artifact"). This is the gate that catches Geology's phantom
midterm/final and Mandarin's missing oral rubric *the day they regress*.
(Phase 3 makes the gate pass by construction; the gate still ships first.)

**2.6 Citation relevance gate.** In `attachOpenReadings`
(`readingListEngine.js:223-242`), before `attachResource`: score
abstract/title overlap against lesson concept terms + course discipline
anchor; below threshold → drop the slot and log
`"no relevant open reading found for L12 (rejected 3 famous-but-off-topic)"`.
Query fix in `readingQueryForSession` (`:184-192`): append the course
discipline/name anchor instead of a bare concept term; in `providers.js:92-94`
replace global `cited_by_count:desc` sort with relevance-ranked search (keep
citation count as tie-breaker only). Provider string hygiene
(`providers.js:101-106`): strip HTML tags in `cleanText`, append " et al."
when `authorships.length > 3` (same at `:138`, `:168`), and skip/normalize
shard-key labels in `attachGenomeResources`
(`readingListEngine.js:133-141` — never render
`writing about literature:reference §1` as a title). Test: four fixtures →
zero off-discipline attachments (the MNIST/cancer/QUANTUM-ESPRESSO set all
reject), dropped slots logged.

**2.7 Genome-coverage visibility.** `libraryShardLoader.js`: when
`inferCourseDisciplines` returns a discipline with no shard, log
`"no genome shard for inferred discipline 'cs'"` into the genomeLink budget
event detail — today's `0 genome + 0 cached` gives no hint the discipline
simply isn't covered.

## Phase 3 — Identity: the assessment registry (the map becomes an index)

The audit's structural finding: `blueprint.assessments` mints **one**
assessment per lesson from `lesson.studentArtifact`
(`courseBlueprintCompiler.js:11860-11862`) while the map/graph carries ~4 —
so the map's midterms, finals, orals, and labs are orphans, and the minted
titles (fused, colliding) feed bugs 1.1/1.2. Fix the identity, and the bug
class dies.

**3.1 Registry schema.** `graph.assessments[]` becomes canonical:
`{ id: "A8.1", title, kind: graded-artifact | in-class | exam, weightPct,
dueSession, sectionRef, sourceText }`. `deriveFromCourseMap.js:142-160`
already creates one assessment per map atom with `dueSession` +
`section.assessmentRefs` — add `kind` classification (reuse
`ARTIFACT_KIND_PATTERNS` from the finalizer: quiz/check/exam/lab/oral/
workshop) and stable ids. Weight allocation: distribute the lesson's
syllabus weight across its assessments by kind (exams heavier), keeping the
sum-to-100 invariant the alignmentLint already checks.

**3.2 Compiler consumes the registry.** `buildBlueprintFromGraph` passes
`graph.assessments` through; `courseBlueprintCompiler` stops re-deriving
`studentArtifact` (`buildStudentArtifactLabel` retires with its fusion bug)
and instead:
- `kind: graded-artifact` → one Assignment Brief per assessment (a lesson
  with two graded artifacts gets two briefs — compiled, zero AI calls), brief
  title = registry title verbatim.
- `kind: in-class` → listed in the lesson plan's activity block + map cell;
  no brief; named in the FAQ/study guide as "in class".
- `kind: exam` → **a real exam document**: compile from the quiz-bank atom
  pool of the covered lesson range (map 7.2 "Midterm Exam: minerals through
  metamorphic rocks" → items drawn from L1–L6 kernels' unused mcBank items +
  short-answer frames, 2× weekly length, answer key included). This closes
  the audit's worst alignment hole (Geology midterm/final, CS "Midterm exam:
  foundational Python", Mandarin "Final Oral Performance" → `kind: oral`
  generates the prompt sheet + speaking rubric from the lesson's kernel
  vocabulary).
- Rubrics attach per graded assessment id, not per lesson.

**3.3 Every render shows the same identity.**
- Map render (`renderCourseMap.js`): Weekly Assessments cells render
  registry titles + the deliverable reference ("→ Assignment Briefs / Lesson
  08") — `xlsxGenerator.js:204-242` needs no column change, plus 3.4's links.
- Briefs/exams carry the reverse stamp in the meta line:
  "Course Map 8.1 · A8.1 · 5%".
- Syllabus grading table rows render `id — title` (kills the 12
  indistinguishable "Autograded quiz and lab checkpoint" rows).
- The finalizer's reference-shortener keys replacements on assessment **id**
  (week resolved per item at replacement time) — bug 1.1's collision becomes
  structurally impossible.

**3.4 Links in the artifacts.** XLSX: assessment cell items become
`HYPERLINK`-style relative links to the brief/exam docx inside the package
zip (cell.hyperlink against `../Assignment Briefs/<file>.docx`); manifest
lists the link map. DOCX briefs get a "Related: Course Map row 8" line.

**3.5 In-app click-through.** `CourseMapPreview.jsx` assessment cells render
each item as a chip; click dispatches `coursemapper:focus-deliverable`
`{ featureId: 'assignments', lessonIndex, assessmentId }`; `DeliverableView`
scrolls/highlights. Mirror of the existing `focus-coursemap-cell` listener
(`CourseMapPreview.jsx:195-216`). Reverse: DeliverableView's assignment
header gets "Show in course map" using the existing event.

**3.6 Smart-sync and agent edits ride the ids.** Renaming an assessment in
either surface is one graph op; both renders update on re-render. Agent
tools get `assessmentId` as an addressable target (deferred from V0.13's
agent-graph-tools item — only the addressing lands here, not new tools).

Cost: all deterministic render/compiler work — **zero new AI calls**; exam
compilation reuses existing kernel atoms.

## Phase 5 — Slide and document polish (the remaining P1 texture)

**5.1 Backtick leak.** Slide/docx text renders markdown backticks verbatim
("\`{'name': 'Ava', 'age': 19}\`"). Strip to plain text in docx; in pptx
render code spans in the mono variant the deck theme already declares (or
strip if unsupported).

**5.2 Deck structure variation.** All 58 decks are the same 12-slide frame
with ~3 content slides; slide 6 "EVIDENCE TABLE" rows carry leftover strings;
slides 11/12 both titled "KEY TAKEAWAYS"; slide 10's table ships an empty
trailing cell. Fixes: retitle slide 11 ("READINESS CHECK"); drop empty table
cells; the evidence-table builder only emits rows that parse as
claim/evidence pairs, else the slide collapses to the worked-example content
(v0.13.3's workedExamples-in-slides item lands here: kernel `workedExamples`
get the slide that today's meta-slides 9–10 waste). Deck length becomes
content-driven within 10–14 slides — the PPTX audit line (min/max/median)
should stop reading 12/12/12.

**5.3 Speaker-notes density.** Notes are mail-merge walls repeating the
lesson title 6–10×. Cap title mentions per note at 2 via the finalizer's
existing replacement machinery (`keep: 2` pattern per artifact reference,
extended to lesson-title references).

**5.4 Bloom honesty.** Quiz "Bloom's Coverage" claims all five levels
verbatim in every file; syllabus tags mislabel ("Describe…" → Apply). Derive
tags from the item's stem verb against a fixed verb→level map, and let
coverage state only what's present.
