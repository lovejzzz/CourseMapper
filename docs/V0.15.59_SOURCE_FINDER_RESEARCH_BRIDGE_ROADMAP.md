# v0.15.59 Source Finder Research Bridge Roadmap

_Written June 26, 2026. Target app version: `0.15.59`._

## Evidence

The Project Management EduTool audit stream repeatedly showed a source/research
bridge gap:

- ZIPs could report retrieved OpenAlex/source-finder resources while the
  exported source ledger stayed thin or review-only.
- A Project Management syllabus could receive an off-discipline cardiovascular
  medicine reading because loose words such as "risk" matched a project topic.
- Retrieved provider rows already carried useful DOI/license/topic metadata,
  but the source-finder attachment path dropped some of that identity before
  source-ledger assembly.

## Goal

Bridge retrieved source-finder/OpenAlex resources into trusted,
concept-linked source ledger rows without weakening source quality checks. A
retrieved scholarly source should keep DOI/license/title/author/year/topic
metadata through export, and Project Management topics should reject unrelated
medical literature unless the course is explicitly healthcare-facing.

## Lane

Research/source bridge. This release is a narrow source-finder and
source-ledger patch. It does not claim prompt-artifact leakage, texture, or
fresh deployed package quality is fully solved.

## Changes

1. Preserve OpenAlex DOI values in provider results.
2. Preserve DOI, provider topic metadata, title, authors, year, license, and
   attribution through source-finder normalization and graph resource
   attachment.
3. Link source-finder resources to taught concepts through CourseGraph
   `edges.teaches` when section-level `conceptRefs` are sparse.
4. Add a Project Management discipline anchor so medicine/public-health papers
   cannot satisfy risk, scope, charter, scheduling, or stakeholder topics
   unless the course/topic is healthcare-facing.
5. Pin the bridge with focused regressions that check DOI/license preservation,
   concept-linked ledger rows, and off-discipline rejection.

## Release Boundary

In scope:

- Preserve existing provider metadata instead of inventing source proof.
- Improve source-ledger concept links for graph shapes already used by
  CourseMapper.
- Reject obvious off-discipline Project Management source hits.
- Keep generic ambiguous-license rules and source-ledger grading strict.

Out of scope:

- Weakening source-ledger, citation, prompt-artifact, or texture grading.
- Claiming a fresh deployed EduTool package now reaches 100/100 before ZIP/log
  evidence proves it.
- Broad research architecture changes beyond this source-finder bridge slice.
