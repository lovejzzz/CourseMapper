# V0.15.186 — Grounded Gates

_Release version: 0.15.186 · July 1, 2026 · contract: `release-contracts/v0.15.186.json`_

## Goal

One release closing the July 1 three-axis pipeline audit: make the gold audit
truly green by fixing content bugs (not gates), make template rotation
unprofitable in the grader, ground the last template-only assessment surfaces,
land the cost/speed fixes the audit measured (prompt caching had never landed;
stalls cost 6-8 minutes), and put the new design system + UI declutter behind
an enforced contract.

## Lanes

### Lane 0 — Gold audit true green (root fixes, not gate edits)

- Grounding echoes stop rewriting domain vocabulary ("Misconception Clinic",
  teacher-prep "lesson plan") via `lessonDomainVocabulary` exemption and the
  discussion-protocol echo bypass in `lessonSourceGrounding`.
- The "X: X" echo-collapse regex anchors to segment starts so deliberate
  colon-joined lists ("Decision Case: case fact sort…") survive.
- `compactSourceCue` strips leading conjunctions and joins leading clauses,
  fixing "And interpretation quality practice"-class artifact names and the
  sparse-assessment genre classification.
- Artifact short references derive from the artifact's own head noun; the
  generic rotation pool is deduplicated (the lessons-1/10/13 collision) and
  target regexes get trailing boundaries.
- Result: `npm run audit:gold` 40/40, 0 blockers (was 26 blockers / 7 samples
  at v0.15.185).

### Lane 1 — Anti-rotation grading (grader v1.8.0)

- `SUBSTANCE_BOILERPLATE_THRESHOLDS` extends to studyGuides / lessonPlans /
  quizBank / assignments at 0.35/0.7 bars (measured max today: 5%).
- Texture weight 10 → 25 of 135; texture < 60 is a P1.
- Proof both directions: the byte-identical-lesson fixture drops A → 74/C;
  the six-course calibration set holds 97-98/A; headless proof 98/A.

### Lane 2 — Grounding + CI

- Kernel projection grounds short-answer/essay items from term example /
  anchor fact / misconception-versus-correction when the course layer is
  missing — genome-linked lessons stop shipping mail-merge assessment frames.
- Fast verification runs `audit:gold:ci` (10 samples, all fragile ones, all
  scopes, ~90s) on every push — the silent-red hole from the v0.15.3 field
  audit (reproduced at v0.15.185) is structurally closed.

### Lane 3 — Cost & speed

- Byte-identical kernel system prompts (courseLevel schema → user prompt) +
  warm-first dispatch on both Pass B and prose kernel paths, so provider
  prompt caches can land (live telemetry showed cachedInputTokens: 0 on every
  recorded call).
- Feature concurrency 3 → 4; open-readings prefetch overlaps authoring;
  finish retries run per-feature-group in parallel; 120s stream inactivity
  watchdog (the course-map phase previously had none at all).

### Lane 4 — Design system v1 + declutter

- Semantic tokens (accent/status/gbrand CSS variables mapped into Tailwind),
  type scale with a 10px floor (112 sub-10px labels migrated), radius roles,
  `Button`/`Card`/`StatusBadge` primitives, `docs/DESIGN_SYSTEM.md` contract,
  enforced by `tests/design-system.test.js`.
- Declutter: agent Configure nag 3 → 1, empty session-outline Type column
  hidden, autosave pill → quiet meta text, view tab always "Content".

## Release Boundary

This release may NOT claim:

- Live prompt-cache hits or measured wall-clock wins — those require a fresh
  provider round (crucible or deployed audit) after deploy.
- Model downshift routing — designed, deferred pending a per-provider
  cheap-tier sibling map with availability fallback.
- A fix for the pre-existing deliverable-terminal-states E2E failure
  (present at v0.15.185; under separate investigation).
- Completion of the design-system migration — slate utilities, DependencyMap
  SVG palette, the changelog page theme, and legacy dark-mode overrides are
  explicitly opportunistic follow-ups.
