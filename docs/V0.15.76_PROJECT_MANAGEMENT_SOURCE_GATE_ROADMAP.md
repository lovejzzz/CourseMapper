# v0.15.76 Project Management Source Gate Roadmap

## Evidence

A fresh deployed v0.15.75 Project Management ZIP/log audit regraded at 97/100
(A), with 0 P0, 2 P1, and 3 P2 findings. The source-ledger bridge is no longer
empty: the package exported 14 trusted concept-linked source rows. The quality
loss moved to relevance and polish:

- Off-discipline medical, genomics, and implementation-science papers appeared
  as trusted source rows in a Project Management package.
- One lesson remained on template fallback after partial enrichment.
- Course Map text contained a double-period seam from sentence-shaped fallback
  prose.
- Quiz Bank text contained an exact `X: X` echo chain such as `Define project
management: Define project management`.

The live evidence is recorded at
`verification-output/edutool-audit-loop/20260627T-v01575-fresh/`.

## Lane

Product quality and source relevance. CourseMapper must keep source proof both
trusted and on-discipline, then clean deterministic text seams before exported
materials reach the user.

## Scope

- Add Project Management discipline inference so course maps with project
  charter, scope, stakeholder, schedule, agile, Scrum, critical-path, and WBS
  language map to a Project Management source context.
- Add an OpenAlex topic allowlist for Project Management that accepts business,
  decision-science, engineering, and social-science rows while rejecting
  unrelated medicine/health-science rows.
- Treat generated fallback stems as weak course-map topic candidates, so repair
  prose such as quick evidence checks and course-application boilerplate cannot
  become the next topic.
- Strip terminal punctuation from fallback topics before templating.
- Collapse exact `X: X` and `X: For X` echo chains in compiled prose.

## Non-Goals

- Do not lower source-ledger or deep-quality grader standards.
- Do not claim a clean 100/100 package before a fresh deployed v0.15.76 ZIP/log
  audit proves it.
- Do not solve the full partial-enrichment retry architecture in this release.
- Do not redesign the export panel in this release, although the latest UI
  evidence shows it needs a calmer review state.
- Do not promote ambiguous metadata or invent source licenses.

## Release Boundary

In scope:

- Project Management source-topic gating.
- Deterministic course-map fallback-topic cleanup.
- Deterministic compiled-language echo-chain cleanup.
- Focused regression coverage based on the v0.15.75 Project Management package.

Out of scope:

- Broader cross-discipline source ontology.
- Full enrichment retry/recovery work.
- Export-panel and agent-panel UX redesign.
- Provider-model selection changes.
