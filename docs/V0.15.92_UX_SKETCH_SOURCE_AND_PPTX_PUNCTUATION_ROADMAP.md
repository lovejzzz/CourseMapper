# v0.15.92 UX Sketch Source and PPTX Punctuation Roadmap

_Written June 28, 2026. Target app version: `0.15.92`._

## Goal

Keep the `100/100` target honest after the fresh deployed `v0.15.91`
`User Experience Design Studio` ZIP/log audit. That package exported at
`99/A` with texture `94`, but two real quality debts remained:

- a trusted UX source-ledger row accepted `List of In Living Color sketches`
  as proof for sketching, low-fidelity layouts, and screen structure,
- a rendered PPTX example-slide `Key Takeaway` ended on a bare content word
  without terminal punctuation.

## Evidence

The captured audit is stored at:

`verification-output/edutool-audit-loop/20260628T070346Z-v01591-ux-fresh`

Before this release, `local-regrade.json` matched the package at `99/A`.
After adding the stricter source check, the same package regraded at `98/A`
in `local-regrade-after-v01592-patch.json` with two P1 findings:

- `[citations] source ledger row sf-6-3 is off-discipline for User Experience Design Studio`
- `[format] truncated slide bullet ending mid-clause without terminal punctuation`

## Lane 1: Sketch False-Friend Quarantine

- Treat pop-culture and comedy sketch pages as UX false friends.
- Keep those candidates visible as source review rows instead of trusted
  source-ledger proof.
- Preserve real UX sketching, wireframing, information architecture, and
  low-fidelity layout sources.

## Lane 2: Grader Truth

- Mirror the production quarantine in the deep quality grader.
- Prove that the captured `v0.15.91` artifact no longer looks cleaner than it
  really is.
- Do not weaken source thresholds, license requirements, or concept-link
  requirements.

## Lane 3: PPTX Export Cleanup

- Ensure example-slide `Key Takeaway` callouts render with terminal
  punctuation.
- Fix the exported PPTX surface, not the grader.
- Keep short labels and existing punctuation intact elsewhere.

## Carry-Forward Quality Work

- Do not claim clean provider output before a fresh deployed `v0.15.92`
  ZIP/log audit.
- Texture remains below perfect at `94/100`; deterministic variation cleanup
  is still active.
- Continue auditing across UX and Project Management so source gates do not
  overfit one course domain.

## Release Boundary

This release fixes one source-truth class and one PPTX export-format class. It
does not claim clean `100/100`, does not hide findings, and does not lower the
grader. The next proof must be a fresh deployed provider run showing the sketch
false friend is absent from trusted `sourceLedger` proof and the PPTX
punctuation issue no longer appears.
