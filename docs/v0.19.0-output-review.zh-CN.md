# v0.19.0 三套完整课程与教育审读

审读日期：2026-09-06。三套材料来自本次开发集中的虚构来源包，分别是比例与舍入（30 分钟）、历史记录冲突（40 分钟）、公平比较与顺序效应（45 分钟）。每套包含原有十类材料。它们是完整的单次工作坊，并非完整学期课程，也不是新的未见测试。

## 生成与证据范围

三套可重复导出样本使用生产 blueprint/compiler 和 Word、PowerPoint、XLSX、ZIP 导出器，不调用模型。材料保留可编辑结构。ZIP 的文件内容来自生产打包器；审计脚本在 Node 中将这些字节装入 ZIP。另一次实际 Chrome 工作流从首页发起本地 Scion 生成，并通过界面下载了完整课程 ZIP；两种证据没有混为一谈。

真实浏览器生成的比例课完成了十种原有材料。其日志清单明确记载：本地模型的结构化 skeleton 未满足合同，随后走 prose/编译器恢复，最终可导出并带复核提示。完成下载不等于模型成功理解了全部来源，更不等于获得教育质量认证。没有活动 adapter，没有使用托管推理。

对三个开发课程逐项检查了任务、来源、推理、参考答案、常见错误、反馈、评分标准和迁移题；渲染 24 份 Word 文档及三套 PowerPoint，检查全部材料页面。修正后重新渲染，重点复看修改的作业、rubric、测验和全部 48 张幻灯片。XLSX 用独立读取器检查实际单元格与显示。CSV 和完整 ZIP 通过结构、内容和源引用检查。

Word/PPTX 的 PDF 渲染由 LibreOffice 完成，不能冒充网站 PDF 下载链路的验证。随后正式站下载的 Study Guide PDF 暴露出旧横表过密与数学符号异常；现已重写该导出路径，复用 Word 的教学内容构建器。三套课程额外生成 27 份真实 PDF，浏览器逐页检查文字边界、来源限制和答案分页；中文长课件测试验证所有要点与末尾备注保留。另对比例课指南、rubric、测验等实际 PDF 页面做视觉审阅。Google Docs/Sheets/Slides 的真实账号写入及导入后样式没有在本轮逐项验证；其入口和既有选择保留。导出到外部文件后是快照，无法反向自动同步。

## 十类材料的判断

| 材料               | 本轮审读结论与改进                                                                                                      | 使用边界                                                                                 |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Course Map         | 保留目标、课堂流程、确切来源与设计评价；实际 XLSX 可读，内容没有被压缩成泛化主题词。                                    | 课程图是规划索引，具体评分需查看对应任务和 rubric。                                      |
| Syllabus           | 课程目标、材料、任务引用与单次课时保持一致；不将 rubric 的 100 分推断为课程总评权重。                                   | 教师姓名、机构政策和截止时间需要本校教师确认，不能由生成器冒充官方规定。                 |
| Lesson Plans       | 将读来源、示范、解释错误、独立练习和修改安排进原定时长，教师检查使用完整答案。                                          | 三页教师指南仍偏密集；教师应根据学生基础调整讲解速度。                                   |
| Slide Decks        | 来源在任务之前，推理在独立练习之前；教师答案置于备注。修复旧 recap/概念版式吞掉标题或留下半页空栏的问题。               | 三套分别 15、16、17 张，部分页面刻意只保留一项结论；没有自动添加虚构图表或装饰性“证据”。 |
| Assignment Briefs  | 有明确输入、产物、推理要求、错误样例和修改步骤，比例题使用准确的近似符号。                                              | 这是带示范与自评的形成性练习，不应当作无提示的独立考试。                                 |
| Rubrics            | 三项任务相关标准、四个可观察等级、反馈和强弱答案；Word 按标准分表，避免密集横表跨页。                                   | 尚无外部教师评分一致性研究；可接受的等价解法需要教师判断。                               |
| Discussion Prompts | 讨论具体证据、错误与未解决的问题，提供教师追问和闭合答案。                                                              | 不把讨论参与次数当成理解深度，也不据此宣称学生已经迁移。                                 |
| Quiz & Exam Bank   | 保留八题配置；用另一情境检验理解，参考答案与题干相符，最后一题要求按反馈修改。组件学生模式隐藏答案，Word 答案另起一页。 | 题库供教师选题，不应把八题全部塞入短课时。泛化恢复题需要明确的教师答案复核。             |
| Study Guides       | 示范、错误诊断、独立情境、完整答案和反馈使用共同任务数据；区别练习原例与迁移。                                          | 学生可查看答案，独立尝试应先遮住答案；软件无法证明实际独立完成。                         |
| Course FAQ         | 六个简短问题明确要学什么、提交什么、如何评分、如何修改；分类字段符合原编辑器。                                          | FAQ 是课程使用说明，不替代内容教学或机构政策。                                           |

## 三个内容判断

比例课明确区分 `7/12`、四舍五入的 `0.5833` 与 `58.33%`。反向检验保留精确分数，不写成错误的 `0.5833 × 12 = 7`。一批试纸的结果不能外推为其他批次。独立题改用温室种子，并加入未测试的种子，要求学生选择 48 而非 60 作分母。这比只更换数值多了一项分母选择要求，但仍是有限的近迁移。

历史课中两位证人分别把同一首次开放事件记为 1908、1909 年，因此是同一事件的冲突。不能因为日期更早就裁定来源正确。参考答案提出寻找独立、同时代且明确记载同一事件的记录，并标明该记录尚未取得。独立题加入建筑许可日期，要求区分相关背景与能解决首播日期争议的证据。

实验课指出音乐、第二次尝试与练习同时变化，无法从现有记录分离音乐效果。修正方案用可比的 A/B 版本与四个平衡序列，保持计时等条件一致，记录完成时间和错误，并检查顺序差异。方案没有被写成已观察到的有效结果；残留效应和版本等价性仍需检验。独立题改用符号搜索，避免继续要求学生评分不存在的“拼图”步骤。

## 审读发现并修复的具体缺陷

- 学生视图仍能展开测验答案；切换视图后正确选项可能保留绿色标记。
- 泛化题目的参考答案没有复核提示，复制来源被误当成完整答案。
- 最后一题是没有实际案例的“专业决策”填充题。
- 原幻灯片类型与新内容不匹配，形成空比较栏或不合适的大字版式。
- 一些反向检验提示把舍入值误写为等式，来源限制遗漏“其他批次未测试”。
- 来源分析任务混入实验设计指令；符号搜索评分仍提到拼图。
- 新 rubric 内容套用旧横向页面；测验问题与答案出现在同一页。
- 最终去重处理会截短关键来源限制，现保护共享任务中的完整答案、反馈与评分依据。
- PDF 旧横表难以阅读、数学符号与中文缺字，幻灯片 PDF 会丢弃溢出要点并截短备注。
- FAQ 分类缺失；没有选择题的题库被错误报告缺少选择题干扰项。

## 未解决的能力限制

30 个新案例的首次留出测试中，12 个仅 1 个生成了具体共享任务，11 个未覆盖，共 24 个自动缺陷。后续暴露的案例不能再当作未见测试。18 个开发案例通过检查并不能抵消这项结果。

本次材料更具体、更一致，导出缺陷更少，但不能据此声称 Scion 已成为通用教育专用模型或系统可在任何学科无人复核地直接使用。现阶段最可信的产品能力是：保留教师来源、把已准入的具体任务编译为多种可编辑材料、明确显示缺口，并可靠地传播修改。跨学科来源理解、真实教师评分一致性、学生学习成效仍需后续独立验证。

## 重复生成样本

从仓库根目录运行，例如：

```sh
npx vite-node scripts/benchmarks/exportClassroomSamples.ts d-c04-recurring
npx vite-node scripts/benchmarks/exportClassroomSamples.ts d-s02-same-event-conflict
npx vite-node scripts/benchmarks/exportClassroomSamples.ts d-e03-order-effects
```

默认输出到 `.audit-work/v019-classroom-samples/`。每套保留输入、结构化输出、单文件导出、ZIP、就绪报告和 ZIP 检查结果。运行使用开发案例与 compiler，模型调用数为零；真实浏览器 Scion 生成证据另行记录。

学生模式边界：答案隐藏和正确选项样式清除通过组件测试。保留的生产教师工作区没有学生模式切换入口，本轮没有把它记为线上学生模式交互通过。
