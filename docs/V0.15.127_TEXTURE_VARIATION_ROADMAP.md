# V0.15.127 Texture Variation Roadmap

## Goal

Remove deterministic repeated scaffolding that kept a fresh UX Studio package at
`99/100` even after all P0/P1/P2 findings were gone.

## Evidence

- App version: `0.15.126`
- Audit folder:
  `verification-output/edutool-audit-loop/20260629T114208Z-v015126-ux-fresh`
- Visible result: `Quality 99`, `Texture 90`
- Local regrade: `99/100 (A)`
- P findings: `0 P0`, `0 P1`, `0 P2`
- Export verification passed, enrichment coverage was complete, and the prior
  PPTX punctuation P1 no longer reproduced.
- The remaining scored loss was texture, concentrated in repeated shingles such
  as:
  - `cite specific user research findings instead of general impressions`
  - `whole class then quick pair share`
  - `close with the handoff`
  - `collect critique notes, usability evidence, and rationale changes`

## Diagnosis

This is CourseMapper-side deterministic scaffolding, not merely model
randomness. The model can still repeat safe language, but the fresh package
showed compiler-owned phrases repeating through exported lesson plans, slide
notes, and slide-deck grounding metadata. A better model may help, but it cannot
guarantee texture when the compiler stamps identical phrases into every lesson.

## Lane

1. UX studio evidence routine variation
   - Rotate the studio evidence routine by lesson before it reaches compiled
     modality decode and deliverable grounding.
   - Preserve the same critique/usability/rationale intent.

2. Slide note and lesson-plan scaffold variation
   - Rotate discussion evidence notes instead of using one fixed phrasing.
   - Rotate closing handoff speaker notes.
   - Rotate the warm-up grouping string that previously appeared in every lesson
     plan.

3. Deliverable-facing modality grounding
   - Export a compact, lesson-specific course modality profile in grounding
     metadata instead of repeating the raw course-level teaching pattern in each
     deck.

4. Course Map fallback review language
   - Vary generic review checks so Course Map rows do not repeat the same
     audit-looking sentence across lessons.

## Release Boundary

- This release targets the concrete texture loss from the fresh v0.15.126 audit.
- This release does not weaken the grader, source gates, report/digest truth,
  export verification, or source-ledger requirements.
- This release does not claim provider-clean `100/100` until a fresh deployed
  v0.15.127 ZIP/log audit proves the repeated shingles are gone in real provider
  output.
