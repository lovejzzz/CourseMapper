# Introduction to Computer Science with Python

Introduction to Computer Science with Python, a 15-lesson introductory college
course with weekly autograded quizzes and hands-on coding labs. Lessons cover:
orientation and environment setup; variables, expressions, and types;
conditionals and boolean logic; while loops; for loops and range; functions and
scope; lists; strings and text processing; dictionaries and nested data; file
input and output; a midterm review and midterm exam; recursion; classes and
objects; debugging and testing; an introduction to algorithms; and a final
project integrating the full semester.

Grading: weekly quizzes 40%, midterm exam 20%, final project 25%, lab
participation 15%.
